## 핵심 개념

### 클래스와 인스턴스

이름·나이·색상처럼 관련된 속성과 자기소개 같은 동작을 하나의 클래스로 묶어 다룸. `Person`과 `Car` 예제로 서로 다른 값을 가진 인스턴스를 만드는 구조를 살펴봄.

### 인스턴스 초기화와 메서드

인스턴스를 만들 때 필요한 값을 전달하고, `__init__`에서 초기 상태를 설정하도록 구성함. 계좌는 잔액을 0으로 시작하고, 상품은 이름·가격·재고를 전달받도록 작성함.

인스턴스를 통해 메서드를 호출하면 해당 인스턴스가 첫 번째 인자로 자동 전달됨을 확인함. 예제에서는 이 인자를 `self`로 받아 자신의 속성에 접근함.

### 상속과 공통 동작

`Char`에 이름과 체력을 두고, `Warrior`와 `Wizard`가 이를 상속하는 구조를 살펴봄. 자식 클래스에 초기화 메서드가 없어도 부모의 초기화 메서드를 사용할 수 있음을 확인함.

두 자식 클래스에 각각 `attack()`을 정의하여 같은 메서드 이름으로 서로 다른 공격 동작을 표현함.

### 예제 코드와 실행 코드의 구분

`Person`, `Car`, `Student`, `Char` 관련 예제는 삼중 따옴표 안에 보관되어 있어 현재 파일 실행 시 해당 클래스 정의와 호출이 실행되지 않음. 실제 실행 부분과 보관한 예제를 구분해 읽어야 함을 확인함.

## 배운 문법

### 클래스 정의와 클래스 속성

`class`로 클래스를 정의하고, 클래스 본문에 속성을 작성함.

```python
class Person():
    name = "홍길동"
    age = 15
```

### 인스턴스 생성과 속성 변경

클래스를 호출해 인스턴스를 생성하고, 점 표기법으로 해당 인스턴스의 속성값을 변경함.

```python
p1 = Person()
p1.name = "A"
p1.age = 20
```

### `__init__`과 인스턴스 속성

`__init__`에서 전달받은 값을 `self`의 속성에 저장하여 인스턴스의 초기 상태를 설정함. 앞뒤에 밑줄 두 개가 붙는 특수 메서드 표기를 확인함.

```python
class Car():
    def __init__(self, color, mode):
        self.color = color
        self.mode = mode
```

### 인스턴스 메서드와 `self`

인스턴스 메서드의 첫 번째 매개변수로 `self`를 두고 자신의 속성에 접근함. 인스턴스를 통한 호출에서는 호출한 객체가 이 인자로 자동 전달됨.

```python
    def introduce(self):
        print(f"내이름은 {self.name}이야")
```

### `random.randint()`

`random.randint()`로 지정한 범위의 정수를 생성함. 계좌를 초기화하면서 10000000부터 99999999 사이의 값을 계좌번호로 저장함.

```python
        self.number = random.randint(10000000, 99999999)
```

### 복합 대입 연산자

`+=`와 `-=`로 기존 속성값을 증가시키거나 감소시킴. 상품 판매에서는 재고를 차감하고, 재입고에서는 재고를 더하도록 작성함.

```python
        self.stack -= count
        print(f"남은재고:{self.stack}")
        print(f"판매금액:{self.price*count}")

    def restock(self, count):
        self.stack += count
```

### 산술 연산과 반환값

덧셈과 나눗셈으로 세 과목의 총점과 평균을 계산함. `return`으로 계산값을 호출한 곳에 돌려주도록 작성함.

```python
    def total(self):
        return self.korean + self.english + self.math

    def aver(self):
        return (self.korean + self.english + self.math)/3
```

### `if`·`elif`·`else` 조건 분기

평균 점수의 범위를 비교해 등급을 구분함. 높은 점수 조건부터 검사하고, 해당 조건에서 등급을 반환하도록 작성함.

```python
        elif avg >= 80:
            return "B"
        elif avg >= 70:
            return "C"
        else:
            return "D"
```

### `return`을 이용한 조기 종료

조건을 만족하면 안내 문구를 출력하고 `return`으로 메서드를 종료함. 계좌 예제에서는 출금 후 잔액이 음수가 되는 경우 이후 출금 처리를 막도록 작성함.

```python
        if self.balance - amount < 0:
            print("잔액이 부족하여 출금 불가")
            return
```

### f-string

문자열 앞에 `f`를 붙이고 중괄호 안에 속성이나 계산식을 넣어 출력 문자열을 구성함. 계좌·성적·상품 예제에서 반복해서 사용함.

```python
    def info(self):
        print(f"이름:{self.name}, 계좌번호:{self.number}, 잔액:{self.balance}")
```

### 상속과 메서드 재정의

클래스 이름 뒤 괄호에 부모 클래스를 지정해 상속함. 자식 클래스에서 `attack()`을 정의하여 해당 클래스의 공격 동작을 구현함.

```python
class Warrior(Char):

    def attack(self):
        print("검으로 공격")
```

### 리스트와 `for` 반복문

서로 다른 클래스의 인스턴스를 하나의 리스트에 담고 순서대로 순회함. 반복문에서는 각 인스턴스의 `attack()`을 호출함.

```python
chars = [Warrior("전사", 100), Wizard("법사", 50), Warrior("전사", 30)]    

for char in chars:
    char.attack()
```

### 딕셔너리와 `values()`

키와 값의 쌍으로 딕셔너리를 작성함. 딕셔너리 자체와 `values()`로 조회한 값들을 각각 출력하도록 작성함.

```python
d =  {'a':1,
      'b':2}

print(d)
print(d.values())
```
