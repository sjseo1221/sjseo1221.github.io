## 배운 문법

### `for`와 `range`

`range`의 시작값, 종료값, 간격을 지정해 반복함. 시작값을 생략하면 `0`부터 시작하며, 종료값은 반복 범위에 포함하지 않음을 정리함.

```python
for i in range(1, 10, 1): # start, end, step
    print(i) #start 스킵하면 0, 리스트가 보통 0부터 시작하기 때문. 매번0적기 번거로워
```

### `while`과 자릿수 연산

`while`은 조건을 만족하는 동안 반복하며, `% 10`으로 마지막 자리를 구하고 `//= 10`으로 처리한 자리를 제거함. 이 과정을 반복해 각 자릿수를 합산함.

```python
while n > 0:
   sum += n % 10
   n //= 10
print(sum)
```

### 조건문과 개수 누적

`if`로 조건을 확인하고, 조건을 만족할 때 `+= 1`로 개수를 누적함. 배수 여부는 나머지 연산자인 `%`로 확인함.

```python
cnt = 0
for num in num_list:
    if num % 4 == 0: cnt += 1
print(cnt)
```

### `split`, `map`, `list`로 입력 처리

`input().split()`으로 입력을 나누고, `map(int, ...)`로 각 항목을 정수로 변환함. 변환한 값을 `list`로 묶어 리스트에 저장함.

```python
N = int(input())
num_List = list(map(int, input().split())) 
```

### 리스트의 `append`와 `insert`

`append`는 리스트 끝에 값을 추가하고, `insert`는 지정한 위치에 값을 삽입함.

```python
x = 25
num1.append(x) #x값은 맨 끝에 감

#insert
num1.insert(3, x)  #내가 원하는 공간에 넣을수 있음
```

### 리스트의 `sort`

리스트의 `sort()`를 호출해 요소를 정렬함.

```python
#sort
num3 = [10, 5, 2, 1, 83, 72, 37]
num3.sort()
# print(num3)
```

### 인덱스로 순회하고 `break`로 종료하기

`len`과 `range`를 함께 사용해 리스트의 인덱스를 순회함. 목표값을 찾으면 `i+1`로 첫 위치를 1로 세는 번호를 출력하고, `break`로 반복을 종료함.

```python
for i in range(len(num_List)):
    if num_List[i] == target:
        print(i+1)
        break
```

### `%` 형식과 f-string

`%d` 형식과 f-string을 사용해 문자열 안에 정수 값을 넣어 출력함.

```python
print("제가 입력한 숫자는 %d 입니다" %a)
print(f"제가 입력한 숫자는 {a} 입니다.") #f스트링
```
