### 함수와 IQR 경계 계산

`find_whiskers()` 함수에서 `quantile()`로 두 사분위수를 구하고 IQR의 1.5배를 이용해 하한과 상한을 계산함. 두 경계를 함께 반환함.

```python
    Q1 = data[column].quantile(0.25)
    Q3 = data[column].quantile(0.75)
    iqr = Q3 - Q1
    lower = Q1 - 1.5 * iqr
    upper = Q3 + 1.5 * iqr
    return lower, upper
```

### 자료형 조건, 이상치 집계와 경계 저장

`dtype`과 `or` 조건으로 문자형·불리언형 컬럼을 건너뛰고, 반환받은 경계를 두 변수로 나누어 받음. 범위 밖 조건을 `|`로 결합해 개수를 세고 경계를 딕셔너리에 저장하며, 이상치 처리에는 `clip()`을 사용함.

```python
d = {}
for c in X_train.columns:
    if X_train[c].dtype == "object" or X_train[c].dtype == "bool": continue
    lower, upper = find_whiskers(X_train, c)
    print(c, ":", ((X_train[c] < lower) | (X_train[c] > upper)).sum())
    d[c] = [lower, upper]
```
