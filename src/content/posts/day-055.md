## 오늘 배운 것

- `nn.Module`을 상속하고 레이어 구성과 `forward()` 연산을 나누어 신경망을 구현함.
- 이미지 입력을 펼친 뒤 Linear와 ReLU를 거쳐 클래스별 점수를 계산하는 구조를 실습함.
- 모델과 데이터를 같은 장치로 옮기고, 예측 확률과 모델 파라미터를 확인하는 방법을 익힘.

## 핵심 개념

### 실습한 신경망의 구성

28×28 이미지 입력을 받아 은닉층 두 개와 출력층을 통과하는 신경망을 구성함. 입력 특성 784개에서 은닉층 512개, 은닉층 512개, 출력 10개로 이어지도록 설정함.

은닉층의 Linear 뒤에는 ReLU를 배치하고, 마지막 Linear에서는 클래스별 점수인 logits를 반환하도록 구현함.

### 클래스별 점수와 예측

모델이 반환한 logits를 Softmax에 전달해 클래스별 확률 분포로 변환함. 이후 확률이 가장 큰 클래스의 인덱스를 예측값으로 선택함.

### 연산 장치 설정

가속기를 사용할 수 있으면 해당 장치를 선택하고, 그렇지 않으면 CPU를 사용하도록 구성함. 모델과 입력 데이터 모두 선택한 `device`로 옮긴 뒤 추론을 수행함.

## 배운 문법

### 가속기 사용 가능 여부 확인

`torch.accelerator.is_available()`로 가속기 사용 가능 여부를 확인함. 사용할 수 있는 경우 현재 가속기의 종류를 가져오고, 나머지는 CPU로 설정함.

```python
if torch.accelerator.is_available():
  device = torch.accelerator.current_accelerator().type # GPU가 있다면 GPU로 변환
else:
  device = "cpu"                                         # 아니면 CPU활요
```

### 클래스 상속과 초기화

`nn.Module`을 상속하는 클래스를 선언하고, `__init__()`에서 `super().__init__()`을 호출함. 사용할 레이어를 인스턴스 속성으로 설정함.

```python
class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
```

### `forward()` 정의

`forward()` 안에 입력 데이터가 통과할 연산 순서를 작성함. 입력을 펼치고 레이어 묶음을 적용한 뒤 logits를 반환함.

```python
    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits
```

### `nn.Flatten()` 적용

`nn.Flatten()`으로 펼치기 레이어를 만들고 입력 이미지에 적용함.

```python
flatten = nn.Flatten()
flat_image = flatten(input_image)
```

### `nn.Linear()` 설정

`in_features`와 `out_features`에 입력과 출력 특성 수를 지정함. 생성한 레이어를 함수처럼 호출해 입력에 적용함.

```python
layer1 = nn.Linear(in_features=28*28, out_features=20)
hidden1 = layer1(flat_image)
```

### `nn.ReLU()` 적용

`nn.ReLU()`로 생성한 활성화 함수를 중간 연산 결과에 적용함.

```python
hidden1 = nn.ReLU()(hidden1)
```

### `nn.Sequential()`로 레이어 묶기

여러 레이어를 `nn.Sequential()`에 순서대로 전달함. 실습에서는 펼치기, 선형 변환, 활성화, 다음 선형 변환을 하나로 묶음.

```python
seq_modules = nn.Sequential(
    flatten,
    layer1,
    nn.ReLU(),
    nn.Linear(20, 10)
)
```

### `torch.rand()`로 입력 만들기

`torch.rand()`에 차원별 크기를 전달해 실습용 무작위 입력 텐서를 생성함.

```python
input_image = torch.rand(3, 28, 28)
```

### `.to(device)`로 장치 이동

모델 인스턴스와 텐서에 `.to(device)`를 호출해 선택한 연산 장치로 옮김.

```python
X = torch.rand(1, 28, 28).to(device)      # 데이터를 device로 옮기기

logits = model(X)                         # 클래스별 점수(logits), shape: (1, 10)
```

### 모델 인스턴스 생성과 구조 확인

정의한 클래스로 모델 인스턴스를 생성하고 장치를 지정함. `print(model)`로 구성한 신경망 구조를 확인함.

```python
model = NeuralNetwork().to(device)
print(model) # 내가 만든 신경망 구조가 그대로 나온다.
```

### 모델 호출

모델 인스턴스를 함수처럼 호출하고 입력 텐서를 전달함. 반환값을 logits 변수에 저장함.

```python
logits = seq_modules(input_image)
```

### `nn.Softmax()`와 차원 지정

`nn.Softmax(dim=1)`로 확률 변환에 사용할 차원을 지정함. 생성한 모듈에 logits를 전달함.

```python
softmax = nn.Softmax(dim=1)
pred_probab = softmax(logits)
```

### `argmax()`로 예측 인덱스 선택

`argmax(1)`로 지정한 차원에서 가장 큰 값의 인덱스를 구함.

```python
y_pred = pred_prob.argmax(1)            # 확률이 가장 큰 클래스의 인덱스
```

### `.size()`로 텐서 크기 확인

텐서의 `.size()`를 호출해 각 연산 단계의 크기를 확인함.

```python
print(input_image.size())
```

### 파라미터 순회와 슬라이싱·f-string

`named_parameters()`가 제공하는 이름과 파라미터를 `for`문에서 나누어 받음. f-string에 파라미터 크기와 `param[:2]`로 선택한 일부 값을 넣어 출력함.

```python
for name, param in model.named_parameters():
    print(f"Layer: {name} | Size: {param.size()} | Values : {param[:2]} \n")
```
