## 핵심 개념

### 문자열과 숫자의 구분

따옴표로 감싼 숫자는 숫자가 아니라 문자열로 다룸. 실습에서는 `"1"`과 `"2"`를 변수에 저장한 뒤 더하는 코드로 문자열 처리를 확인함.

입력받은 값도 기본적으로 문자열이므로 계산에 사용하려면 형 변환이 필요함. 숫자와 문자열을 그대로 더하는 연산은 지원하지 않아 오류가 발생한다는 점을 기록함.

### 변수와 이름의 규칙

변수는 값을 저장하고 이후에 다시 참조하는 데 사용함. 변수 이름은 대소문자를 구분하며, 숫자로 시작하거나 공백을 포함할 수 없음을 확인함.

변수 자체를 출력하는 것과 변수 이름을 따옴표로 감싸 출력하는 것을 구분함. 전자는 저장된 값을 참조하고, 후자는 문자열을 다루는 방식임.

### 계산과 조건 판단을 활용한 실습

합·차·곱·몫·나머지를 계산하는 연습부터 시작해, 평균 계산과 자릿수 분리, 시간 단위 변환으로 확장함. 조건문을 활용한 점수 구간 분류, 약수·배수 판단, 윤년 판단도 연습함.

마지막에는 가위바위보 게임에서 현재 돈, 진행 횟수, 승리 횟수를 따로 관리함. 돈은 1,000원에서 시작하며, 비기면 500원을 차감하고 이기면 1,000원을 더하며 지면 700원을 차감하도록 작성함. 게임은 진행 횟수가 15회 미만이고 돈이 남아 있는 동안 반복하도록 구성함.

### 문자열 표기와 변수 대입

`=`로 변수에 값을 저장하며, 문자열은 작은따옴표와 큰따옴표로 표현할 수 있음을 확인함. 수업에서는 문자열 표기를 큰따옴표로 통일하기로 기록함.

```python
a="1"
b="2" #숫자의 문자처리
print(a+b)

a='바나나' #파이썬은 쌍따옴표와 작은따옴표 구분을 안해
```

### `print()`의 `end` 지정

`print()`는 기본적으로 출력 뒤에 줄바꿈을 수행함. `end`를 지정하면 출력 끝에 붙일 내용을 바꿀 수 있음을 확인함.

```python
print("hello workd", end='!!!')
print("python")
```

### `%`를 이용한 출력 포매팅

`%d`로 정수, `%f`로 실수를 문자열에 넣고, 여러 값을 넣을 때는 자리 표시자와 값을 일대일로 맞춤. `%.1f`처럼 소수점 아래 표시 자릿수를 지정하는 방법도 연습함.

```python
print("지금 시간은 %d시 %d분 입니다" %(hour, min))

eye = 1.0
print("제 시력은 %f입니다" %eye)
print("제 시력은 %.1f입니다" %eye) #소수점 1자리
```

### `input()`, `split()`, `map()`을 이용한 입력 처리

`input()`으로 받은 문자열을 `split()`으로 나누고, `map(int, ...)`로 각 값을 정수로 변환함. 변환한 두 값을 각각 변수에 저장해 계산하는 방식을 연습함.

```python
#정수형으로 바꾸고싶을때
# num1, num2 = map(int, input("숫자 2개 입력: ").split())
# print(num1 + num2)
```

### 복합 대입 연산자

`+=`, `-=`, `*=`, `%=`로 기존 변수의 값을 계산한 뒤 같은 변수에 다시 저장함. 주석에 풀어 쓴 대입식과 비교하며 의미를 확인함.

```python
# num = 5
# num += 1 # num = num + 1
# num -= 1 # num = num - 1
# num *= 4 # num = num * 4
# num %= 5 # num = num % 5
# print(num)
```

### `if`, `elif`, `else`를 이용한 분기

조건이 참일 때 실행할 처리를 `if`로 작성하고, 다른 조건은 `elif`, 나머지 경우는 `else`로 구분함. 조건 아래에 여러 문장을 둘 때는 들여쓰기로 해당 조건에 속하는 범위를 나타냄.

```python
# num = int(input("숫자입력: "))

# if num > 0: print("True")
# elif num == 0: print("zero")
# else: print("False")
```

### `randint()`를 이용한 난수 생성

`random` 라이브러리의 `randint(1,3)`으로 1부터 3까지의 정수 중 하나를 선택하도록 작성함. 이를 컴퓨터의 가위바위보 선택값으로 사용함.

```python
    com = randint(1,3) #랜드값중에 인트만 가져올거
    user = int(input("숫자 입력: "))
```

### `while`과 논리 연산자 `and`

`while`에 반복 조건을 작성하고, `and`로 진행 횟수와 남은 돈의 조건을 함께 확인함. 반복 안에서는 현재 게임 순서를 출력하며 진행 상태를 관리함.

