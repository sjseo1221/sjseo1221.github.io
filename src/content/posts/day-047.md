### 클래스 비율과 반올림

`value_counts(normalize=True)`로 클래스별 비율을 계산함. 여기에 100을 곱해 백분율로 바꾸고, `round()`로 소수점 둘째 자리까지 반올림함.


### 조건 필터링과 분위수

불리언 조건으로 행을 추린 뒤 클래스 비율을 계산함. `quantile(0.9)`로 구한 경계보다 값이 **큰** 행만 선택하므로, 경계와 같은 값은 포함하지 않음.

```python
round(df[df['wavelet_skewness'] > 0]['is_forged'].value_counts(normalize=True)[0]*100, 2)
qan90 = df['wavelet_variance'].quantile(0.9)
round(df[df['wavelet_variance']>qan90]['is_forged'].value_counts(normalize=True)[1]*100, 2)
```

```python
df.groupby('is_forged')[['wavelet_variance','wavelet_skewness', 'wavelet_curtosis', 'image_entropy']].mean().round(2)
```

### 컬럼 제외와 중복 처리

`drop(columns=...)`으로 컬럼을 제외하고, `.columns`로 남은 컬럼 이름을 가져옴. `duplicated().sum()`으로 중복 수를 세고, 중복 제거에는 `drop_duplicates()`를 사용함.

```python
cols = df.drop(columns=['note_id']).columns
dup_cnt = df[cols].duplicated().sum()
print(dup_cnt)
df.info()
```

### 학습·테스트 데이터 분리와 언패킹

`train_test_split()`의 반환값을 네 변수에 나누어 저장함. 테스트 비율은 `0.3`, `random_state`는 `42`로 지정함.

```python
x_cols = df.drop(columns=['is_forged']).columns

x_train, x_test, y_train, y_test = train_test_split(df[x_cols], df['is_forged'], test_size=0.3, random_state=42)
```

### 중앙값으로 결측치 채우기

`median()`으로 컬럼별 중앙값을 구하고, `fillna()`로 결측치를 대체함. 테스트 데이터에도 학습 데이터에서 구한 중앙값을 적용함.

```python
x_train = x_train.fillna(x_train.median())
x_test = x_test.fillna(x_train.median())
```

### IQR 경계 계산과 이상치 집계

학습 데이터의 25%·75% 분위수 차이로 IQR을 구하고, 각 분위수에서 IQR의 1.5배만큼 떨어진 값을 하한과 상한으로 설정함. 컬럼별 비교 결과에 `sum()`을 적용해 경계를 벗어난 값의 개수를 확인함.

```python
IQR = q_75 - q_25
upper = q_75 + 1.5 * IQR
lower = q_25 - 1.5 * IQR

print((x_train[x_cols] > upper).sum())
print((x_train[x_cols] < lower).sum())
```

### `clip()`으로 이상치 제한

`clip()`으로 하한보다 작은 값과 상한보다 큰 값을 각각 경계값으로 제한함. `axis=1`을 지정해 컬럼별 경계를 적용함.

```python
x_train = x_train.clip(lower, upper, axis=1)
x_test = x_test.clip(lower, upper, axis=1)
```

### Logistic Regression 모델 학습

`LogisticRegression()`으로 모델을 생성함. `fit()`에 학습 특징과 타깃을 전달해 학습함.

```python
model = LogisticRegression()
model.fit(x_train, y_train)
```

### 테스트 데이터 예측

`predict()`에 테스트 특징을 전달하고, 예측값을 `y_pred`에 저장함. 작성한 코드에서는 예측 배열을 출력하도록 구성함.

```python
y_pred = model.predict(x_test)
print(y_pred)
```

### 정확도 계산

`accuracy_score()`에 실제 타깃과 예측값을 전달해 정확도를 계산함. 실행 결과가 입력에 없으므로 정확도 수치는 기재하지 않음.

```python
accuracy_score(y_test, y_pred)
```

### 혼동행렬과 히트맵

`confusion_matrix()`로 실제값과 예측값의 분류 결과를 집계함. `sns.heatmap()`의 `annot=True`, `fmt='d'`를 지정해 각 칸의 값을 정수로 표시함.

```python
cm = confusion_matrix(y_test, y_pred)
print(cm)
sns.heatmap(cm, annot=True, fmt='d')
plt.show()
```
