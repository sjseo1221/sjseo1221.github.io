## 핵심 코드

### ① 전처리 + 윤곽선

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)   # 색 정보가 필요 없고 계산량도 줄어서 흑백으로 바꿈
blurred = cv2.GaussianBlur(gray, (5, 5), 0)     # 블러 없이 Canny를 쓰면 잡음이 가짜 엣지로 잡힘. 커널은 홀수, 0이면 σ를 자동 계산
edges = cv2.Canny(blurred, 80, 160)             # 160 이상은 확실한 엣지, 80~160은 확실한 엣지와 이어질 때만 엣지, 80 미만은 버림

contours, _ = cv2.findContours(
    edges, cv2.RETR_EXTERNAL,                   # 가장 바깥 윤곽선만 가져옴. 도형 안쪽 윤곽선은 무시함
    cv2.CHAIN_APPROX_SIMPLE)                    # 직선 구간의 중간 점을 생략해 점 개수를 줄임
large_contours = [c for c in contours if cv2.contourArea(c) >= 1000]  # 작은 잡음 윤곽선 제거
```

### ② 도형 판별

```python
area = cv2.contourArea(cnt)
perimeter = cv2.arcLength(cnt, True)            # True는 닫힌 곡선이라는 뜻
if area <= 0 or perimeter == 0:                 # 아래 원형도 계산에서 0으로 나누는 것을 막음
    return "Unknown"

approx = cv2.approxPolyDP(cnt, 0.02 * perimeter, True)  # 둘레의 2%까지 오차를 허용해 다각형으로 단순화함. 값을 키우면 꼭짓점이 줄어듦
vertices = len(approx)
circularity = 4 * np.pi * area / (perimeter ** 2)       # 원 = 1.0, 정사각형 ≈ 0.785, 정삼각형 ≈ 0.605

if vertices == 3:   return "Triangle"
elif vertices == 4: return "Quadrilateral"
elif vertices >= 8 and circularity >= 0.85: return "Circle"  # 꼭짓점이 많은 것만으로는 별 모양과 구분이 안 돼서 원형도도 확인함
else: return "Unknown"
```

## 🐛 에러 로그 (코드 점검에서 발견)

- 해결: 창 이름을 `"Edges"`, `"Result"`처럼 나눔

## Q&A

**cv2가 뭐임?**
- 처음 내 이해: 그냥 import하는 라이브러리 이름
- 실제로는: OpenCV(컴퓨터 비전 라이브러리)의 파이썬 모듈임. 설치 이름은 `opencv-python`, import 이름은 `cv2`로 서로 다름. 1.x 때 `cv`였고 2.x부터 `cv2`가 됐으며, 4.x인 지금도 관례로 `cv2`를 씀

**가우시안 블러는 어떤 원리임?**
- 처음 내 이해: 이미지를 뿌옇게 만드는 효과
- 실제로는: 각 픽셀을 주변 픽셀의 가중 평균으로 바꾸는 합성곱임. 잡음은 주변과 튀는 값이라 평균을 내면 눌리고, 도형 테두리 같은 큰 밝기 차이는 남음. 다만 커널이 너무 크면 진짜 엣지도 약해짐

**"중심이 크고 바깥은 작음"은 무슨 뜻임?**
- 처음 내 이해: 뜻을 모름
- 실제로는: 섞는 비율이 위치마다 다르다는 뜻임. 3×3 커널 기준으로 중심이 4/16(25%), 상하좌우가 각 2/16, 모서리가 각 1/16임. 평균 블러는 모든 칸이 같은 비율이라 더 거칠게 뭉개짐

**왜 하필 중심이 제일 큼?**
- 처음 내 이해: 그냥 그렇게 정한 것
- 실제로는: 중심이 지금 새 값을 계산하는 픽셀 자신이라서임. 자기 값은 대부분 유지하고 튀는 부분만 완화하려는 것임. 수식으로도 거리 0에서 $e^0 = 1$로 최댓값이 됨. 가까운 픽셀일수록 같은 물체일 가능성이 높다는 직관과도 맞음

**Canny의 80, 160은 그냥 사람이 주는 값임?**
- 처음 내 이해: 정해진 표준값이 있을 것
- 실제로는: 맞음, 사람이 정하는 하이퍼파라미터임. 조명, 대비, 카메라 잡음에 따라 최적값이 달라서 자동으로 정해지지 않음. 하위:상위 비율은 보통 1:2~1:3을 씀
- (보충) 임계값을 낮추면 엣지가 많이(잡음 포함) 잡히고, 높이면 뚜렷한 엣지만 남지만 테두리가 끊길 수 있음
