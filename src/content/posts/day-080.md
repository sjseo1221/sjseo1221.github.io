## 오늘 배운 것

- Responses API로 Few-Shot 분류, 반례 기반 답장, 단계별 추론(CoT)을 실습하고 Gradio 화면의 입력 컴포넌트를 하나씩 추가해 봄.
- 규칙은 instructions, 처리할 내용은 input에 두고, 응답 JSON은 loads로 검사한 뒤 dumps로 출력함.

## 실습 흐름

1. 클라이언트 준비(API 키 → `client`)
2. instructions·prompt 문자열 작성
3. `client.responses.create` 호출
4. 결과 후처리(JSON이면 `loads`/`dumps`)
5. 기대 결과와 비교

- Q1 Few-Shot: 정답 예시 6개를 보여 주고 문의 5건을 JSON으로 분류시킴 (5건 모두 기대 결과와 일치)
- Q2 Counter-Example: 나쁜 답장 4개를 보여 주고 스스로 문제점을 판단해 좋은 답장을 쓰게 함
- Q3 CoT: 5단계 출력 포맷을 정해 카페 순이익 문제를 단계별로 풀게 함 (정답 200,550원과 일치)
- Gradio: `gr.Interface`에 Textbox → Number → Radio → CheckboxGroup → Slider → Dropdown을 하나씩 추가함

## 핵심 코드

### 1. Few-Shot 분류 호출과 JSON 후처리

```python
import json
from openai import OpenAI
from google.colab import userdata

api_key = userdata.get('openai_api')       # Colab 보안 비밀에서 키를 읽어 코드에 키를 직접 쓰지 않음
client = OpenAI(api_key=api_key)           # 이후 모든 API 호출의 출발점

developer_instructions = """...라벨 정의, JSON 배열만 출력해..."""  # 고정 규칙은 instructions에
prompt = """[예시]...[분류 대상]...[출력 포맷]..."""               # 예시와 분류 대상은 input에

response = client.responses.create(
    model="gpt-4o-mini",                   # 작고 저렴한 mini 등급 모델
    instructions=developer_instructions,   # 규칙: 우선순위가 높고 거의 안 바뀜
    input=prompt,                          # 이번 요청에서 처리할 내용
    temperature=0,                         # 정답이 정해진 작업이라 무작위성을 최소로
)

text = response.output_text.strip().removeprefix("```json").removeprefix("```").removesuffix("```").strip()
# 모델이 코드블록으로 감쌌을 때만 제거됨, 아니면 그대로 통과하므로 조건문이 필요 없음
result = json.loads(text)                  # JSON 문자열 → list[dict], 형식이 틀리면 여기서 JSONDecodeError
print(json.dumps(result, ensure_ascii=False, indent=2))  # 한글 유지 + 들여쓰기된 정식 JSON으로 출력
```

### 3. Gradio 최종 구조

```python
def greet(name, age, gender, hobbies, happiness, lang):  # 매개변수 순서 = inputs 리스트 순서
    ...
    r += "\n" + "당신은" + str(happiness) + "만큼 행복하군요!"  # 숫자는 str()로 바꿔야 + 연결 가능
    r += "\n" + "당신은" + lang + "개발자군요!"                # lang은 이미 str이라 변환 불필요
    return r

demo = gr.Interface(
    fn = greet,                            # 괄호 없이 함수 자체를 넘김, Submit 때 Gradio가 호출함
    inputs = [
        gr.Textbox(label = "이름"),                              # str
        gr.Number(label = "나이", minimum=1, maximum=99),         # float(30.0처럼 소수점이 붙음)
        gr.Radio(label = "성별", choices = ["남자", "여자"]),      # 하나 선택, 미선택이면 None
        gr.CheckboxGroup(label = "취미", choices=["게임", "운동", "독서"]),  # 여러 개 선택, list[str]
        gr.Slider(label ="행복도", minimum=0, maximum=100),       # 숫자
        gr.Dropdown(label = "주언어", choices = ["Python", "C++", "Java"]),  # 하나 선택, str
    ],
    outputs = gr.Textbox(label = "출력")
)
demo.launch()
```

- (보충) 수업 코드의 `gr.Checkboxgroup`은 오타이고 `gr.CheckboxGroup`(대문자 G)이어야 함
- (보충) `r[:-4]`는 `과(와)`가 4글자라서 마지막 조사를 지우는 용도이며, 취미를 하나도 안 고르면 엉뚱한 글자가 잘림

## Q&A

- 질문: Few-shot 프롬프트란 무엇이고 zero-shot과 어떻게 다른가?
- 처음 내 이해: few-shot이라는 용어를 몰랐음
- 실제로는: 입력과 정답 쌍을 몇 개 보여 주고 새 입력을 같은 패턴으로 처리시키는 방식이며, 예시 없이 지시만 주는 것이 zero-shot임. 출력 형식과 판단 기준을 예시로 전달할 수 있음. 예시가 한 라벨에 쏠리면 결과도 쏠림

- 질문: `instructions`와 `input`(프롬프트)은 어떻게 다르고, 규칙을 `input`에 합쳐도 되는가?
- 처음 내 이해: 인스트럭션을 프롬프트에 넣어도 되는 것 아닌가 생각했음
- 실제로는: 동작은 하지만 instructions는 개발자 지시라 우선순위가 높고, input은 요청마다 바뀌는 처리 대상임. 분리하면 재사용이 쉽고 입력 속 문장이 규칙으로 오해될 여지가 줄어듦. previous_response_id로 대화를 이어도 instructions는 이월되지 않아 매 요청 다시 넘겨야 함

- 질문: few-shot 예시와 출력 포맷을 `instructions`에 넣어도 되는가?
- 처음 내 이해: 고정 규칙이니 instructions에 넣어도 될 것 같다고 생각했음
- 실제로는: 가능하고 오히려 자연스러운 구조임. 규칙·예시·포맷은 instructions, 바뀌는 분류 대상만 input에 두면 재사용이 쉬움. 대신 instructions는 매 요청 보내므로 예시가 길수록 토큰을 더 씀

- 질문: `prompt` 변수는 사용자 입력을 받는 것인가, `input=` 인자와 `input()` 함수는 무엇이 다른가?
- 처음 내 이해: prompt 변수가 입력을 받는 것이라 생각했음 (실습 1의 `input()` 때문)
- 실제로는: `prompt`는 코드에 미리 써 둔 문자열일 뿐이고 입력을 기다리지 않음. 입력 대기는 파이썬 내장 함수 `input()`이 하고, `input=`은 API의 인자 이름임

- 질문: `json.loads`로 변환한 뒤 `json.dumps`로 다시 문자열로 바꾸는 이유는 무엇인가?
- 처음 내 이해: 이미 JSON인데 왜 다시 바꾸는지 몰랐음
- 실제로는: loads는 올바른 JSON인지 검사하고 값을 꺼내 쓰기 위한 것이고, dumps는 큰따옴표와 들여쓰기가 있는 정식 JSON으로 보기 좋게 출력하기 위한 것임

- 질문: `json.loads`의 반환 자료형은 무엇이고, `print(result)`와 `json.dumps` 출력은 어떻게 다른가?
- 처음 내 이해: list로 반환되는지, 어떤 모양인지 확인하고 싶었음
- 실제로는: 맨 바깥이 `[`면 list, `{`면 dict로 결정됨. 이번에는 dict 5개가 든 list였음. `print(result)`는 작은따옴표 한 줄이고, `dumps(indent=2)`는 큰따옴표에 항목마다 줄바꿈됨. `ensure_ascii=False`를 빼면 한글이 유니코드 코드로 바뀜

- 질문: `removeprefix`와 `removesuffix`는 무슨 함수이고 `lstrip`/`rstrip`과 무엇이 다른가?
- 처음 내 이해: 응답 정리 코드에서 처음 보고 용도를 몰랐음
- 실제로는: 문자열 맨 앞/맨 뒤가 지정한 덩어리와 같을 때 한 번만 제거한 새 문자열을 돌려줌. 일치하지 않으면 원본을 그대로 반환해 에러가 없음. lstrip/rstrip은 인자를 글자 집합으로 보고 연속되는 만큼 모두 지움. 여기서는 모델이 응답을 코드블록으로 감쌌을 때만 제거하는 방어용임
