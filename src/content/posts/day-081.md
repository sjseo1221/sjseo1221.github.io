## 오늘 배운 것

- Gradio는 함수 하나를 입력·출력 컴포넌트와 연결해 앱으로 만드는 도구이고, Interface는 한 번에, Blocks는 배치와 이벤트를 직접 조립함.
- 입력·출력 리스트의 순서가 곧 함수의 인자·반환값 순서이며, matplotlib 그래프는 `fig`를 반환해서 `gr.Plot`에 넘김.

## 이론 파트

### Interface와 Blocks

- Interface: `fn`, `inputs`, `outputs` 세 가지만 주면 화면이 자동으로 만들어짐 (실습 3: 계산기, BMI)
- Blocks: `Row`/`Column`으로 배치를 직접 정하고 `btn.click`, `msg.submit`으로 이벤트를 연결함 (실습 4, 5)
- 공통 규칙: `inputs` 리스트 순서 = 함수 인자 순서, 함수 반환값 순서 = `outputs` 리스트 순서
- 함수는 `fn=calculate`처럼 괄호 없이 넘김. 괄호를 붙이면 그 자리에서 바로 호출되어 버림

### matplotlib: fig와 ax

- `fig`(Figure): 도화지 전체. 저장하거나 Gradio에 통째로 넘기는 단위
- `ax`(Axes): 도화지 안의 그래프 칸. 점, 선, 제목은 여기에 그림
- `fig, ax = plt.subplots()`: 빈 도화지와 그래프 칸을 만들어 두 값을 언패킹으로 받음

### 이론 Q&A

- 질문: `np.random.rand`와 `np.random.randn`은 어떤 분포 차이가 있는가?
- 처음 내 이해: 둘의 차이를 몰랐음
- 실제로는: `rand`는 0 이상 1 미만의 균등분포, `randn`은 평균 0, 표준편차 1인 정규분포. x 좌표처럼 고르게 흩뿌릴 때는 `rand`, 잡음처럼 0 주변에 몰려야 할 때는 `randn`을 씀

- 질문: 선형회귀 실습에서 `y = 3 * X + 5 + noise` 수식을 쓴 이유는 무엇인가?
- 처음 내 이해: 왜 이런 수식을 썼는지 몰랐음
- 실제로는: 정답 직선(기울기 3, 절편 5)을 아는 가짜 데이터를 만들어, 학습 후 `coef_`가 3 근처, `intercept_`가 5 근처로 복원되는지 확인하려는 것. `noise`는 현실 데이터처럼 점이 직선에서 흩어지게 하는 용도이고, 3과 5 자체에 특별한 의미는 없음

- 질문: `plt.plot()`과 `plt.subplots()`의 차이와 `subplots`의 쓰임은 무엇인가?
- 처음 내 이해: 비슷한 그리기 함수라고 생각함
- 실제로는: `plot`은 선을 그리는 함수이고, `subplots`는 도화지(`fig`)와 그래프 칸(`ax`)을 만드는 함수. `subplots(1, 2)`처럼 행·열을 주면 한 도화지에 그래프를 여러 개 놓을 수 있음

- 질문: 같은 `ax`에 `plot`을 두 번 호출하면 점과 직선이 한 그래프에 겹쳐 그려지는가?
- 처음 내 이해: `ax.plot()` 두 번이면 점과 직선이 다 들어간다고 생각함
- 실제로는: 같은 `ax`라면 겹쳐 그려짐. `ax.plot(X, y, "o")`로 점도 그릴 수 있지만, 점 하나하나에 크기·색을 줄 수 있는 `scatter`가 산점도에는 더 적합함

- 질문: `fig, ax = plt.subplots()` 줄을 쓰지 않고 `ax.scatter`와 `ax.plot`만 쓰면 안 되는가?
- 처음 내 이해: 그냥 `ax.scatter`, `ax.plot`을 두 번 쓰면 된다고 생각함
- 실제로는: `ax`는 `subplots()`가 만들어 주는 변수라서 이 줄 없이는 `NameError`가 남. 또 `return fig`로 Gradio에 넘길 `fig`가 필요하고, 호출할 때마다 새 도화지를 만들어 그래프가 겹쳐 쌓이는 것도 막아 줌

- 질문: `plt.plot()`을 쓰면 반환되어 넘어가는 것은 `ax`인가?
- 처음 내 이해: `plt.plot()`이 `ax`를 넘긴다고 생각함
- 실제로는: `plt.plot()`은 `ax`도 `fig`도 아닌 선 객체(`Line2D`) 리스트를 반환함. Gradio `gr.Plot`에 넘기는 것은 `fig`이고, `plt.plot()` 방식이면 `plt.gcf()`로 꺼낼 수 있음

### 핵심 코드 1: 파일 단어 빈도 분석 (실습 4-1)

```python
from collections import Counter

def analyze(file):  # file: gr.File(type='filepath')라서 파일 '경로 문자열'이 들어옴
  with open(file, "r", encoding='cp949') as f:  # 한글 윈도우 텍스트 인코딩. UTF-8 파일이면 'utf-8'로 바꿔야 UnicodeDecodeError가 안 남
    txt = f.read()  # 파일 전체가 하나의 긴 str

  words = txt.split()  # 공백·줄바꿈 기준으로 잘라 단어 리스트로 만듦
  words = [word for word in words if len(word) >= 2]  # 한 글자(조사 등)는 제외
  counter = Counter(words)  # {단어: 횟수} 형태로 집계
  top5 = counter.most_common(5)  # [(단어, 횟수), ...] 횟수 많은 순 상위 5개

  response = ""  # 결과 문장을 쌓을 빈 문자열
  for word, count in top5:  # 튜플을 word, count로 언패킹. counter를 넣으면 전체가 돌고, words를 넣으면 ValueError
    response += f"{word} : {count}회\n"  # \n이 없으면 결과가 한 줄로 붙음
  return response  # for와 같은 들여쓰기(반복문 밖). 안에 넣으면 첫 줄만 만들고 끝남. 이 값이 결과 Textbox로 감
```

### 핵심 코드 2: 선형회귀 그래프 (실습 4-2)

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

def draw(n):  # n: 슬라이더 값(초기값 10, 범위 5~100, step=1이라 정수)
  X = np.random.rand(n, 1) * 10  # 0~10 균등 난수, shape (n, 1). fit은 (샘플 수, 특성 수) 모양을 요구해서 2차원
  noise = np.random.randn(n, 1) * 2  # 평균 0, 표준편차 2인 정규분포 잡음
  y = 3 * X + 5 + noise  # 정답 직선(3, 5) + 잡음

  model = LinearRegression()  # 학습 전 모델
  model.fit(X, y)  # coef_ ≈ 3, intercept_ ≈ 5로 학습됨 (n이 클수록 더 가까움)
  y_pred = model.predict(X)  # 직선 위의 예측값, shape (n, 1)

  fig, ax = plt.subplots()  # 호출마다 새 도화지. fig는 Gradio에 넘기고 ax에 그림
  ax.scatter(X, y)  # 잡음 섞인 실제 데이터는 점으로
  ax.plot(X, y_pred, color="red")  # 예측값은 빨간 선으로
  ax.set_xlabel("X")
  ax.set_ylabel("y")
  ax.set_title("Random Linear Regression Data")

  return fig  # 숫자·문자열이 아니라 그림 객체를 gr.Plot에 넘김
```

### 핵심 코드 3: 대화 기억이 이어지는 챗봇 응답 (실습 5)

```python
from openai import OpenAI
from google.colab import userdata

api_key = userdata.get('openai_api')  # Colab 보안 비밀에서 읽음. 키를 코드에 직접 쓰지 않으려는 목적
client = OpenAI(api_key=api_key)

temperature = 1  # 클수록 답이 다양함 (0~2)
instructions = None  # 역할 지시문. 설정 버튼으로 바뀌는 전역 변수
max_output_tokens = 100  # 답변 길이 상한. 작으면 답이 중간에 잘릴 수 있음
stores = []  # 응답 ID를 쌓는 리스트

def get_response(message):
    response = client.responses.create(
      model="gpt-4o-mini",  # 사용한 모델
      input=message,  # 이번 턴 문장 하나만 보냄
      instructions=instructions,
      temperature=temperature,
      max_output_tokens=max_output_tokens,
      store = True,  # 서버에 응답을 저장해야 다음 호출에서 참조 가능
      previous_response_id = None if len(stores) == 0 else stores[-1]  # 첫 턴은 None, 이후엔 직전 응답 ID로 문맥을 이어 붙임
    )
    stores.append(response.id)  # 이번 응답 ID를 다음 호출용으로 저장
    return response.output_text  # 답변 텍스트(str)
```
