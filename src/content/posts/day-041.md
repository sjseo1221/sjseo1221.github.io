## 오늘 배운 것

- NumPy로 데이터를 생성하고, 학습용·테스트용 데이터로 나누는 과정을 실습함.
- scikit-learn의 `LinearRegression`으로 모델을 학습하고 예측값을 구함.
- 네 가지 회귀 평가 지표를 계산하고, 산점도에 예측 직선을 함께 표시함.

## 핵심 개념

### 선형 회귀 실습 구성

정수 데이터 `X`에 정규분포 난수를 더해 `y`를 만들고, 두 데이터의 관계를 학습하는 선형 회귀 실습을 진행함. 학습 후에는 모델의 계수와 절편을 확인함.

### 학습 데이터와 테스트 데이터

전체 데이터를 학습용 70%, 테스트용 30%로 나누어 사용함. 학습 데이터로 모델을 학습하고, 테스트 데이터에 대한 예측값으로 평가 지표를 계산함.

### 모델 평가와 시각화

MAE, MSE, RMSE, R2-score를 계산해 모델을 평가함. 학습·테스트 데이터의 산점도와 예측 직선을 함께 그려 데이터와 예측의 관계를 확인함.

## 배운 문법

### 난수 시드 설정과 정수 데이터 생성

`np.random.seed()`로 난수 시드를 설정함. `np.random.randint(0, 30, 200)`으로 0 이상 30 미만의 정수 200개를 생성함.

```python
np.random.seed(42)
X = np.random.randint(0, 30, 200)
```

### 정규분포 난수와 배열 크기

`X.size`로 원소 개수를 확인하고, 같은 개수의 정규분포 난수를 생성함. 생성한 난수를 `X`에 더해 `y`를 구성함.

```python
y = X + np.random.normal(size=X.size)
```

### 데이터 분할과 여러 변수에 결과 할당

`train_test_split()`의 `test_size=0.3`으로 테스트 데이터 비율을 지정함. 반환된 네 결과를 학습용 특성, 테스트용 특성, 학습용 라벨, 테스트용 라벨 변수에 나누어 저장함.

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
```

### 산점도와 범례 표시

`plt.scatter()`로 학습 데이터와 테스트 데이터를 각각 표시함. `label`로 이름을 지정하고 `plt.legend()`로 범례를 표시한 뒤 그래프를 출력함.

```python
plt.scatter(X_train, y_train, label="train")
plt.scatter(X_test, y_test, label="test")
plt.legend()
plt.show()
```

### 모델 생성과 입력 형태 변환·학습

`LinearRegression()`으로 모델을 생성함. `reshape(-1, 1)`로 학습용 특성을 한 열의 2차원 배열로 바꾼 뒤 `fit()`에 전달함.

```python
model = LinearRegression()
model.fit(X_train.reshape(-1, 1), y_train)
```

### 모델 속성 확인과 f-string 출력

`coef_`와 `intercept_`로 학습한 계수와 절편을 확인함. f-string 안에 속성값을 넣어 설명과 함께 출력함.

```python
print(f"Coefficient : {model.coef_}")     # 모델의 coefficient
print(f"Intercept : {model.intercept_}")  # 모델의 intercept
```

### 테스트 데이터 예측

테스트용 특성도 `reshape(-1,1)`로 형태를 변환함. 학습한 모델의 `predict()`로 예측값을 구해 `y_pred`에 저장함.

```python
y_pred = model.predict(X_test.reshape(-1,1))
```

### 회귀 평가 지표 계산

실제값 `y_test`와 예측값 `y_pred`를 각 평가 함수에 전달함. MAE, MSE, RMSE, R2-score를 계산해 f-string으로 출력함.

```python
print(f"MAE : {mean_absolute_error(y_test, y_pred)}")
print(f"MSE : {mean_squared_error(y_test, y_pred)}")
print(f"RMSE : {root_mean_squared_error(y_test, y_pred)}")
print(f"R2-score : {r2_score(y_test, y_pred)}")
```

### 그래프 제목과 예측 직선 표시

`plt.title()`로 제목을 지정하고, `plt.plot()`으로 테스트 특성과 예측값을 연결함. `c='red'`와 `linestyle='--'`로 예측 직선을 빨간색 파선으로 표시함.

```python
plt.title("Linear Regression")
plt.scatter(X_train, y_train, label="train")
plt.scatter(X_test, y_test, label="test")
plt.plot(X_test, y_pred, label="Line of Best Fit", c='red', linestyle='--')
plt.legend()
plt.show()
```
