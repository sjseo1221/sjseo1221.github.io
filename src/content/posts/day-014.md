## 배운 문법

### CSV 파일 읽기

`pd.read_csv()`로 CSV 파일을 읽어 DataFrame으로 저장함.

```python
df = pd.read_csv("books.csv")
```

### 문자열 포함 여부와 시작 문자 확인

`.str.contains()`로 특정 문자열의 포함 여부를 확인하고, `.str.startswith()`로 시작 문자를 검사함. 저자 이름 검사에서는 `na=False`를 지정해 결측치를 조건에 맞지 않는 값으로 처리함.

```python
q2 = df.loc[df['author'].str.startswith('K', na=False), 'author'].nunique()
```

### 비교 연산과 조건 결합

비교식으로 행 선택 조건을 만들고, `&`로 두 조건을 모두 만족하는 경우를 선택함. `|`는 두 조건 중 하나라도 만족하는 경우를 선택하는 데 사용함.

```python
q3 = ((df['genre']=='Programming') & (df['rating']>=4.3)).sum()
```

### 조건을 만족하는 개수 세기

조건식의 결과에 `.sum()`을 적용해 조건을 만족하는 행의 개수를 계산함.

```python
q4 = ((df['pages']>=250)&(df['pages']<=350)).sum()
```

### `.loc`과 `.iloc`으로 값 선택하기

`.loc`으로 조건이나 인덱스에 해당하는 행과 열을 선택하고, `.iloc`으로 위치에 해당하는 값을 선택함. 아래 코드에서는 저자가 일치하는 행의 제목 중 첫 번째 값을 가져옴.

```python
q7 = df[df['author']=='Mark Wilson']['title'].iloc[0]
```

### 중복을 제외한 값의 개수 확인

`.nunique()`로 중복을 제외한 값의 개수를 계산함. 이름이 `K`로 시작하는 행을 고른 뒤 저자 수를 계산하는 데 사용함.

```python
q2 = df.loc[df['author'].str.startswith('K', na=False), 'author'].nunique()
```

### 여러 후보 값과 일치하는지 확인

`.isin()`으로 값이 지정한 목록에 포함되는지 확인함. 2019년 또는 2021년에 해당하는 책의 수를 계산함.

```python
q10 = df['year'].isin([2019, 2021]).sum()
```

### 평균과 반올림

`.mean()`으로 평균을 계산하고, `.round(2)`로 소수점 둘째 자리까지 반올림함.

```python
q5 = df[(df['year']>=2020)&(df['genre']=='AI')]['rating'].mean().round(2)
```

### 그룹별 평균과 최댓값의 인덱스 찾기

`.groupby()`로 장르별 데이터를 묶은 뒤 평균을 계산함. 집계 결과에 `.idxmax()`를 적용해 평균이 가장 큰 장르를 선택함.

```python
q6 = df.groupby('genre')['pages'].mean().idxmax()
```

### 문자열 길이와 최댓값 위치 활용

`.str.len()`으로 제목의 길이를 구하고, `.idxmax()`로 가장 긴 제목의 인덱스를 찾음. 해당 인덱스와 `.loc`을 이용해 제목을 가져옴.

```python
q8 = df.loc[df['title'].str.len().idxmax(), 'title']
```

### 작은 값·큰 값 순으로 일부 행 선택

`.nsmallest()`와 `.nlargest()`로 기준 열의 값이 작거나 큰 행을 지정한 개수만큼 선택함. 아래 코드에서는 매출이 높은 두 영화를 고른 뒤 두 번째 제목을 가져옴.

```python
q10 = df.nlargest(2, 'revenue_million')['title'].iloc[1]
```

### 결측치 확인과 개수 계산

`.isna()`로 결측치 여부를 확인하고, `.sum()`으로 결측치 개수를 계산함.

```python
q2 = df['rating'].isna().sum()
```

### 결측치가 있는 행 제거와 행 수 확인

`.dropna()`로 결측치가 있는 행을 제거하며, `subset`을 지정하면 해당 열만 검사함. `len()`으로 제거 후 남은 행의 수를 확인함.

```python
q9 = len(df.dropna(subset=['rating', 'revenue_million']))
```

### 그룹별 행 수와 데이터 크기 확인

`.groupby(...).size()`로 그룹별 행 수를 계산하고, Series의 `.size`로 선택된 데이터의 원소 수를 확인함. 아래 코드에서는 평점이나 매출 중 하나라도 결측치인 영화를 장르별로 세어 가장 많은 장르를 선택함.

```python
q5 = df[df['rating'].isna() | df['revenue_million'].isna()].groupby('genre').size().idxmax()
```

### `if`·`else`로 값 비교하기

`if`·`else`로 두 결측치 개수를 비교해 더 큰 개수를 저장함. 이 코드는 열 이름이 아니라 개수를 저장하므로 문제의 요구와 차이가 있음을 확인함.

```python
if q2 > q3: q4 = q2
else: q4 = q3
```

### 리스트 컴프리헨션과 DataFrame 구성

`range()`와 리스트 컴프리헨션으로 1부터 10까지의 번호를 만들고, `pd.DataFrame()`으로 표를 구성함. 열 이름을 지정해 답안 목록을 새 열에 대입함.

```python
submission = pd.DataFrame([i for i in range(1,11)], columns=['question'])
submission['ans'] = ans
```

### CSV 파일로 저장하기

`.to_csv()`로 DataFrame을 CSV 파일에 저장함. `index=False`를 지정해 인덱스는 파일에 포함하지 않도록 함.

```python
submission.to_csv("submission.csv", index=False)
```
