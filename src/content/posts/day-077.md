## 오늘 배운 것

- ViT는 이미지를 Patch Token으로 바꿔 Transformer Encoder에 넣는 모델이며, 사전학습 모델을 불러와 추론한 뒤 3-클래스 헤드로 교체해 파인튜닝함.

## 이론

### 1. ViT, Transformer, Self-Attention

- ViT는 이미지를 16×16 Patch로 자르고 각 Patch를 Token(768차원 벡터)으로 바꿔 Transformer에 넣음
- 224×224 이미지는 (224÷16)² = 196개 Patch이고, `[CLS]` Token 1개를 더해 총 197개 Token이 됨
- Self-Attention은 각 Token이 다른 모든 Token을 얼마나 참고할지 weight를 계산하고, 그 비율로 정보를 섞음 (`softmax(Q·Kᵀ/√d)·V`)
- ViT에서 Attention weight는 Token 197개 × 197개 표이고, Head 12개라서 층마다 `(1, 12, 197, 197)`임
- Encoder 층 하나는 `LayerNorm → Attention → + (잔차)`, `LayerNorm → MLP(768→3072→768) → + (잔차)`이며 12번 반복됨. 층을 지나도 shape은 `(1, 197, 768)`으로 유지되고 값만 바뀜
- 마지막에 `[CLS]` 벡터(768)를 분류 헤드(`Linear`)에 넣어 클래스별 점수(`logits`)를 얻음

### 2. 추론 vs 학습, logits

- 추론은 순전파만 함. `torch.no_grad()`로 기울기 기록을 끄고, `labels`를 넘기지 않아 손실도 계산하지 않음
- 학습은 `zero_grad → 순전파(loss) → backward → step` 순서로 가중치를 갱신함
- `logits`는 softmax 전 클래스별 원점수(음수 가능, 합이 1 아님)이고, `softmax`를 거치면 합이 1인 확률이 됨

**Q&A**

- 질문: 추론에서도 순전파 → 기울기 → 역전파가 일어나는가, `logits`는 무엇인가?
- 처음 내 이해: 순전파로 기울기를 구하고 정답과의 차이를 보고 역전파하는 것이라고 이해했고, logits가 무엇인지 몰랐음
- 실제로는: 그 흐름은 학습 때의 이야기임. 추론은 순전파만 하고 손실·역전파·가중치 갱신이 없음. logits는 마지막 층이 내는 클래스별 원점수이고, 학습할 때는 logits와 정답으로 loss를 계산해 역전파를 시작함

### 3. 사전학습, 파인튜닝, 백본 고정

- **사전학습**: 대규모 일반 데이터로 모델을 만드는 단계. 우리는 결과물(체크포인트)을 받아 씀
- **파인튜닝**: 사전학습 모델을 내 데이터에 맞게 추가 학습. 보통 백본까지 포함한 전체 학습(풀 파인튜닝)을 가리킴
- **백본 고정**: 백본(`model.vit`)을 잠그고 헤드(`model.classifier`)만 학습 (`requires_grad = False`)

| | 백본 고정 | 풀 파인튜닝 |
|---|---|---|
| 학습되는 부분 | 헤드만 | 백본 + 헤드 |
| 속도·메모리 | 빠르고 가벼움 | 느리고 무거움 |
| 적합한 상황 | 데이터·자원이 적을 때, 빠른 기준선 | 데이터가 충분하고 높은 성능이 필요할 때 |
| 학습률 | 비교적 큼 (1e-3) | 아주 작게 (2e-5) |

4. Beans(콩잎 병) 3-클래스 데이터로 헤드를 교체해 학습: 백본 고정(05번), 풀 파인튜닝(06번)
5. 두 방식 비교와 오분류 이미지 분석

### 핵심 코드

```python
# 추론: 전처리 → 모델 → 점수 → 확률 → 상위 5개
inputs = processor(images=image, return_tensors="pt")   # 이미지(RGB)를 (1, 3, 224, 224) 텐서로
with torch.no_grad():                                   # 추론만 하므로 기울기 기록을 끔
    outputs = model(**inputs)                           # **: pixel_values=... 로 풀어서 전달
probs = torch.softmax(outputs.logits, dim=-1)           # dim=-1: 클래스 축 기준으로 확률화
top_probs, top_ids = torch.topk(probs, k=5, dim=-1)     # 상위 5개의 확률과 클래스 번호
```

```python
# 헤드 교체: 체크포인트에 헤드가 없어서 3개짜리 새 헤드가 만들어짐
model = AutoModelForImageClassification.from_pretrained(
    model_id,
    num_labels=num_labels,            # 헤드 출력 크기(3). 핵심 인자
    id2label=id2label,                # 번호 → 이름 (결과 해석용, 계산에는 영향 없음)
    label2id=label2id,
    ignore_mismatched_sizes=True      # 크기가 다른 헤드가 있어도 에러 없이 새로 만듦 (안전장치)
)
```

```python
# 백본 고정: 잠긴 가중치는 loss.backward()에서 기울기가 계산되지 않음
for param in model.vit.parameters():
    param.requires_grad = False       # 학습에서 제외 (True면 학습)

# True인 것(=헤드)만 옵티마이저에 넘김. 풀 파인튜닝은 model.parameters() 전체 + lr=2e-5
optimizer = torch.optim.AdamW(
    filter(lambda p: p.requires_grad, model.parameters()),
    lr=1e-3                           # 새 헤드는 큰 학습률로 빠르게 학습
)
```
