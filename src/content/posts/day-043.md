순이익 히스토그램을 보고 오른쪽 꼬리가 길고 중앙값이 평균보다 작으며, 오른쪽에 이상치가 있다고 기록함. 연구개발비와 순이익의 산점도에서는 연구개발비가 증가할수록 순이익도 증가하는 경향을, 연구개발비와 마케팅비 사이에서는 큰 상관관계가 보이지 않는다고 기록함.

마케팅비 박스플롯을 그리는 과정에서는 결측치를 제거한 뒤 시각화를 진행함. New York과 Florida의 위쪽에 이상치가 있으며, 평균은 California, Florida, New York 순이라고 메모함. 이러한 해석은 코드 주석에 남긴 관찰이며, 실행 결과나 별도의 평균 계산 결과는 제시되지 않음.

## 배운 문법

### CSV 읽기와 데이터 기본 정보 확인

`pd.read_csv()`로 데이터를 불러오고, `head()`, `shape`, `info()`, `describe()`로 일부 행·크기·열 정보·수치형 통계를 확인함.

```python
df = pd.read_csv("https://raw.githubusercontent.com/dukalee/datasets/refs/heads/main/startups.csv")
df.head()
...
df.shape
...
df.describe()
```

### 그룹별 집계와 반올림

`groupby()`로 주별 데이터를 묶고, `count()`와 `mean()`으로 개수와 평균을 계산함. `agg()`로 두 집계를 한 번에 수행하고 `round(2)`로 소수점 둘째 자리까지 반올림함.

```python
df.groupby('State')['R&D Spend'].count()
df.groupby('State')['R&D Spend'].mean().round(2)

df.groupby('State')['R&D Spend'].agg(['count', 'mean']).round(2)
```

### 상위 데이터 선택과 조건별 개수·비율 계산

`nlargest()`로 연구개발비 상위 10개 행을 선택함. 불리언 인덱싱과 `len()`으로 조건을 만족하는 행의 개수를 구하고, 전체 행 수로 나누어 백분율을 계산함.

```python
q2_1 = df.nlargest(10, 'R&D Spend')['Profit'].mean().round(2)
q2_2 = len(df[df['Marketing Spend']<=0])
q2_3 = round(len(df[df['State']=='New York'])/len(df)*100,2)
```

### 히스토그램과 산점도

`plt.hist()`로 한 변수의 분포를, `plt.scatter()`로 두 변수의 관계를 시각화함. `plt.show()`로 그래프를 표시함.

```python
plt.hist(df['Profit'])
plt.show()
...
plt.scatter(df['R&D Spend'], df['Profit'])
plt.show()
```

### 박스플롯과 범주 이름 지정

`plt.boxplot()`에 주별 데이터를 전달해 분포를 비교함. `tick_labels`로 각 박스에 대응하는 주 이름을 지정함.

```python
plt.boxplot([df_cal['Profit'], df_ny['Profit'], df_fl['Profit']], tick_labels=['California', 'New York', 'Florida'])
plt.show()
```

### 결측치가 있는 행 제거

주별로 데이터를 선택한 뒤 `dropna()`를 적용함. 선택한 데이터에서 결측치가 있는 행을 제거한 결과를 마케팅비 박스플롯에 사용함.

```python
df_cal = df[df['State']=='California'].dropna()
df_ny = df[df['State']=='New York'].dropna()
df_fl = df[df['State']=='Florida'].dropna()
```

### 여러 조건 결합과 행 삭제

`|`로 세 지출 항목의 음수 조건을 결합하고, 불리언 값의 `sum()`으로 해당 행 수를 계산함. 조건에 맞는 행의 `index`를 `drop()`에 전달해 삭제함.

```python
print(((df['R&D Spend'] < 0 ) | (df['Administration'] < 0 ) | (df['Marketing Spend'] < 0 )).sum())
...
df = df.drop(df[(df['R&D Spend'] < 0 ) | (df['Administration'] < 0 ) | (df['Marketing Spend'] < 0 )].index)
```

### 학습·테스트 데이터 분리

`train_test_split()`으로 입력 변수와 예측 대상을 함께 분리함. 테스트 비율은 `0.3`, 난수 시드는 `101`로 설정함.

```python
train_x, test_x, train_y, test_y = train_test_split(df[['R&D Spend','Administration','Marketing Spend','State']], df['Profit'], test_size = 0.3, random_state = 101)
```

### 결측치 확인과 중앙값 대체

`isna().sum()`으로 열별 결측치 수를 확인함. `median()`으로 구한 학습 데이터의 중앙값을 `fillna()`에 전달해 학습·테스트 데이터의 결측치를 채움.

```python
train_x.isna().sum()
...
train_x['R&D Spend'] = train_x['R&D Spend'].fillna(train_x['R&D Spend'].median())
...
test_x['R&D Spend'] = test_x['R&D Spend'].fillna(train_x['R&D Spend'].median())
```

### 사분위수와 IQR 경계 계산

`quantile(0.25)`와 `quantile(0.75)`로 각 수치형 열의 사분위수를 계산함. 두 사분위수의 차이인 IQR을 이용해 하한과 상한을 설정함.

```python
q1 = train_x[['R&D Spend','Administration','Marketing Spend']].quantile(0.25)
q3 = train_x[['R&D Spend','Administration','Marketing Spend']].quantile(0.75)
...
lower = q1 - 1.5 * IQR
upper = q3 + 1.5 * IQR
```

### 열별 범위로 값 제한

`clip()`으로 각 지출 열의 값을 하한과 상한 사이로 제한함. `axis=1`을 지정해 열별 경계값을 적용하고, 테스트 데이터에도 같은 경계를 사용함.

```python
train_x[['R&D Spend','Administration','Marketing Spend']] = train_x[['R&D Spend','Administration','Marketing Spend']].clip(lower, upper, axis=1)
test_x[['R&D Spend','Administration','Marketing Spend']] = test_x[['R&D Spend','Administration','Marketing Spend']].clip(lower, upper, axis=1)
```

### 원-핫 인코딩

`pd.get_dummies()`로 `State`를 정수형 더미 변수로 변환함. `drop_first=True`를 지정해 첫 범주에 해당하는 더미 열은 제외함.

```python
train_x = pd.get_dummies(train_x, columns=['State'], drop_first=True, dtype=int)
```

### 학습·테스트 데이터의 열 맞추기

`reindex()`로 테스트 데이터의 열 구성과 순서를 학습 데이터에 맞춤. 테스트 데이터에 없는 열은 `fill_value=0`으로 채움.

```python
test_x = test_x.reindex(columns=train_x.columns, fill_value=0)
```

### 선형 회귀 모델 학습과 예측

`LinearRegression()`으로 모델을 생성하고 `fit()`으로 학습함. `predict()`로 테스트 데이터의 순이익 예측값을 구함.

```python
lr = LinearRegression()

lr.fit(train_x, train_y)
...
y_pred = lr.predict(test_x)
```

### 회귀 평가 지표 계산

실제값과 예측값을 `mean_squared_error()`, `root_mean_squared_error()`, `r2_score()`에 전달함. 각 지표의 계산값을 `print()`로 출력하도록 작성함.

```python
print(mean_squared_error(test_y, y_pred))
print(root_mean_squared_error(test_y, y_pred))
print(r2_score(test_y, y_pred))
```
