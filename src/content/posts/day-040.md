## 오늘 배운 것

- `y = wx + b`로 입력값을 예측값으로 바꾸고, 기울기와 절편에 따른 직선의 변화를 확인함.
- 오차를 바탕으로 여러 직선을 비교하고, OLS로 선형회귀 모델의 계수를 계산함.
- `LinearRegression` 클래스를 직접 구현하고, MAE·MSE·RMSE·R²로 예측을 평가함.

## 핵심 개념

### 선형식으로 예측하기

공부 시간과 점수, 광고비와 예상 매출의 관계를 `y = wx + b`로 계산함. 코드에서 `x`는 입력값, `w`는 기울기, `b`는 편향으로 사용함.

공부 시간 예제에서는 `w = 10`, `b = 30`으로 설정함. 광고비 예제에서는 `w = 3`, `b = 20`으로 설정하고, 출력할 때 입력과 예측값에 각각 100을 곱해 만원 단위로 표시함.

기울기를 비교하는 코드에서는 절편을 10으로 두고 기울기를 1, 3, 5로 바꿈. 절편을 비교하는 코드에서는 기울기를 2로 두고 절편을 0, 10, 30으로 바꾸어 직선을 그림.

### 오차와 회귀 평가 지표

실제값에서 예측값을 빼 오차를 계산함. 오차를 제곱해 합산하는 SSE와, 제곱한 오차의 평균을 구하는 MSE를 구현함.

실습에서는 다음 네 가지 지표를 함수로 작성함.

- **MAE**는 실제값과 예측값 차이의 절댓값을 평균하여 계산함.
- **MSE**는 실제값과 예측값 차이를 제곱한 뒤 평균하여 계산함.
- **RMSE**는 MSE에 제곱근을 적용하여 계산함.
- **R²**는 실제값의 평균을 기준으로 구한 전체 변동성 `sst`와 예측 오차의 제곱합 `sse`를 이용해 `1 - sse / sst`로 계산함.

R² 함수의 주석에서는 `sst`를 실제값이 평균에서 얼마나 흩어져 있는지 나타내는 값으로, `sse`를 모델이 설명하지 못하는 오차로 정리함.


==#전체 변동성(평균을 빼) sum of squared total==

==`sst = np.sum((y_true - np.mean(y_true))**2) #실제값이 평균에서 얼마나 흩어져있는지!!`==

==#모델이 설명 못하는 오차 sum of squared error==

==`sse = np.sum((y_pred - y_true)**2)`==


==1-sse/sst의 의미==
==sse는 내가 만든 모델의 오차==
==sst는 원래 모델이 갖고 있는 변동성==
==같은 sse이더라도 원래 변동성이 컸으면 내가 만든 모델의 오차가 좀 존재하더라도 그건 잘 만든 모델==
==근데 같은 sse이더라도 원래 변동성이 없는 데이터면 그건 좋지 않은 모델임!!!!!!!==



### 후보 직선 비교와 OLS

동일한 공부 시간 데이터에 대해 `5 * X + 40`, `10 * X + 30`, `15 * X + 20`으로 예측값을 계산하고, 각 모델의 MSE를 비교함.

이후 절편을 30으로 고정하고 기울기를 5부터 15까지 바꾸면서 MSE를 확인함. 후보를 직접 비교하는 방식에 이어 OLS에 필요한 합계를 구하고, 기울기와 절편을 계산함.

계산한 계수로 학습 데이터의 예측값을 구하고, 실제 데이터의 산점도 위에 Line of Best Fit을 겹쳐 그림. 새로운 입력값 6에 대해서도 같은 선형식을 적용함.

두 파일의 절편 계산에는 차이가 있음을 확인함. 예제 파일의 `fit()`은 `self.b`를 구할 때 전역 변수 `w`를 참조하지만, 내 풀이 파일은 해당 인스턴스에서 계산한 `self.w`를 사용함. 예제 파일의 구현을 그대로 사용할 때는 이 차이를 확인해야 함.

## 배운 문법

### 산술 연산으로 선형식 계산하기

곱셈과 덧셈으로 `y = wx + b`를 구현함. 변수에 저장한 기울기·편향·입력값을 이용해 예측값을 계산함.

```python
w = 10 # 기울기
b = 30 # 편향
x = 6 # 입력값

y = w * x + b
```

### `np.array()`와 배열 연산

`np.array()`로 입력값과 실제값을 배열로 생성함. 배열에 곱셈과 덧셈을 적용해 여러 입력의 예측값을 한 번에 계산함.

```python
X = np.array([1, 2, 3,4 ,5])
y = np.array([42, 48, 61, 69, 81])

pred_A = 5 * X + 40
pred_B = 10 * X + 30
pred_C = 15 * X + 20
```

### `np.arange()`로 연속된 입력 생성하기

`np.arange()`로 그래프에 사용할 정수 배열을 생성함. 아래 코드에서는 0부터 7까지의 입력에 같은 선형식을 적용함.

```python

# y = 10x + 30

```

### `for`와 `range()`로 계수 바꾸기

`for`로 리스트의 입력값을 순회하거나, `range()`로 기울기의 후보를 반복함. `range(5, 16)`을 사용해 기울기 5부터 15까지의 MSE를 계산함.

```python
for w in range(5, 16):
  y_pred = w * X + b # b가 30으로 고정되어 있는 관계식
  mse = np.mean((y - y_pred) ** 2)

  print(f"w={w:2d}, MSE={mse:.2f}")
```

### f-string과 출력 형식 지정하기

f-string에 변수나 계산식을 넣어 결과를 표시함. `:2d`로 정수의 출력 폭을 지정하고, `:.2f`로 소수점 아래 두 자리까지 표시함.

### `.size`와 `np.sum()`으로 OLS 계산 준비하기

배열의 `.size`로 데이터 개수를 구하고, `np.sum()`으로 OLS에 필요한 합계를 계산함. 배열끼리의 곱과 `** 2`를 함께 사용해 곱의 합과 제곱합을 구함.

```python
n = X.size

sum_xy = np.sum(X * y)
sum_x = np.sum(X)
sum_y = np.sum(y)
sum_x2 = np.sum( X ** 2)
```

### `np.mean()`과 제곱 연산으로 MSE 계산하기

실제값과 예측값의 차이를 제곱하고 `np.mean()`으로 평균을 구함. 같은 계산을 후보 직선 비교와 모델 평가에 반복해서 사용함.

```python
mse = np.mean((y - y_pred) ** 2)

print(f"MSE : {mse}")
```

### `abs()`로 MAE 계산하기

`abs()`로 오차의 절댓값을 구한 뒤 평균을 반환함. 계산 과정을 `mae()` 함수로 묶어 사용함.

```python
def mae(y_true, y_pred):
  error = abs(y_true - y_pred)
  return np.mean(error)
```

### `np.sqrt()`로 RMSE 계산하기

작성한 `mse()` 함수를 호출한 뒤 `np.sqrt()`로 제곱근을 구함. 계산 결과를 `q3`에 저장함.

```python
def rmse(y_true, y_pred):
  return np.sqrt(mse(y_true, y_pred))
q3 = rmse(y, y_pred)
```

### 함수 정의·반환·키워드 인자

`def`로 예측 함수를 정의하고 `return`으로 계산값을 반환함. 호출할 때 인자 이름을 지정해 입력값과 계수를 전달함.


### 클래스와 `__init__()`으로 상태 초기화하기

`class`로 모델을 정의하고, `__init__()`에서 기울기와 절편을 `None`으로 초기화함. `self`를 통해 인스턴스에 값을 저장함.

```python
class LinearRegression:
  def __init__(self):
    self.w = None
    self.b = None
```

### 인스턴스 속성에 학습 결과 저장하기

`fit()` 내부에서 계산한 계수를 `self.w`와 `self.b`에 저장함. 내 풀이에서는 절편 계산에도 `self.w`를 사용함.

```python
    # 가장 적절한 기울기 w 계산
    self.w = (n * sum_xy - sum_x * sum_y) / (n * sum_x2 - sum_x**2)

    # 절편 b 계산
    self.b = (sum_y - self.w * sum_x) / n
```

### 인스턴스 생성과 메서드 호출

`LinearRegression()`으로 모델 인스턴스를 만들고 `fit()`을 호출해 학습함. `predict()`에서는 저장된 계수를 이용해 예측값을 반환함.

```python
  def predict(self, X):
    return X * self.w + self.b
```
