## 핵심 개념

### 학습 데이터 기준의 전처리

데이터에서 중복 행을 제거한 뒤 입력 특징과 정답을 분리함. 테스트 데이터 비율은 30%, 데이터 분리의 `random_state`는 101로 설정함.

결측치 대체 기준과 이상치 경계는 학습 데이터에서 계산함. 인코더와 스케일러도 학습 데이터에 맞춘 뒤 테스트 데이터에 적용함.

수치형 결측치는 지정한 네 컬럼의 중앙값으로, `oak_aged`의 결측치는 최빈값으로 채움. 이상치는 행을 삭제하지 않고 IQR로 계산한 하한과 상한 안으로 제한함.

### 다중 분류 MLP 구성

입력 특징 수와 클래스 수를 데이터에서 구해 모델에 전달함. 은닉층은 64개와 32개 노드로 구성하고, 각 은닉층에 Batch Normalization, ReLU, Dropout을 배치함.

출력층 크기는 클래스 수에 맞춤. 출력층 뒤에 Softmax를 별도로 추가하지 않고, 모델 출력을 `CrossEntropyLoss`에 전달함. 입력 텐서는 `float32`, 정답 텐서는 `long`으로 구성함.

### 학습·검증과 조기 종료

최대 300회 학습하면서 매 epoch의 학습 손실과 테스트 로더에서 계산한 검증 손실을 기록함. 두 손실 모두 배치별 손실의 합을 해당 로더의 배치 수로 나누어 계산함.

검증 손실이 기존 최저 손실보다 `min_delta` 이상 낮아질 때 가중치를 보관함. 개선되지 않은 횟수가 15회에 도달하면 학습을 멈추고, 보관한 가중치를 복원함.

### 예측과 평가

각 데이터에서 가장 큰 logit의 인덱스를 예측 클래스로 선택함. 정확도, 분류 리포트, 혼동 행렬로 평가하도록 구현함.

새 데이터에도 결측치 처리, 이상치 제한, 인코딩, 스케일링을 적용한 뒤 예측함. 예측한 정수 인덱스는 원래 품종 이름으로 복원함. 실행 출력은 제공되지 않아 실제 정확도나 종료 epoch는 기록하지 않음.

### 함수와 분위수를 이용한 IQR 경계 계산

`def`로 컬럼별 이상치 경계를 반환하는 함수를 정의함. `quantile()`로 구한 1사분위수와 3사분위수의 차이에 1.5를 곱해 하한과 상한을 계산함.

```python
def find_whiskers(data, column):
    Q1 = data[column].quantile(0.25)
    Q3 = data[column].quantile(0.75)
    iqr = Q3 - Q1
    return Q1 - 1.5*iqr, Q3 + 1.5*iqr
```
