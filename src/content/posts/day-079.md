## 오늘 배운 것

- 이미지 인코더와 텍스트 인코더가 합쳐진 CLIP을 (이미지, 상품 설명) 쌍으로 대조학습해 문장 검색을 시도함.
- 라벨은 따로 없고 배치 안의 같은 자리(대각선)가 정답이며, 531개 학습으로는 눈에 띄는 개선이 없었음.

## 이론: 핵심 개념

- **CLIP 구조**: `Bingsu/clip-vit-base-patch32-ko`는 이미지 인코더와 텍스트 인코더가 합쳐진 모델임. 둘 다 512차원 벡터를 만들고, 길이 1로 정규화되어 나와서 내적이 곧 코사인 유사도임 ⭐
- **라벨은 대각선** ⭐: 배치에 B쌍이 있으면 이미지 B장 × 문장 B개의 점수표(B×B)가 나옴. i번째 이미지의 정답은 i번째 문장이므로 라벨은 `[0, 1, ..., B-1]`이면 충분함. 학습은 각 행에서 대각선 점수가 가장 크게 만드는 것임
- **손실의 감각**: 모델이 `return_loss=True`로 이미지→문장, 문장→이미지 두 방향 손실의 평균을 계산해 줌. 찍으면 `ln B`(4쌍은 약 1.386, 64쌍은 약 4.16)이고, 4쌍 예시에서 대각선이 압도적으로 커서 손실이 0.009였음
- **검색 원리**: 카탈로그 이미지 71장을 미리 벡터로 만들어 두고, 질의 문장 벡터와 내적해 높은 순서로 나열함. 점수는 확률이 아니라 코사인 유사도임

### ① 데이터 → 배치

`pairs`, `processor`, `train_ds`의 출처임.

```python
MODEL_ID = "Bingsu/clip-vit-base-patch32-ko"         # 한국어·영어 CLIP (이미지 인코더 + 텍스트 인코더)
processor = CLIPProcessor.from_pretrained(MODEL_ID)  # 모델과 같은 ID로 불러서 짝을 맞춤 (문장→input_ids, 이미지→224x224)
pairs = pd.read_csv("data/pairs.csv")                # 한 행 = 이미지 1장 + 캡션 1개, split 열이 train/val/test

class FashionPairs(Dataset):
    def __init__(self, df, root="data", deterministic=False):
        # 상품(item_id)별로 묶어 (이미지 경로, 캡션 리스트) 1항목으로 만듦 → len은 쌍 수가 아니라 상품 수
        self.items = [(g.image_path.iloc[0], list(g.caption)) for _, g in df.groupby("item_id", sort=True)]
        self.root, self.deterministic = Path(root), deterministic
    def __len__(self):
        return len(self.items)
    def __getitem__(self, i):
        image_path, captions = self.items[i]
        # 학습: 꺼낼 때마다 캡션을 무작위로 하나 → 같은 이미지가 한 배치에 두 번 들어가는 모순 방지
        # 검증(deterministic=True): 항상 첫 캡션 → 매번 같은 값이라 점수 비교 가능
        caption = captions[0] if self.deterministic else random.choice(captions)
        image = Image.open(self.root / image_path).convert("RGB")   # 3채널로 통일
        return image, caption

def collate(samples):
    images, captions = zip(*samples)   # (이미지, 문장) 묶음을 이미지끼리/문장끼리로 뒤집음
    # padding=True: 배치에서 가장 긴 문장에 맞춰 뒤를 패딩(attention_mask로 표시), max_length=77: CLIP 텍스트 최대 길이
    return processor(text=list(captions), images=list(images), return_tensors="pt", padding=True, truncation=True, max_length=77)

train_ds = FashionPairs(pairs[pairs.split == "train"])                    # 학습: 캡션 무작위
val_ds = FashionPairs(pairs[pairs.split == "val"], deterministic=True)    # 검증: 첫 캡션 고정
```

### ② 학습

`train_ds`, `collate`는 ①에서 옴.

```python
device = "cuda"
CFG = dict(epochs=8, batch_size=64, lr=1e-5, weight_decay=0.1)   # lr이 작은 이유: 이미 학습된 모델을 조금만 고치는 파인튜닝
train_loader = DataLoader(train_ds, batch_size=CFG["batch_size"], shuffle=True,
                          drop_last=True, collate_fn=collate)    # drop_last: 남는 작은 배치를 버려 매번 64×64 표 유지
model = CLIPModel.from_pretrained(MODEL_ID).to(device)           # 셀을 다시 돌려도 항상 사전학습 상태에서 출발

def compute_loss(model, batch, device):
    batch = {k: v.to(device) for k, v in batch.items()}
    return model(**batch, return_loss=True).loss   # TODO 1 ⭐ return_loss=True가 없으면 loss가 None. .item()으로 꺼내지 말고 텐서 그대로(기울기 연결)

# optimizer는 위에서 새로 불러온 model의 가중치를 잡으므로 model 로드 뒤에 만들어야 함
optimizer = torch.optim.AdamW(model.parameters(), lr=CFG["lr"], weight_decay=CFG["weight_decay"])
total_steps = CFG["epochs"] * len(train_loader)   # 531상품 → 8 step/epoch × 8 = 64 step
warm = max(1, int(0.1 * total_steps))             # 처음 10%는 학습률을 서서히 올림(사전학습 가중치를 갑자기 흔들지 않으려고)
scheduler = torch.optim.lr_scheduler.LambdaLR(optimizer, lambda s: min((s + 1) / warm, max(0.0, (total_steps - s) / max(1, total_steps - warm))))

for epoch in range(1, CFG["epochs"] + 1):   # CFG["epochs"]=8 → epoch 1~8
    model.train()                           # val_loss가 평가 모드로 바꿔 놓으므로 epoch마다 학습 모드 복귀
    for batch in train_loader:
        optimizer.zero_grad()                       # TODO 2 ⭐ 기울기는 누적되므로 매 step 초기화
        loss = compute_loss(model, batch, device)   # 이 배치를 얼마나 못 맞혔는지
        loss.backward()                             # 어느 가중치가 얼마나 틀렸는지(기울기) 계산
        optimizer.step()                            # 가중치를 실제로 고침
        scheduler.step()                            # step마다 학습률 갱신 (optimizer.step() 다음에)
```
