## 오늘 배운 것

- 웹캠 프레임을 한 장씩 읽어 YOLO11에 넣고, 결과를 그려 화면에 띄우는 루프를 실습함.
- 핵심은 "열기 → (읽기 → 추론 → 그리기 → 표시) 반복 → 해제" 구조임.

## 실습 흐름

1. 모델 로드(`YOLO`) → 2. 카메라 열기(`VideoCapture`) → 3. 프레임 루프(읽기·추론·plot·imshow) → 4. q 입력 시 종료 → 5. 자원 해제(`release`)

## 핵심 코드

```python
import cv2
from ultralytics import YOLO

def run_detection_webcam(model_path="yolo11n.pt", camera_index=0, conf_threshold=0.5):
    # yolo11n = nano. 가장 작고 빨라서 CPU에서도 실시간에 가까움 (n<s<m<l<x 순으로 정확↑ 속도↓)
    webcam_model = YOLO(model_path)

    # 카메라 연결 객체. 내장 웹캠은 보통 0번, 외장은 1, 2...
    cap = cv2.VideoCapture(camera_index)

    # 카메라가 없거나 다른 앱이 점유 중이면 여기서 바로 원인을 알리려고 확인함
    if not cap.isOpened():
        raise RuntimeError(f"카메라 {camera_index}번을 열 수 없습니다.")

    try:  # 어떻게 끝나든(q, 에러, Ctrl+C) finally 정리 코드를 보장하려고 사용
        while True:
            # ret: 읽기 성공 여부, frame: BGR 순서의 NumPy 배열 (RGB 아님)
            ret, frame = cap.read()
            if not ret:
                break  # 연결이 끊기면 빈 프레임으로 계속 돌지 않게 탈출

            # conf: 신뢰도 0.5 미만 탐지는 버림. 낮추면 오탐↑, 높이면 놓침↑
            # verbose=False: 프레임마다 찍히는 로그 억제
            # [0]: 결과가 이미지별 리스트로 오기 때문에 첫 장만 꺼냄
            result = webcam_model(frame, conf=conf_threshold, verbose=False)[0]

            # 박스·클래스명·신뢰도를 프레임 위에 그린 BGR 배열 반환 → imshow에 바로 사용 가능
            annotated = result.plot()

            # 같은 창 제목으로 반복 호출하면 새 창이 아니라 내용만 갱신됨 → 영상처럼 보임
            cv2.imshow("YOLO11 Object Detection", annotated)

            # 1ms 키 입력 대기 + 창을 실제로 다시 그리는 역할 (없으면 창이 멈춤)
            # & 0xFF: OS별로 붙는 상위 비트를 제거해 ord("q")와 정확히 비교
            if cv2.waitKey(1) & 0xFF == ord("q"):
                break
    finally:
        cap.release()            # 카메라 점유 해제 (안 하면 다른 앱이 못 씀)
        cv2.destroyAllWindows()  # OpenCV 창 닫기

run_detection_webcam(model_path="yolo11n.pt", conf_threshold=0.5)
```

## 헷갈리기 쉬운 포인트 (보충)

- `numpy`, `matplotlib` import는 이 코드에서 쓰이지 않음. 노트북에서 `plt.imshow`로 볼 때 쓰던 흔적이라 지워도 동작 동일함
- OpenCV 이미지는 **BGR** 순서임. `matplotlib`으로 띄울 때는 RGB로 변환이 필요함
- `waitKey`는 단순 키 입력용이 아니라 `imshow` 창을 갱신하는 데도 필요함. q 입력은 터미널이 아니라 **영상 창을 선택한 상태**에서 눌러야 함
- `yolo11n.pt`가 로컬에 없으면 첫 실행 때 자동 다운로드됨. COCO 80개 클래스(사람·자동차·컵 등)를 인식함
- 특정 클래스만 탐지하려면 `classes=[0]` 옵션 사용 (0번이 person)
