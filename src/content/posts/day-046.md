## 핵심 개념

### 공부 시간과 통과 여부의 관계

`studies.csv`에서 `hours_studied`를 입력값으로, `passed`를 예측 대상으로 사용함. 데이터의 기본 정보와 수치형 통계 요약을 확인하고, 두 변수의 관계를 산점도로 살펴보는 실습을 진행함.

### Logistic Regression과 경사하강법

가중치 `w`와 절편 `b`로 계산한 값에 시그모이드 함수를 적용하여 예측 확률을 구함. 가중치와 절편을 모두 `0.0`으로 초기화하고, 학습률 `0.1`로 1,000회 반복하여 조정하도록 구현함.

예측값과 실제값의 차이를 이용해 두 매개변수의 편미분을 계산하고, 학습률을 곱한 만큼 빼는 방식으로 갱신함.

### 확률 예측과 분류 결과

`predict_proba()`는 시그모이드를 적용한 확률을 반환하도록 구현함. `predict()`는 기본 기준값인 `0.5` 이상을 1로, 그 미만을 0으로 변환하도록 구현함.

### 시각화와 모델 평가

실제 데이터를 산점도로 표시하고, 같은 입력에 대한 예측 확률을 빨간색 선으로 함께 그리도록 작성함.

학습에 사용한 `X`를 다시 예측하여 혼동행렬, 정확도, 분류 리포트를 구함. 별도의 평가 데이터로 분리하는 코드는 포함되지 않음.

### 클래스와 인스턴스 속성 정의하기

```python
class LogisticRegression:

  def __init__(self):

```

### 시그모이드 함수 구현하기

메서드의 반환식에서 `np.exp()`를 사용하여 시그모이드 함수를 구현함.

```python
  def sigmoid(self, z):
    return 1 / (1 + np.exp(-z))
```

### 학습 설정과 데이터 개수 확인하기

학습률과 반복 횟수를 변수로 지정하고, `X.size`로 데이터의 총개수를 구함.

```python
    lr = 0.1 # 학습률
    epochs = 1000 # epoch
    n = X.size # 데이터 n의 총 개수
```

### 반복문으로 예측 계산하기

`range(epochs)`를 사용하여 정해진 횟수만큼 반복함. 각 반복에서 현재 가중치와 절편으로 계산한 값을 시그모이드 함수에 전달함.

```python
    for epoch in range(epochs):
      z = self.w * X + self.b # 방정식
      y_pred = self.sigmoid(z) # 예측
```

### 편미분 계산과 매개변수 갱신하기

`np.sum()`으로 오차에 관련된 항을 합산하여 편미분을 계산함. `-=` 연산자로 학습률과 편미분을 곱한 값을 기존 매개변수에서 뺌.

```python
      dw = (1/n) * np.sum((y_pred - y) * X)
      db = (1/n) * np.sum(y_pred - y)

      #학습률 만큼 조정
      self.w -= lr * dw
      self.b -= lr * db
```

### 확률 반환과 정수형 분류값 만들기

기본 매개변수 `threshold = 0.5`를 지정하여 분류 기준을 설정함. 비교 연산의 결과를 `.astype(int)`로 정수형으로 변환함.

```python
  def predict_proba(self, X):
    return self.sigmoid(self.w * X + self.b)

  def predict(self, X, threshold = 0.5):
    return (self.predict_proba(X) >= threshold).astype(int)
```

### 모델 생성과 학습·예측 메서드 호출하기
