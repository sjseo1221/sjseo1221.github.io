원소별 곱셈인 `*`와 행렬 곱셈인 `@`를 서로 다른 연산으로 다룸.

### 축별 집계와 조건 처리

조건에 맞는 원소만 추출하는 방식과 조건에 따라 값을 바꾸는 방식을 각각 실습함. 3의 배수 추출, 합격 여부 분류, 음수를 0으로 바꾸는 문제에 적용함.

### 난수 생성과 표본 추출

## 배운 문법

### `np.arange()`로 범위 배열 생성

시작값, 끝값, 간격을 지정해 배열을 생성함. 끝값은 포함하지 않으므로 1부터 20까지의 범위를 다루기 위해 끝값을 21로 지정함.

```python
print(np.arange(1,21,3))
```

### `np.full()`과 `np.linspace()`로 배열 생성

`np.full()`로 지정한 모양을 같은 값으로 채움. `np.linspace()`로 시작값과 끝값 사이를 지정한 개수만큼 균일하게 나눔.

```python
np.full([5,5],7)
...
np.linspace(0,100,11)
```

### `np.array()`와 `.dtype`

`np.array()`로 리스트를 배열로 변환함. 정수 배열과 실수 배열을 각각 만든 뒤 `.dtype`으로 자료형을 확인함.

```python
a = np.array([1, 2, 3])
b = np.array([1.0, 2.0, 3.0])
print(a.dtype)
print(b.dtype)
```

### `.shape`, `.ndim`, `.size`

`.shape`으로 배열의 모양, `.ndim`으로 차원 수, `.size`로 전체 원소 수를 확인함.

```python
scalar = np.arange(24)
print(scalar.shape)
print(scalar.ndim)
print(scalar.size)
```

### 음수 인덱스와 다차원 슬라이싱

음수 인덱스로 배열 끝에서부터 구간을 선택함. 다차원 배열에서는 쉼표로 행과 열의 선택 범위를 구분함.


```python
print(m[-3:])   # 뒤에서 3번째 위치부터 끝까지
mat[:,1]        # 가운데 열
mat[-2:,-2:]    # 오른쪽 아래 2×2
```
> ⭐ print(m[-3:])   # 뒤에서 3번째 위치부터 끝까지


### `reshape()`, `np.transpose()`, `flatten()`

`reshape()`으로 모양을 바꾸며, 한 차원을 `-1`로 지정해 크기를 자동으로 계산하게 함. `np.transpose()`로 전치하고 `flatten()`으로 1차원 배열을 만듦.
> ⭐ 한 차원을 `-1`로 지정해 크기를 자동으로 계산

```python
m = m.reshape(4,4)
np.transpose(m)
...
m = m.reshape(2,-1)
...
m = m.flatten()
```

### 배열의 원소별 산술 연산

배열끼리 곱해 각 원소를 제곱함. 배열과 수의 곱셈·나눗셈·덧셈을 조합해 모든 원소에 온도 변환 공식을 적용함.

```python
m = np.arange(1,6)
print(m*m)
...
numbers = np.array([0,10,20,30,40])
print(numbers*9/5 + 32)
```

### `np.zeros()`와 브로드캐스팅 덧셈

`np.zeros()`로 0으로 채운 배열을 생성함. `(4, 3)` 배열에 원소가 3개인 배열을 더해 각 행에 같은 열별 값을 적용함.

```python
zero_numbers = np.zeros((4,3))
#print(numbers)
numbers = np.array([1,2,3])
print(zero_numbers+numbers)
```

### 평균·최댓값·최솟값·표준편차

배열의 `.mean()`, `.max()`, `.min()`, `.std()`를 호출해 점수의 요약 통계를 계산함.

```python
scores = np.array([88,72,95,60,79])
print(scores.mean())
print(scores.max())
print(scores.min())
print(scores.std())
```

### 축 지정과 `argmax()`

`mean(axis=1)`로 학생별 평균을, `mean(0)`으로 과목별 평균을 계산함. 학생별 평균에 `argmax()`를 적용해 가장 높은 평균을 가진 학생의 인덱스를 구함.

```python
score = np.array([[80, 90, 70], [60, 85, 95],[100, 75, 88]])
print(score.mean(axis=1)) #학생별
print(score.mean(0))
...
print(score.mean(1).argmax())
```
> ⭐mean(axis=1)`로 학생별 평균, axis=0은 과목별 평균

### 불리언 인덱싱과 나머지 연산

`%`와 비교 연산으로 3의 배수인지 판별함. 이 조건을 배열의 인덱스로 사용해 조건을 만족하는 원소만 추출함.

```python
numbers = np.arange(1,31)
print(numbers[numbers%3==0])
```

### `np.where()`로 조건에 따라 값 선택

조건을 만족할 때와 만족하지 않을 때 사용할 값을 지정함. 점수를 합격 여부로 바꾸거나 음수만 0으로 바꾸는 데 사용함.

```python
score = np.array([45, 88, 60, 92, 55, 70])
score = np.where(score>=60, '합격', '불합격')
print(score)
...
numbers = np.where(numbers<0, 0, numbers)
```

### `np.vstack()`과 `np.split()`

`np.vstack()`으로 두 배열을 세로로 쌓음. `np.split()`으로 배열을 같은 크기의 세 부분으로 나눔.

```python
a = np.array([1, 2, 3])
b =  np.array([4, 5, 6])
np.vstack([a,b])
...
a = np.arange(1,13)
a = np.split(a, 3)
```

### 시드 지정과 중복 없는 무작위 추출

`np.random.seed()`로 시드를 지정함. `np.random.choice()`에 `replace=False`를 전달해 같은 번호를 중복해서 뽑지 않도록 함.

```python
np.random.seed(0)
np.random.choice(np.arange(1,46), 6, replace=False)
```
> ⭐`replace=False` 비복원

### 정수 난수 생성과 `np.sum()`

`np.random.randint(0,2,100)`으로 0 또는 1을 100개 생성함. `np.sum()`으로 값을 합산해 1이 나온 횟수를 계산함.

```python
np.random.seed(7)
numbers = np.random.randint(0,2,100)
print(np.sum(numbers))
```

### `@`로 행렬 곱셈

두 배열 사이에 `@`를 사용해 행렬 곱셈을 수행함. 실행 코드에서는 먼저 정의한 두 2×2 배열을 사용함.

```python
A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])
A@B
```
