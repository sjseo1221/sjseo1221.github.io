## 핵심 개념

### 이미지와 정답의 구성

이미지는 RGB 64×64 크기로 처리하며, 입력 Tensor를 이미지 수·채널·높이·너비 순서로 구성함. 정답은 고양이 0, 강아지 1의 정수 번호로 다룸.

원본 픽셀값을 기준으로 정규화하며, 이미 정규화한 입력에 같은 처리를 중복 적용하지 않도록 함. 이미지 확인 시에는 정규화된 값을 다시 표시용 범위로 변환함.

### CNN의 특징 추출과 분류

모델을 이미지 특징을 추출하는 부분과 두 클래스로 분류하는 부분으로 나누어 구성함. 특징 추출에는 합성곱·ReLU·최대 풀링을 세 차례 사용하고, 분류에는 Flatten·선형 계층·ReLU·Dropout을 사용함.

최종 출력은 클래스별 값 두 개로 구성하며, 이를 정답 번호와 함께 손실 계산에 사용함.

### 학습과 평가의 구분

전체 인덱스에서 20%를 테스트용으로 분리하고, 클래스 비율을 유지하도록 설정함. 학습 데이터는 배치 순서를 섞고, 테스트 데이터는 순서를 섞지 않도록 구성함.

학습에서는 손실을 역전파해 모델을 갱신함. 평가에서는 기울기를 계산하지 않고, 출력에서 가장 큰 값의 위치를 예측 클래스로 선택해 정답과 비교함.

### 예측 파일의 형식 검증

채점용 입력에도 학습 데이터와 같은 변환을 적용함. 예측 시에는 입력 행 순서를 유지하고, 결과를 `label` 열 하나로 저장함.

저장 후 파일을 다시 읽어 100행인지, 값이 정수 0 또는 1인지, 저장된 순서가 메모리의 예측 목록과 같은지 검사함. 선택적 정답 비교 코드는 기본적으로 실행하지 않도록 설정함.
