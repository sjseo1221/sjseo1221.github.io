## 핵심 개념

### XOR 데이터와 MLP 구성

입력은 `(0,0)`, `(0,1)`, `(1,0)`, `(1,1)`의 네 조합이며, 정답은 각각 `0`, `1`, `1`, `0`으로 구성함. 입력과 정답을 실수형 텐서로 만들고, 정답의 형태를 `(4,1)`로 맞춤.

MLP는 입력 노드 2개, 은닉 노드 2개, 출력 노드 1개로 구성함. 두 층의 가중치는 무작위로, 편향은 0으로 초기화함.

### 순전파와 손실 계산

각 층에서 입력과 가중치를 곱하고 편향을 더한 뒤 Sigmoid를 적용함. 역전파에서 사용할 입력과 중간 계산값을 객체의 속성에 저장함.

예측값과 정답의 차이는 이진 교차 엔트로피인 BCE로 계산함. 직접 작성한 손실 함수와 PyTorch에서 제공하는 함수를 각각 사용함.

### 수동 역전파와 매개변수 갱신

학습률은 `1.0`, 반복 횟수는 `1000`으로 설정함. 매 반복에서 순전파, 손실 계산, 역전파, 매개변수 갱신을 차례로 수행함.

### 자동 미분으로 바꾼 학습

가중치와 편향에 기울기 추적을 설정하고, 손실에서 역전파를 호출하는 방식으로 변경함. 매개변수 갱신은 계산 그래프에 기록하지 않으며, 갱신 후에는 기울기를 초기화함.


### 행렬 곱과 내장 Sigmoid

`@`로 행렬 곱을 수행한 뒤 편향을 더함. 자동 미분 버전에서는 직접 정의한 함수 대신 `torch.sigmoid()`를 사용함.

### 로그와 평균을 이용한 손실 함수

`torch.log()`와 텐서 연산으로 각 데이터의 BCE를 계산함. `.mean()`으로 평균 손실을 반환함.

```python
def bce_loss(y_true, y_pred):
  return -(y_true*torch.log(y_pred) + (1-y_true)*torch.log(1-y_pred)).mean()
```

### 경사 하강법의 대입 연산

각 매개변수에서 학습률과 기울기의 곱을 뺀 값으로 속성을 갱신함. 갱신한 네 값을 튜플로 반환함.

```python
def gd(mlp, dw1, db1, dw2, db2, lr):
  mlp.w1 = mlp.w1 - lr * dw1
  mlp.b1 = mlp.b1 - lr * db1
  mlp.w2 = mlp.w2 - lr * dw2
  mlp.b2 = mlp.b2 - lr * db2
```
