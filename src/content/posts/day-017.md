## 오늘 배운 것

- `products.csv`를 읽고 상품의 가격·평점·재고를 조건별로 분석함.
- 최댓값·최솟값에 해당하는 상품 조회, 카테고리별 집계, 분위수를 활용한 개수 계산을 연습함.
- 여러 열을 곱한 파생 열을 만들고, 분석 결과를 표로 정리해 CSV로 저장함.

## 배운 문법

### CSV 파일 읽기

`pd.read_csv()`로 CSV 파일을 읽어 DataFrame으로 저장함.

```python
df = pd.read_csv("products.csv")
```

### 최댓값·최솟값의 인덱스와 `loc`

`idxmax()`와 `idxmin()`으로 최댓값·최솟값의 인덱스를 구하고, `loc`으로 해당 행의 상품명을 선택함.

```python
q1 = df.loc[df["price"].idxmax(), "product_name"]
...
q3 = df.loc[df['stock'].idxmin(), 'product_name']
```

### 여러 조건 결합과 개수 계산

각 조건을 괄호로 묶고 `&`로 결합함. 조건식의 결과에 `sum()`을 적용해 두 조건을 모두 만족하는 상품 수를 계산함.

```python
q2 = ((df['category']=='Electronics')&(df['rating']>=4.0)).sum()
```

### `groupby()`와 그룹별 집계

`groupby()`로 카테고리를 묶고, `mean()`으로 평균 가격을, `size()`로 상품 개수를 계산함. 집계 결과에 `idxmax()`를 적용해 값이 가장 큰 카테고리를 선택함.

```python
q4 = df.groupby('category')['price'].mean().idxmax()
...
q10 = df.groupby("category").size().idxmax()
```

### 조건으로 행 필터링

가격이 100 이하인 행만 추린 뒤, 그 안에서 평점이 가장 높은 상품명을 조회함.

```python
p2 = df[df['price']<=100]
q5 = p2.loc[p2['rating'].idxmax(), 'product_name']
```

### `nsmallest()`와 `iloc`

`nsmallest()`로 평점이 낮은 상품 두 개를 선택함. 상품명 열에서 `iloc[1]`로 두 번째 위치의 값을 가져옴.

```python
q6 = df.nsmallest(2, 'rating')['product_name'].iloc[1]
```

> Q6 오답: nsmallest(2, 'rating')은 가장 낮은 것부터 2개를 정렬해서 주기 때문에 iloc[0]은 1번째로 낮은 상품입니다. 2번째는 iloc[1]이어야 합니다.

### 열끼리 계산하고 파생 열 추가하기

재고와 가격을 곱한 값을 `stock_price` 열에 저장함. 새 열을 기준으로 값이 가장 큰 상품을 조회함.

```python
df['stock_price'] = df['stock']*df['price']
q7 = df.loc[df['stock_price'].idxmax(), 'product_name']
```

### `isin()`으로 여러 값 중 포함 여부 확인하기

`isin()`으로 카테고리가 지정한 목록에 포함되는지 확인함. 결과에 `sum()`을 적용해 해당 상품 수를 계산함.

```python
q8 = df['category'].isin(['Clothing', 'Grocery']).sum()
```

> q8 = df['category'].isin(['Clothing', 'Grocery']).sum()

### `quantile()`로 분위수 구하기

`quantile(0.75)`로 가격의 0.75 분위수를 구함. 해당 기준값을 초과하는 상품만 개수에 포함함.

```python
p75 = df['price'].quantile(0.75)
q9 = (df['price']>p75).sum()
```

> p75 = df['price'].quantile(0.75)

### 리스트 컴프리헨션과 DataFrame 생성

`range()`와 리스트 컴프리헨션으로 1부터 10까지의 번호를 생성함. 번호를 담은 DataFrame을 만들고 분석 결과 목록을 새 열로 추가함.

```python
submission = pd.DataFrame([i for i in range(1, 11)], columns=['question'])
submission['ans'] = ans
```

### CSV 파일로 저장하기

`to_csv()`로 DataFrame을 CSV 파일에 저장함. `index=False`를 지정해 행 인덱스는 파일에 포함하지 않도록 함.

```python
submission.to_csv("submission.csv", index=False)
```
