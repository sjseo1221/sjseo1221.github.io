## 오늘 배운 것

- ResNet은 입력을 그대로 더하는 잔차 연결로 깊이 문제를 풀었고, 전이학습은 ImageNet으로 학습된 ResNet18의 마지막 층만 바꿔 쓰는 방식임.
- 포켓몬 1,025종 분류에서 fc → layer4 순서로 학습해 val 정확도를 61.8%에서 80.1%로 올렸고, 학습한 모델을 웹캠 추론 코드(`main.py`)에 연결함.

## Part 1. 이론

### 합성곱과 풀링

- Conv2d는 합성곱 층이고, 입력 형태는 NCHW(배치, 채널, 높이, 너비) 순서임
- 풀링은 파라미터가 0개이고 특징 맵의 크기만 줄임
- LeNet-5는 채널이 6개와 16개이고, 120과 84는 설계자가 고른 값임. 400은 16×5×5로 계산되는 값임
- AlexNet은 Mini-AlexNet으로 CIFAR-10에 실습했고 SGD(lr 0.01, momentum 0.9, weight decay 5e-4)를 썼음

**Q&A**
- 질문: 풀링은 파라미터 수를 줄이는 층인가?
- 처음 내 이해: 풀링이 파라미터를 줄여 주는 층이라고 생각했음
- 실제로는: 풀링 자체의 파라미터는 0개임. 맵이 작아지면 뒤에 오는 Linear 층의 입력이 줄어서 그쪽 파라미터가 줄어드는 것임

### ResNet의 잔차 학습

- 일반 층은 H(x)를 직접 배우고, 잔차 층은 F(x) = H(x) − x를 배워서 출력을 F(x) + x로 만듦
- 입력 x를 그대로 통과시켜야 할 때 일반 층은 w≈1이 필요하고, 잔차 층은 w≈0이면 됨
- BasicBlock은 conv-bn-relu-conv-bn에 shortcut을 더하고, 더한 뒤에 ReLU를 적용함
- stride가 1이 아니거나 채널 수가 바뀌면 shortcut에 1×1 conv(downsample)를 넣어 크기를 맞춤

**Q&A**
- 질문: 잔차(residual)란 무엇인가?
- 처음 내 이해: 잔차라는 말 자체가 낯설어서 무엇을 가리키는지 몰랐음
- 실제로는: 목표 출력 H(x)에서 입력 x를 뺀 나머지 F(x)임. 층이 "입력과 달라져야 할 부분"만 배우면 되므로, 그대로 통과시키는 것이 w≈0이라는 쉬운 해가 됨

### ResNet18 구조

- 구성은 stem + layer1~4 + avgpool + fc임
- layer마다 BasicBlock이 2개씩이라 블록은 총 8개임
- 전체 파라미터는 11,689,512개이고, layer4가 약 72%를 차지함. fc는 513,000개임
- layer가 넘어갈 때마다 크기는 절반, 채널은 2배가 되어 층당 연산량이 비슷하게 유지됨
- layer1만 stride=1인 이유는 stem이 이미 크기를 4배 줄였기 때문임

**Q&A**
- 질문: layer1~4가 각각 잔차 학습 단위인가, 왜 4단계로 나누는가?
- 처음 내 이해: layer1, 2, 3, 4가 각각 잔차 학습이라고 생각했음
- 실제로는: layer는 stage(묶음)이고 잔차 연결의 단위는 그 안의 block임. 단계마다 크기를 줄이고 채널을 늘리면서 연산량을 비슷하게 맞추려고 나눈 것임

### 백본과 ImageNet 사전학습

- 백본은 특징을 뽑는 몸통이고, 헤드(fc)는 그 특징으로 분류하는 끝부분임
- 사전학습은 ImageNet-1k(1,000개 클래스, 약 128만 장)로 이미 학습한 가중치를 쓰는 것임. 코드에서는 `ResNet18_Weights.IMAGENET1K_V1`로 지정함
- num_classes가 1000이 아니면 사전학습 가중치를 불러올 수 없으므로, 먼저 불러온 뒤 fc를 교체함

**Q&A**
- 질문: 사전학습 가중치는 직접 학습해서 구하는가, 가져와서 쓰는가?
- 처음 내 이해: 내가 직접 학습해서 가중치를 구하는 줄 알았음
- 실제로는: 이미 학습된 가중치를 가져와 씀. 이번 실습에서 학습하는 것은 새로 바꾼 fc와 필요하면 layer4뿐임
- 질문: `resnet18()` 함수는 무엇을 하며, 내려받은 가중치 파일에 구조가 들어 있는가?
- 처음 내 이해: 내려받은 파일에 ResNet18의 모양까지 들어 있다고 생각했음
- 실제로는: `resnet18()`은 torchvision 코드로 구조를 만들어 주는 함수이고, .pth에는 숫자(가중치)만 들어 있음. 이번에는 구조를 직접 구현하지 않고 가져다 쓰는 것임

## Part 2. 실습: 포켓몬 1,025종 ResNet18 전이학습

### 실습 흐름

1. 데이터 준비 → 2. Q1 사전학습 모델 불러오기 → 3. Q2 고정 후 fc 교체 → 4. Q3 fc만 학습 → 5. Q4 layer4+fc 학습 → 6. 사람 얼굴 기준 보정

- 데이터는 `JJMack/pokemon-classification-gen1-9`이고 train 13,188행임. 이미지 열 이름은 `image_data`임
- 라벨은 도감 번호 − 1이고, 이미지는 128×128 흰 배경으로 맞추고 ImageNet의 MEAN/STD로 정규화함
- 증강은 매번 즉석에서 적용함. 좌우 반전 0.5, 회전 ±15°, 크기 0.85~1.15, 밝기 ±30, 흰 테두리를 씀

### train·val·test 3분할

- 강아지·고양이 과제는 train과 test 두 개만 썼고, 포켓몬 실습은 val이 추가됨
- 에폭 수나 학습률 같은 값은 val 결과를 보고 고르고, test는 마지막에 한 번만 봄

### 핵심 코드

```python
# Q1: 사전학습 가중치로 모델을 만듦
model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)
print(model.fc)   # Linear(in_features=512, out_features=1000, bias=True)

# Q2: 먼저 전부 고정한 뒤 fc를 교체함
for p in model.parameters():
    p.requires_grad = False          # 몸통은 ImageNet 특징을 그대로 쓰려고 고정함
model.fc = nn.Linear(model.fc.in_features, NUM_CLASSES)
                                     # 새로 만든 층은 requires_grad=True가 기본이라 fc만 학습됨
model = model.to(device)             # 교체한 뒤에 GPU로 보내야 새 fc도 같이 이동함

# Q3: fc만 학습함
EPOCHS_1 = 5; LR_1 = 1e-3
optimizer = torch.optim.Adam(model.fc.parameters(), lr=LR_1)
                                     # 학습되는 파라미터만 optimizer에 넘김(check_stage가 이를 검사함)
fit(EPOCHS_1, optimizer, "fc만")

# Q4: layer4를 풀고 작은 학습률로 이어서 학습함
EPOCHS_2 = 5; LR_2 = 1e-4            # 이미 좋은 값을 크게 흔들지 않으려고 학습률을 낮춤
for p in model.layer4.parameters():
    p.requires_grad = True
params = list(model.layer4.parameters()) + list(model.fc.parameters())
optimizer = torch.optim.Adam(params, lr=LR_2)
fit(EPOCHS_2, optimizer, "layer4+fc")
```

### 결과

- val top-1은 61.8%에서 80.1%로 올랐고, test는 top-1 78.2% / top-5 89.3%임
- train과 val의 정확도 차이는 약 18.6%p이고, val loss는 아직 내려가는 중이었음
- 사람 얼굴 1,500장(CelebA)으로 클래스별 로짓의 평균과 표준편차를 구해 z-score로 보정함. 특정 포켓몬이 모든 얼굴에 높은 점수를 받는 "허브" 현상을 줄이기 위함임

## Part 3. 학습한 모델을 웹캠에 연결: `main.py`

웹캠 속 얼굴을 찾아 가장 닮은 포켓몬의 사진과 이름을 얼굴 옆에 띄우는 추론 코드임. 코랩에서 학습한 `pokemon_resnet18.pth`를 같은 폴더에 두고 실행함.

### 흐름

1. 체크포인트 로드 → 2. 얼굴 검출 → 3. 학습 때와 같은 전처리 → 4. 로짓 계산과 보정 → 5. 화면에 카드 그리기

### 핵심 코드

```python
ckpt = torch.load(checkpoint_path, map_location="cpu", weights_only=True)
                                       # 이름·그림 bytes·텐서만 들어 있어서 weights_only=True로 안전하게 불러옴
net = resnet18(weights=None)           # 구조는 코드로 만들고, 가중치는 곧 파일에서 덮어쓰므로 None
net.fc = nn.Linear(net.fc.in_features, ckpt["num_classes"])
                                       # 학습 때와 같은 모양의 fc로 바꿔야 state_dict가 들어감
net.load_state_dict(ckpt["model_state_dict"])
net = net.to(device).eval()            # 추론이므로 eval 모드로 둠

# 점수 보정: 학습 때 구한 사람 얼굴 평균·표준편차로 z-score를 만들고 상위 3마리를 고름
z = (logits - logit_mean) / logit_std
values, positions = z.topk(3)          # 도감 번호는 position + 1
```

- 체크포인트에는 가중치 외에 num_classes, input_size, mean, std, class_names, class_types, card_jpegs, logit_mean, logit_std가 함께 들어 있음. 구조는 코드, 숫자는 파일이라는 Part 1의 구분이 그대로 적용됨
- 전처리는 BGR을 RGB로 바꾸고, 흰색 정사각형 캔버스에 얼굴을 올린 뒤 모델 입력 크기로 줄이고 mean/std로 정규화함. 학습 때의 128×128 흰 배경 + ImageNet 정규화와 같은 방식이어야 점수가 맞음
- 예측 줄은 `self.net(self.preprocess(face).to(device))[0]`이고, `@torch.no_grad()`로 기울기 계산을 끔
- 웹캠은 최근 5프레임의 로짓을 평균 내서 결과가 덜 흔들리게 함
- 얼굴 검출은 YuNet을 쓰고, 쓸 수 없으면 OpenCV의 Haar 검출기로 대신함. 가장 큰 얼굴을 골라 25% 여유를 두고 자름
- (보충) 로컬 실행에는 torchvision 설치와 `.pth` 파일 배치가 필요함. 이 실행은 아직 끝내지 못했음
