## 배운 문법

### `torch.tensor()`로 데이터 만들기

중첩 리스트를 텐서로 변환하고, `dtype=torch.float32`로 자료형을 지정함.

```python
# 데이터 준비
X = torch.tensor([[0,0],[0,1],[1,0],[1,1]], dtype=torch.float32)
y = torch.tensor([[0],[1],[1],[0]], dtype=torch.float32)
```

### `nn.Module` 상속과 층 정의

`nn.Module`을 상속한 클래스에서 `super().__init__()`을 호출하고, 선형층과 활성화 함수를 속성으로 등록함.

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 2)
        self.fc2 = nn.Linear(2, 1)
        self.sigmoid = nn.Sigmoid()
```

### `forward()`로 순전파 정의

입력을 선형층과 Sigmoid에 차례로 통과시킨 뒤 최종 값을 반환함.

```python
    def forward(self, x):
        z1 = self.fc1(x)
        a1 = self.sigmoid(z1)
        z2 = self.fc2(a1)
        a2 = self.sigmoid(z2)
        return a2
```

### `nn.BCELoss()`로 손실 계산

손실 함수 객체를 생성하고, 예측 텐서와 정답 텐서를 전달해 손실을 계산함.


### `torch.optim.SGD()`와 `momentum`

`model.parameters()`로 갱신할 파라미터를 전달하고 `lr`로 학습률을 지정함. Momentum 실습에서는 같은 SGD API에 `momentum=0.9`를 추가함.

```python
model_m = MLP()
criterion = nn.BCELoss()

# code here - optimizer 설정
optimizer_m = torch.optim.SGD(model_m.parameters(), lr=1.0, momentum=0.9)
```

### `torch.optim.Adagrad()`

Adagrad 객체에 모델 파라미터와 학습률을 전달함. 개별 학습에서는 학습률을 1.0으로 설정함.

```python
optimizer_a = torch.optim.Adagrad(model_a.parameters(), lr=1.0)
```

### `torch.optim.RMSprop()`

RMSprop 객체를 생성하며 `lr=0.01`과 `alpha=0.9`를 지정함.

```python
optimizer_r = torch.optim.RMSprop(model_r.parameters(), lr=0.01, alpha=0.9)
```

### `torch.optim.Adam()`

Adam 객체에 모델 파라미터를 연결하고 학습률을 0.01로 설정함.

```python
optimizer_adam = torch.optim.Adam(model_adam.parameters(), lr=0.01)
```

### `zero_grad()`·`backward()`·`step()`

손실을 계산한 뒤 기존 기울기를 초기화하고, 역전파로 기울기를 계산한 다음 파라미터를 갱신함.

```python
        y_pred = model(X)
        loss = criterion(y_pred, y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

### `torch.no_grad()`와 `np.where()`

예측 확인 구간을 `torch.no_grad()`로 감싸고, `.T`로 전치한 예측값을 `np.where()`의 조건에 따라 0 또는 1로 변환함. 아래 SGD 예측 코드는 0.5 이상을 1로 처리함.
