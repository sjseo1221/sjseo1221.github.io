## 오늘 배운 것

- pandas의 Series와 DataFrame을 만들고, 행과 열을 선택하는 방법을 익힘.
- 데이터의 구조와 결측 여부를 확인하고, 조건에 맞는 데이터를 추리는 방법을 학습함.
- 기술통계와 정렬부터 행·열 추가 및 삭제, 자료형 변환까지 실습함.

## 핵심 개념

### Series와 DataFrame

Series와 DataFrame을 직접 만들고, 열이나 행을 선택한 뒤 자료형을 확인함. 같은 데이터라도 무엇을 선택하느냐에 따라 다루는 형태가 달라진다는 점을 살펴봄.

### 데이터 구조와 상태 확인

데이터를 불러온 뒤 크기, 열 이름, 자료형, 앞뒤 일부 행을 확인하는 과정을 익힘. `object`는 문자나 여러 종류가 섞인 데이터를 나타낼 수 있다는 점을 기록함.

`info()`의 non-null 정보로 결측 여부를 살펴보고, `describe()`로 통계 요약을 확인하는 방법을 학습함. 실제 출력은 기록되어 있지 않아 데이터의 구체적인 상태나 통계 수치는 제시하지 않음.

## 배운 문법

### 1. `pd.Series()`와 인덱스 지정

`pd.Series()`로 데이터를 만들고, `index`에 원하는 인덱스 값을 지정함. 대괄호에 인덱스 라벨을 넣어 해당 값을 선택함.

```python
names = pd.Series(["손흥민", "메시", "김병지"], index = [10,2,1])
names
names[10]
```

### 2. `pd.DataFrame()`으로 표 만들기

딕셔너리의 키를 열 이름으로, 각 리스트를 열 데이터로 사용해 DataFrame을 생성함.

```python
df = pd.DataFrame({
    "이름" : ["철수", "영희", "민수"],
    "수학" : [90,80,70],
    "국어" : [70,88,92]
})
```

### 3. 열 선택과 `type()`·`.values`·`.str`

`df["이름"]`처럼 열을 선택하고, `type()`과 `.values`로 자료형과 내부 배열을 확인함. 문자열 열에는 `.str` 접근자를 사용하며, 실습에서는 `join("~")`으로 각 문자열의 문자 사이를 연결함.

```python
print(type(name))
print(type(df))

print(name.values, type(name.values))

df["이름"].str.join("~") #문자열에 해당하는 함수 모두 쓸수있다뜻
```

### 4. `.loc[]`와 `.iloc[]`로 행 선택

`.loc[]`는 인덱스 라벨로, `.iloc[]`는 정수 위치로 행을 선택함. 문자열 인덱스를 지정한 DataFrame에서 두 방식으로 첫 번째 행을 선택함.

```python
print(df.loc["네모"])
print(df.iloc[0])
```

### 5. `pd.read_csv()`로 데이터 불러오기

`pd.read_csv()`에 CSV 파일 주소를 전달해 데이터를 불러옴.

```python
df = pd.read_csv("https://raw.githubusercontent.com/dukalee/datasets/refs/heads/main/example_data.csv")
```

### 6. `.shape`·`.dtypes`·`.columns`로 구조 확인

`.shape`로 행과 열의 크기를, `.dtypes`로 열별 자료형을, `.columns`로 열 이름을 확인함.

```python
df.shape

df.dtypes

#object는 문자나 여러 종류 섞인 데이터
df.columns
```

### 7. `.head()`와 `.tail()`로 일부 행 확인

`.head()`는 앞부분을, `.tail()`은 뒷부분을 확인할 때 사용함. 인수를 생략하면 기본 5개 행을 확인하고, 숫자를 전달하면 확인할 행 수를 지정함.

```python
df.head() #상위 5개만 보여줌. default가 5
df.head(3)

df.tail()
df.tail(2)
```

### 8. `.info()`와 `.describe()`로 상태·통계 확인

`.info()`로 열별 자료형과 non-null 개수 등 데이터 상태를 살펴봄. `.describe()`로 통계 요약을 확인함.

```python
df.info()

#non-null 결측치 없음. 모든 데이터 온전히 있음

df.describe()#통계를 요약해줘
```

### 9. 슬라이싱과 여러 행·열 선택

슬라이싱으로 전체 행이나 앞쪽 일부 행을 선택함. `.loc[]`에 행 라벨 목록과 열 이름 목록을 함께 전달해 필요한 부분만 선택함.

```python
df[:]

df[:2]
...
df.loc[[1,3,4],["이름","나이"]]
```

### 10. 조건 필터링과 `&`·`~`

비교식으로 조건에 맞는 행을 추리고, `&`로 여러 조건을 결합함. `~`는 조건을 부정하므로 마지막 식은 나이가 35보다 크지 않은 행을 선택함.

```python
df[df["나이"]>50]

df[(df["나이"]>30)& (df['급여']>50000)]

df[~(df['나이']>35)] #~은 부정의 의미
```

### 11. 최댓값·최솟값·합계·평균·개수 계산

`.max()`, `.min()`, `.sum()`, `.mean()`으로 열의 통계값을 계산하고, 평균에는 `.round(2)`를 연결해 소수 둘째 자리로 반올림함. `.count()`는 결측값을 제외한 값의 개수를 계산함.

```python
df["나이"].max()

df["급여"].min()

df['몸무게'].sum()
```

### 12. 최빈값·빈도·비율·고유값 확인

`.mode()`로 최빈값을, `.value_counts()`로 값별 빈도를 확인하며, `normalize=True`를 지정하면 비율을 구함. `.unique()`는 중복을 제거한 값을, `.nunique()`는 고유값 개수를 확인함.

```python
df['몸무게'].value_counts(normalize=True) #비율을 보여줘

df['나이'].unique() #중복 제거하고 보여줘

df['나이'].nunique() #고유값의 갯수
```

### 13. `.sort_values()`로 정렬

`.sort_values()`는 기본적으로 오름차순 정렬을 수행함. 두 번째 줄의 원문 주석과 달리, `ascending=False`는 내림차순을 지정함.

```python
df['급여'].sort_values() #오름차순

df['급여'].sort_values(ascending=False) #오름차순
```

### 14. 열 추가와 `np.random.randint()`

새 열 이름에 값을 대입해 열을 추가하며, 실습에서는 `None`을 넣은 열도 생성함. `np.random.randint(1, 100, df.shape[0])`으로 행 수만큼 1 이상 100 미만의 정수를 만들어 열에 대입함.

```python
heights = np.random.randint(1, 100, df.shape[0])
heights

df['heights'] = heights
```

### 15. `pd.concat()`으로 행 추가

한 사람의 정보를 담은 딕셔너리 `SJ`를 DataFrame으로 만든 뒤 기존 데이터 아래에 연결함. `ignore_index=True`로 연결 결과의 인덱스를 새로 부여하고, 같은 결과를 두 변수에 함께 대입함.

```python
df_idx = df_added = pd.concat([df, pd.DataFrame([SJ])], ignore_index=True)
```

### 16. `axis=1`로 열 방향 연결

1 이상 100 미만의 정수 8개로 새 DataFrame을 만들고, `pd.concat(..., axis=1)`로 기존 데이터 옆에 연결함.

```python
lucky = pd.DataFrame(np.random.randint(1,100,8), columns=['행운의 숫자'])

new_df = pd.concat([df_idx, lucky], axis=1)
new_df
```

### 17. `.drop()`으로 열과 행 삭제

`.drop()`에 `axis=1`을 지정해 열을 삭제함. 행 삭제에서는 인덱스 라벨 `0`을 지정하고, 반환된 결과를 다시 변수에 대입함.

```python
df_erased = df_added.drop(['NEW', 'heights'], axis = 1) #열기준 삭제
df_erased

df_erased = df_erased.drop(0) #행기준 삭제
df_erased
```

### 18. `.astype()`으로 자료형 변환

`몸무게` 열에 `.astype(str)`를 적용해 문자열로 변환한 뒤 다시 대입함. 변환 후 `.info()`로 자료형을 확인함.

```python
df_erased['몸무게'] = df_erased['몸무게'].astype(str)
df_erased.info()
```
