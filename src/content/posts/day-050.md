## 핵심 개념

### 품종별 분포와 변수 간 관계

알코올 함량 분포를 살펴보며 Cabernet Sauvignon과 Pinot Noir의 평균이 높게 분포한다고 기록함. `proline` 평균은 Cabernet Sauvignon, Pinot Noir, Merlot 순으로 높다고 정리함.

`total_phenols`는 오크통 숙성 여부에 따른 차이가 뚜렷하지 않지만, 품종별 차이는 존재한다고 관찰함.

여러 변수의 관계를 함께 비교하면서 `alcohol`, `total_phenols`, `flavanoids`, `color_intensity`의 품종별 분포가 구별에 도움이 될 것으로 판단함. `flavanoids`가 증가하면 `total_phenols`도 증가하고, `od280_od315`가 증가하면 `hue`도 증가하는 경향을 기록함.

다만 `od280_od315`와 `hue`만 따로 산점도로 확인했을 때는 두 값이 함께 증가하더라도 품종을 구별하기는 어려울 것으로 판단함.

### 학습 데이터 기준의 전처리

중복 행을 제거한 뒤 학습 데이터와 테스트 데이터를 나누고, 결측치 대체·이상치 처리·인코딩·스케일링을 진행함.

수치형 결측치는 학습 데이터의 중앙값으로, `oak_aged`의 결측치는 학습 데이터의 최빈값으로 대체함. 테스트 데이터에도 같은 값을 적용함.

인코더와 스케일러 역시 학습 데이터에 맞춘 뒤 테스트 데이터에는 변환만 적용함.

### IQR 경계로 이상치 제한

학습 데이터의 1사분위수와 3사분위수로 IQR을 구하고, 각 사분위수에서 IQR의 1.5배만큼 떨어진 값을 하한과 상한으로 설정함.

실제 코드는 이상치를 중앙값으로 바꾸는 방식이 아니라, 하한보다 작은 값은 하한으로, 상한보다 큰 값은 상한으로 제한하는 방식으로 작성함.

### 범주별 개수와 비율 집계

`value_counts()`로 품종별 개수를 집계함. `normalize=True`를 지정한 집계도 사용하여 조건에 해당하는 데이터 안에서 품종별 비율을 계산함.

```python
df['variety'].value_counts()
```

### 그룹별 평균과 반올림

`groupby()`로 품종을 나누고 선택한 컬럼들의 평균을 계산함. `round(2)`로 소수점 둘째 자리까지 반올림함.

```python
df.groupby('variety')[['alcohol', 'flavanoids', 'color_intensity']].mean().round(2)
```

### 중앙값과 불리언 마스크

`median()`으로 알코올 함량의 중앙값을 구하고, 중앙값을 초과하는 행만 선택함. 선택된 와인 안에서 품종별 구성 비율을 백분율로 계산함.

```python
median_alcohol = df['alcohol'].median()
mask = (df['alcohol']>median_alcohol)
(df[mask]['variety'].value_counts(normalize=True)*100).round(2)
```

`sns.displot()`으로 품종별 알코올 분포를 나누어 확인함. 평균값을 `pd.DataFrame()`으로 정리한 뒤 `plt.bar()`로 그리거나, `sns.barplot()`의 `hue`로 숙성 여부를 구분하는 방식도 사용함.

`duplicated().sum()`으로 중복 행 수를 확인함. `drop_duplicates()`로 중복 행을 제거한 데이터프레임을 다시 저장함.

```python

df.info()
```

### 학습·테스트 데이터 분리

`train_test_split()`에 특성과 정답을 전달하여 데이터를 나눔. 테스트 비율은 0.3, 난수 기준은 101로 설정함.

```python
x_train, x_test, y_train, y_test = train_test_split(df[float_cols], df['variety'], test_size=0.3, random_state = 101)
```

### 수치형 결측치 확인과 대체

`isna().sum()`으로 컬럼별 결측치 수를 확인함. 선택한 네 컬럼의 학습 데이터 중앙값을 구해 학습·테스트 데이터의 결측치를 함께 대체함.

```python
col_na = ['malic_acid', 'magnesium', 'proanthocyanins', 'hue']
median_value = x_train[col_na].median()

x_train[col_na] = x_train[col_na].fillna(median_value)
x_test[col_na] = x_test[col_na].fillna(median_value)
```

### 범주형 결측치 대체

`mode()[0]`으로 학습 데이터의 최빈값을 선택함. `fillna()`에 같은 값을 전달하여 두 데이터의 `oak_aged` 결측치를 처리함.

```python
mode_value = x_train['oak_aged'].mode()[0]
x_train['oak_aged'] = x_train['oak_aged'].fillna(mode_value)
x_test['oak_aged'] = x_test['oak_aged'].fillna(mode_value)
```

### 사분위수와 이상치 집계

`drop(columns=...)`으로 범주형 컬럼을 제외하고, `quantile()`로 사분위수를 구해 IQR 경계를 계산함. 경계 밖 조건을 `|`로 연결하고, `sum()`으로 컬럼별 개수를 세거나 `any(axis=1).sum()`으로 해당 행 수를 확인함.

```python
q_25 = x_train[float_cols].quantile(0.25)
q_75 = x_train[float_cols].quantile(0.75)

IQR = q_75 - q_25

upper = q_75 + IQR * 1.5
```

### `clip()`으로 값의 범위 제한

`clip()`에 컬럼별 하한과 상한을 전달함. `axis=1`을 지정하여 학습 데이터에서 정한 경계를 두 데이터의 각 컬럼에 적용함.

```python
x_train[float_cols] = x_train[float_cols].clip(lower, upper, axis=1)
x_test[float_cols] = x_test[float_cols].clip(lower, upper, axis=1)
```

### `LabelEncoder`로 범주 인코딩

`LabelEncoder`를 생성하고 학습 데이터에는 `fit_transform()`, 테스트 데이터에는 `transform()`을 적용함. `oak_aged`와 정답인 `variety`는 각각 별도의 인코더로 처리함.

```python
le = LabelEncoder()
x_train['oak_aged'] = le.fit_transform(x_train['oak_aged'])
x_test['oak_aged'] = le.transform(x_test['oak_aged'])
```

### `StandardScaler`로 스케일링

`StandardScaler`를 학습 데이터에 맞추면서 변환함. 테스트 데이터에는 이미 학습한 기준으로 변환만 수행함.

```python
ss = StandardScaler()

x_train = ss.fit_transform(x_train)
x_test = ss.transform(x_test)
```

### 함수·반복문·리스트로 K별 오분류율 수집

```python
    model.n_neighbors = i
```

### KNN 모델 설정·학습·예측

`KNeighborsClassifier()`로 모델을 만들고 `n_neighbors`를 지정함. `fit()`으로 학습한 뒤 `predict()`로 테스트 데이터의 품종을 예측함.
