## 핵심 개념

### 분포를 살펴보는 박스플롯과 히스토그램

박스플롯에서는 상자의 아래선·가운데선·윗선을 각각 25%·50%·75% 지점과 연결해 확인함. 평균과 중앙값, 왜도를 함께 살펴보며 점수 분포를 해석하는 연습을 함.

히스토그램에서는 원본 점수를 구간으로 나누고, 각 구간에 속한 학생 수를 확인함. 성별이나 합격 여부로 분포를 비교할 때는 두 그룹의 구간 경계를 같게 맞춰야 비교 위치가 어긋나지 않음을 확인함.

### 항목별 차이를 비교하는 막대그래프

카페 메뉴별 판매량과 가격을 막대그래프로 비교함. 지난달과 이번 달 판매량은 겹쳐 그리는 방식과 나란히 배치하는 방식으로 각각 비교함.

가격순 비교에서는 정렬한 데이터의 순서와 가로 막대의 표시 위치를 함께 확인함. 판매량 증가율은 증가·감소 여부에 따라 색을 달리해 구분함.

### 두 변수의 관계를 살펴보는 산점도

공부시간을 가로축, 점수를 세로축으로 두고 학생 한 명을 점 하나로 표현함. 출석률은 점 크기에, 합격 여부나 성별은 색상과 점 모양에 연결해 함께 살펴봄.

점이 겹치는 부분은 투명도를 조절해 확인하고, 그룹의 의미를 명확히 보여줄 때는 그룹별로 나누어 그린 뒤 범례로 구분함.

### 전체에서 차지하는 비율을 보는 파이 차트

주문 한 건이 한 행인 데이터에서 메뉴별 주문 수를 집계하고, 전체 주문 중 각 메뉴가 차지하는 비율을 표현함.

일부 메뉴를 제외하고 다시 그리면 남은 주문 수를 기준으로 비율을 다시 계산한다는 점을 확인함.

`pd.read_csv()`로 데이터를 읽고, `head()`로 앞부분을 확인함. 열을 선택한 뒤 `describe()`로 요약 통계를 확인함.

### 박스플롯과 표시 옵션

`plt.boxplot()`에 열 하나 또는 여러 그룹을 담은 리스트를 전달하고, `tick_labels`로 상자별 이름을 지정함. `vert=False`로 가로 방향을 설정하고 `showmeans=True`로 평균을 함께 표시하며, `tick_labels`가 지원되지 않는 버전에서는 주석에 안내된 `labels`로 변경함.

```python
plt.boxplot(df['점수'], tick_labels=['전체 점수'], showmeans=True)   # showmeans=True: 평균을 초록 삼각형으로 표시
```

### 평균·중앙값·왜도 계산

`mean()`, `median()`, `skew()`로 점수의 평균·중앙값·왜도를 계산함. 계산값을 박스플롯의 평균 표시와 중앙값 선을 해석하는 데 활용함.

```python
print('평균:', df['점수'].mean())              # 초록 삼각형 위치 (73.375)
print('중앙값:', df['점수'].median())          # 주황 선 위치 (75.0)
print('왜도:', df['점수'].skew())              # -0.34 → 낮은 점수 쪽 꼬리가 약간 길어 평균이 중앙값보다 낮음
```

### 조건에 맞는 행과 열 선택

`df.loc[조건, 열 이름]`으로 조건에 맞는 행의 특정 열을 선택함. 산점도에서는 `df[조건]`으로 그룹별 행 전체를 선택하는 방법도 사용함.

```python
male   = df.loc[df['성별'] == '남', '점수']    # 남학생 점수 Series
female = df.loc[df['성별'] == '여', '점수']    # 여학생 점수 Series
```

### 비교 결과를 정수로 바꾸고 새 열 만들기

점수 비교 결과를 `astype(int)`로 변환해 합격 여부를 1과 0으로 저장함. `value_counts()`로 각 값의 개수를 확인하고, 파이썬 예약어인 `pass` 대신 `pass_`를 변수명으로 사용함.

```python
df['합격여부'] = (df['점수'] >= 70).astype(int)   # 70점 이상 True→1, 미만 False→0 으로 새 열 저장

```

### 제목·축 이름·화면 출력

`title()`, `xlabel()`, `ylabel()`로 제목과 축 이름을 지정함. 제목과 축 이름은 `show()`보다 먼저 설정함.

### 세로 막대의 색상·폭·겹침과 범례

`plt.bar()`의 `color`에 색 하나 또는 색 리스트를 전달하고, `width`로 막대 폭을 조절함. 같은 위치에 두 번 그릴 때는 먼저 그린 막대가 뒤에 놓이며, `label`과 `legend()`로 각 막대의 의미를 표시함.

```python
plt.bar(df['메뉴'], df['지난달판매량'], width=0.6, color='gray', label='지난달')      # 먼저 그린 막대가 뒤쪽 (넓은 회색)
plt.bar(df['메뉴'], df['이번달판매량'], width=0.3, color='skyblue', label='이번달')   # 나중에 그린 막대가 앞쪽 (좁은 하늘색)
...
plt.legend()                                   # label 이름으로 범례 표시
plt.show()
```

### 가로 막대와 값 정렬

`plt.barh()`로 가로 막대를 그리고, 굵기를 조절할 때는 `height`를 사용함. `sort_values('가격')`으로 원본을 유지한 채 가격 오름차순 데이터를 만들며, 가로 막대에서는 첫 행이 맨 아래에 표시됨을 확인함.

```python
df_sorted = df.sort_values('가격')             # 가격 낮은 순으로 정렬 (원본 df는 그대로)

```

### 숫자 위치 생성과 막대 나란히 배치

`np.arange(len(df))`로 항목별 기준 위치를 만들고, 막대 중심을 폭의 절반만큼 좌우로 이동해 나란히 배치함. `xticks()`로 숫자 위치에 메뉴 이름을 표시하며, 히스토그램에서는 `np.arange()`의 시작값·종료값·간격으로 공통 구간 경계를 생성함.

```python
x = np.arange(len(df))                         # 막대 기준 자리 번호 [0, 1, 2, 3] (글자는 계산이 안 되니 숫자 자리를 직접 만듦)
width = 0.4                                    # 막대 하나의 폭

plt.bar(x - width/2, df['지난달판매량'], width=width, color='gray', label='지난달')     # 기준 자리에서 0.2 왼쪽 (막대 중심 기준)
plt.bar(x + width/2, df['이번달판매량'], width=width, color='skyblue', label='이번달')  # 기준 자리에서 0.2 오른쪽
plt.xticks(x, df['메뉴'])                      # 숫자 자리(0,1,2,3) 아래에 메뉴 이름 표시
```

### 열 단위 계산과 조건부 배열 생성

열끼리 뺄셈과 나눗셈을 적용해 증가율을 계산하고, `np.where(조건, 참일 때 값, 거짓일 때 값)`로 색상이나 조각 분리 거리 배열을 생성함. `axhline()`으로 증가와 감소를 구분할 가로 기준선을 추가함.

```python
df['증가율'] = (df['이번달판매량'] - df['지난달판매량']) / df['지난달판매량']   # (이번달 - 지난달) / 지난달
print(df[['메뉴', '증가율']])

colors = np.where(df['증가율'] >= 0, 'green', 'red')   # 증가(0 이상)는 초록, 감소는 빨강
plt.bar(df['메뉴'], df['증가율'], color=colors)
plt.axhline(0, color='black', linewidth=0.8)    # axhline(axes + horizontal + line): y=0에 가로 기준선
```

### 산점도의 크기·투명도·색상·모양

`plt.scatter()`의 `s`로 점 크기, `alpha`로 투명도, `c`로 색상, `marker`로 점 모양을 지정하며, `s`에 출석률 열을 전달해 학생마다 크기를 달리함. 숫자 열을 `c`에 전달할 때는 `cmap`으로 색상표를 지정하고 `colorbar()`로 숫자와 색의 대응을 표시함.

```python
plt.scatter(df['공부시간'], df['점수'], s=100, alpha=0.5, c='pink', marker='^')   # '^' 세모 / 'o' 원 / 's' 네모 / '*' 별
...
plt.scatter(df['공부시간'], df['점수'], c=df['합격여부'], cmap='coolwarm')   # c에 숫자(0/1) → cmap 팔레트가 색으로 변환 (0 파랑, 1 빨강)
plt.colorbar()                                 # 오른쪽에 "숫자 ↔ 색" 대응 막대 표시
```

### 그룹별 산점도와 범례

### 항목별 개수 집계와 파이 차트 이름표

`value_counts()`로 메뉴별 주문 수를 많은 순서로 집계하고, `plt.pie()`에 전달함. 같은 Series의 `index`를 `labels`로 사용해 주문 수와 메뉴 이름의 순서를 맞춤.

```python
counts = df['메뉴'].value_counts()             # 메뉴별 횟수, 많은 순 → 아메리카노 10, 라떼 6, 에이드 3, 스무디 1

plt.pie(counts, labels=counts.index)           # 같은 Series의 index를 이름표로 → 순서가 자동으로 맞음
```

### 파이 차트의 비율 표시와 조각 꾸미기

`autopct='%1.1f%%'`로 비율을 소수점 한 자리까지 표시하고, `explode`로 조각별 분리 거리를 지정함. `shadow=True`로 그림자를 추가하고, `startangle=90`으로 시작 방향을 12시 방향으로 설정함.

```python

plt.pie(counts, labels=counts.index, autopct='%1.1f%%', explode=explode,
        shadow=True, startangle=90)            # 기본 0도 = 3시 방향, 90도 = 12시 방향
plt.show()
```

### 합계 기준 비율 계산과 Series 필터링

`counts.sum()`으로 전체 주문 수를 구하고 각 메뉴의 주문 수를 나누어 비율을 계산함. 비율 조건을 `np.where()`에 적용해 조각 분리 여부를 정하거나, 불리언 Series로 집계값을 필터링함.

```python
ratio = counts / counts.sum()                  # 0.50, 0.30, 0.15, 0.05 (counts의 index를 그대로 물려받음)

counts_big = counts[ratio >= 0.1]              # True/False Series를 index로 짝지어 10% 이상만 남김 → 스무디 제외
```

### 히스토그램의 구간·범위·테두리·투명도

`plt.hist()`의 `bins`에 구간 개수 또는 경계 배열을 전달하고, `edgecolor`로 테두리, `alpha`로 투명도를 지정함. 표시할 점수 범위는 `range=(60, 100)`처럼 키워드로 지정하며, 그룹 비교에는 같은 경계 배열을 사용함.

```python

bins = np.arange(30, 105, 5)                   # 두 그룹 공통 경계 30, 35, ..., 100 (따로 그리면 그룹마다 구간이 달라져 어긋남)

plt.hist(male,   bins=bins, alpha=0.5, edgecolor='black', label='남학생')   # alpha=0.5: 반투명 → 겹친 부분도 보임
plt.hist(female, bins=bins, alpha=0.5, edgecolor='black', label='여학생')
```

### 히스토그램 반환값 언패킹

`plt.hist()`가 반환하는 값을 `counts`, `edges`, `bars`에 나누어 저장함. 구간별 학생 수와 구간 경계를 각각 출력해 확인함.

