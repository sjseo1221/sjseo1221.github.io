- 서울 자전거 대여 데이터에서 날씨·시간·공휴일·계절별 대여량을 비교하는 EDA를 실습함.
- 조건에 맞는 행을 추린 뒤 평균이나 합계를 구하고, 대여량이 가장 큰 시간·계절·월을 찾는 코드를 작성함.
- 날짜를 일·월·년으로 분리하고, 중복 날짜를 제거해 미운영 일수를 세는 방법을 다룸.
- 실행 결과는 기록에 없으며, 날짜 파생 열을 원본 데이터에 합치는 부분은 주석 처리되어 있어 후속 코드 실행 시 확인이 필요함.

## 핵심 개념

### 비교 대상에 따른 집계 기준

비나 눈이 오는 경우에는 해당 조건의 평균 대여량을 계산하고, 시간대 비교에도 평균을 사용함. 계절과 월을 비교하는 코드에서는 대여량의 합계를 사용함.

공휴일 분석에서는 계산 대상과 그래프의 구분 기준이 서로 다름. 최다 대여 시간 계산은 공휴일 행만 대상으로 하지만, 그래프는 전체 데이터를 계절별로 나누어 그리도록 작성함.

### 날짜 분리와 원본 데이터 연결

날짜 문자열을 나누어 일·월·년을 추출하고, 별도의 `date_split` 데이터프레임을 생성함.

다만 이를 원본 `df`에 연결하는 코드는 모두 주석 처리되어 있음. 제시된 코드만 순서대로 실행하면 `df`에 `month`, `year`, `day` 열이 추가되지 않으므로, 이 열들을 참조하는 월별 집계와 미운영 날짜 조회에서 오류가 발생할 수 있음.

### 결과 확인 범위

평균 대여량, 최다 대여 시간, 최다 대여 계절·월, 미운영 일수를 계산하는 코드를 작성함. 실제 출력은 제공되지 않았으므로 구체적인 결과값이나 가설의 성립 여부는 확정하지 않음.

## 배운 문법

### CSV 읽기와 데이터 일부 확인

`pd.read_csv()`로 데이터를 읽고, `head()`로 앞부분을 확인하도록 작성함.

```python
df = pd.read_csv("https://raw.githubusercontent.com/dukalee/datasets/refs/heads/main/SeoulBikeData.csv")
df.head()
```

### 리스트에 계산 결과 추가

`ans` 리스트에 각 계산 결과를 `append()`로 차례대로 추가함.

```python
ans.append(q1)
```

### 비교 연산과 OR 조건으로 파생 열 생성

강수량이나 적설량이 0보다 큰지를 각각 비교하고, `|`로 연결해 둘 중 하나라도 참인 조건을 만듦. 이 결과를 `Rain_or_Snow` 열에 저장함.

```python
df['Rain_or_Snow'] = ((df['Rainfall(mm)'] > 0) | (df['Snowfall (cm)'] > 0))
df["Date"]
```

### 조건 필터링과 평균·반올림

불리언 조건으로 비나 눈이 오는 행을 선택한 뒤 대여량의 평균을 계산함. `round(2)`로 소수점 둘째 자리까지 반올림함.

```python
q1 = df[df['Rain_or_Snow'] == True]["Rented Bike Count"].mean().round(2)
q1
```

### 그룹별 평균과 최댓값의 인덱스 찾기

`groupby()`로 시간별 데이터를 묶고 평균 대여량을 계산함. `idxmax()`로 평균이 가장 큰 시간의 인덱스를 구함.

```python
q2 = df.groupby("Hour")["Rented Bike Count"].mean().idxmax()
q2
```

### 그룹별 합계 계산

계절별 대여량을 `sum()`으로 합산하고, 합계가 가장 큰 계절을 `idxmax()`로 찾음.

```python
q4_1 = df.groupby("Seasons")["Rented Bike Count"].sum().idxmax()
q4_1
```

`plt.figure(figsize=...)`로 그림 크기를 지정하고, `sns.barplot()`으로 강수·적설 여부에 따른 대여량을 비교하도록 작성함. `plt.show()`로 그래프를 표시함.

### 문자열 분리

문자열 접근자 `.str`과 `split('/')`을 사용해 날짜를 `/` 기준으로 나눔.

```python

date
```

### 분리한 요소 선택과 정수 변환

`.str[0]`, `.str[1]`, `.str[2]`로 날짜의 각 요소를 선택함. `astype(int)`로 정수형으로 변환하고 `print()`로 확인하도록 작성함.

```python

month = date.str[1].astype(int)
year = date.str[2].astype(int)
print(day, month, year)
```

### 데이터프레임 생성과 열 추가

`pd.DataFrame()`에 값과 열 이름을 전달해 데이터프레임을 생성함. 이후 대괄호를 사용해 월과 연도 열을 추가함.

```python

date_split["month"] = month
date_split["year"] = year
date_split
```

### 여러 열 선택·중복 제거·행 개수 계산

미운영 행에서 연·월·일 열을 선택하고, `drop_duplicates()`로 같은 날짜를 한 번만 남김. `len()`으로 중복 제거 후의 행 개수를 계산하도록 작성함.

```python

```
