## 핵심 개념

### 시각화로 확인한 데이터의 특징

성적 분포를 살펴보며 0 미만이거나 100을 초과하는 데이터가 있음을 확인함. 공부 시간과 성적의 산점도에는 이상치가 다수 있으며, 공부 시간이 늘어날수록 성적도 조금씩 높아지는 것 같다고 기록함.

하루 평균 공부 시간과 주간 공부 시간은 함께 증가하는 모습을 보여, 같은 정보를 담고 있다고 해석함. 두 공부 시간의 박스플롯에서도 위쪽 이상치가 다수 존재한다고 기록함.

과외활동 참여 여부별 성적은 중앙값이 비슷하지만, 참여한 집단의 제3사분위수가 더 높다고 기록함. 참여한 집단의 위쪽에 이상치가 더 많은 것 같다고 보았으며, 양쪽 모두 0 미만과 100 초과 데이터가 있음을 확인함.

### 전처리 기준과 적용 대상

성적이 0 미만 또는 100 초과인 행과 하루 공부 시간이 0 미만 또는 24 초과인 행을 먼저 제거함. 이후 학습·테스트 데이터를 분리하고, 학습 데이터의 중앙값을 기준으로 두 데이터의 결측치를 채우도록 작성함.

IQR 기준으로 수치형 열의 이상치를 확인한 뒤, 하루 공부 시간과 주간 공부 시간 중 하나라도 기준을 벗어나는 학습 데이터 행을 제거함. 이때 입력 데이터와 정답 데이터에서 같은 인덱스를 삭제함.

## 배운 문법

### CSV 불러오기와 데이터 구조 확인

`pd.read_csv()`로 데이터를 불러오고 `head()`로 앞부분을 확인함. `shape`, `info()`, `describe()`도 사용해 크기, 열 정보, 수치형 통계를 살펴봄.

```python
df = pd.read_csv("https://raw.githubusercontent.com/dukalee/datasets/refs/heads/main/student_performance.csv")
df.head()
```

### 그룹별 평균과 반올림

`groupby()`로 과외활동 참여 여부별 데이터를 묶고, 성적의 평균을 계산함. `round(2)`로 소수점 둘째 자리까지 정리함.

```python
q1 = df.groupby('Extracurricular Activities')['Performance Index'].mean().round(2)
```

### 상위 행 선택과 조건부 조회

`nlargest()`로 공부 시간 상위 10개 행을 선택함. `loc`에는 수면 시간 조건과 조회할 성적 열을 지정함.

```python
q2 = df.nlargest(10, 'Hours Studied')['Performance Index'].mean().round(2)

q3 = df.loc[df['Sleep Hours'] < 6, 'Performance Index'].mean().round(2)
```

### 불리언 조건 결합과 개수 계산

`|`로 두 조건 중 하나라도 만족하는 행을 표시함. 불리언 결과에 `sum()`을 적용해 성적 범위를 벗어난 행의 개수를 계산함.

```python
q4 = ((df['Performance Index'] < 0) | (df['Performance Index'] > 100)).sum()
```

### 여러 집계 함수 적용

`agg()`에 평균과 중앙값을 함께 지정해 그룹별 통계를 한 번에 계산함.

```python
df.groupby('Extracurricular Activities')['Sample Question Papers Practiced'].agg(['mean', 'median']).round(2)
```

### 히스토그램과 산점도

`plt.hist()`로 성적 분포를, `plt.scatter()`로 두 열의 관계를 시각화함. 그래프는 `plt.show()`로 표시함.

```python
plt.scatter(df['Hours Studied'], df['Performance Index'])
plt.show()
```

### 박스플롯

`sns.boxplot()`으로 과외활동 참여 여부별 성적을 비교함. 공부 시간 열들은 `plt.boxplot()`으로 확인함.

```python
sns.boxplot(data=df, x='Extracurricular Activities', y='Performance Index', hue='Extracurricular Activities')
plt.show()
```

### 조건에 맞는 행 삭제

조건에 해당하는 행의 `index`를 구한 뒤 `drop()`으로 삭제함. 성적 범위와 하루 공부 시간 범위를 각각 적용함.

```python
df = df.drop(df[(df['Performance Index']<0)|(df['Performance Index']>100)].index)
df = df.drop(df[(df['Hours Studied']<0)|(df['Hours Studied']>24)].index)
```

### 학습·테스트 데이터 분리

`train_test_split()`에 입력 열과 정답 열을 전달함. 테스트 비율을 0.3, `random_state`를 101로 설정함.

```python
x_train, x_test, y_train, y_test = train_test_split(df[['Hours Studied','Previous Scores','Extracurricular Activities','Sleep Hours','Sample Question Papers Practiced', 'Weekly Study Hours']]
                                                  , df['Performance Index'], test_size=0.3, random_state=101)
```

### 결측치 확인과 중앙값 대체

`isna().sum()`으로 열별 결측치 개수를 확인함. 세 열의 중앙값을 구해 `fillna()`에 전달하며, 테스트 데이터에도 학습 데이터에서 계산한 중앙값을 사용함.

```python
x_train = x_train.fillna(x_train[['Previous Scores','Sleep Hours','Sample Question Papers Practiced']].median())
x_test = x_test.fillna(x_train[['Previous Scores','Sleep Hours','Sample Question Papers Practiced']].median())

(x_train.isna()).sum()
(x_test.isna()).sum()
```

### 분위수와 IQR 경계 계산

`quantile()`로 제1사분위수와 제3사분위수를 구함. 두 값의 차이인 IQR에 1.5를 곱해 상한과 하한을 계산함.

```python
q_25 = x_train[cols].quantile(0.25)
q_75 = x_train[cols].quantile(0.75)

IQR = q_75 - q_25
upper = q_75 + IQR * 1.5
lower = q_25 - IQR * 1.5
```

### 행 단위 조건 판정과 인덱스 동기화

`any(axis=1)`로 두 공부 시간 열 중 하나라도 이상치 조건에 해당하는 행을 찾음. 해당 인덱스를 입력 데이터와 정답 데이터에서 함께 삭제함.

```python
del_cols = ['Hours Studied', 'Weekly Study Hours']
mask = ((x_train[del_cols] < lower[del_cols]) | (x_train[del_cols] > upper[del_cols])).any(axis=1)
del_idx = x_train[mask].index
x_train = x_train.drop(del_idx)
y_train = y_train.drop(del_idx)
```

### 범주형 변수 인코딩

`LabelEncoder`의 `fit_transform()`으로 학습 데이터를 인코딩함. 테스트 데이터는 같은 인코더의 `transform()`으로 변환함.

```python
le = LabelEncoder()
x_train['Extracurricular Activities'] = le.fit_transform(x_train['Extracurricular Activities'])
x_test['Extracurricular Activities'] = le.transform(x_test['Extracurricular Activities'])
```

### 선형 회귀 모델 학습

`LinearRegression()`으로 모델을 생성함. `fit()`에 학습용 입력 데이터와 정답 데이터를 전달함.

```python
lr = LinearRegression()
lr.fit(x_train, y_train)
```

### 테스트 데이터 예측

학습한 모델의 `predict()`에 테스트 입력 데이터를 전달해 예측값을 구함.

```python
y_pred = lr.predict(x_test)
```

### 회귀 평가 지표 계산

실제값과 예측값을 전달해 MSE, RMSE, R²를 계산함. 각 계산값을 `print()`로 출력하도록 작성함.

```python
print(mean_squared_error(y_test, y_pred))
print(root_mean_squared_error(y_test, y_pred))
print(r2_score(y_test, y_pred))
```
