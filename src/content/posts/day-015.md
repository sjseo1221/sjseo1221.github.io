## 오늘 배운 것

- 선수 데이터에서 조건에 맞는 행을 골라 인원수·합계·평균을 구하는 연습을 함.
- 최댓값·최솟값의 인덱스를 이용해 해당 선수의 이름을 조회함.
- 나이가 많은 상위 3명을 먼저 고른 뒤, 그 안에서 메달이 가장 많은 선수를 찾는 단계적 조회를 실습함.

## 핵심 개념

### 조건에 따른 집계

전체 선수와 특정 국가의 선수를 구분해 인원수, 메달 합계, 평균 나이를 계산함. 같은 데이터라도 국가나 메달 수처럼 어떤 조건을 적용하는지에 따라 집계 대상이 달라짐을 확인하는 실습을 함.

### 순위 조건과 최댓값 조건의 구분

전체 선수 중 메달이 가장 많은 선수를 찾는 문제와, 나이 상위 3명 안에서 메달이 가장 많은 선수를 찾는 문제를 구분함. 후자는 먼저 비교 대상을 좁힌 다음 다른 기준으로 선수를 선택하도록 구성함.

## 배운 문법

### `pd.read_csv()`와 `head()`

CSV 데이터를 DataFrame으로 읽고, `head()`로 앞부분을 확인하도록 작성함.

```python
df = pd.read_csv("https://raw.githubusercontent.com/dukalee/pandas_exercises/refs/heads/main/athletes.csv")

df.head()
```

### 조건 비교와 `sum()`으로 개수 계산

열의 값에 비교 연산을 적용한 뒤 `sum()`으로 조건을 만족하는 선수 수를 계산함. 국가 일치 여부뿐 아니라 메달 수가 0인지, 2개 이상인지 확인하는 데도 같은 방식을 사용함.

```python
q2 = (df['country'] == 'South Korea').sum()
q2
```

### 조건 필터링과 열의 합계

국가 조건에 맞는 행을 선택하고, 그중 `medals` 열에 `sum()`을 적용해 메달 총합을 계산함.

```python
q4 = df[(df['country'] == "South Korea")]["medals"].sum()
q4
```

### `idxmax()`와 `loc`으로 최댓값에 해당하는 행 조회

`idxmax()`로 메달 수가 최대인 행의 인덱스를 구하고, `loc`으로 해당 행의 이름을 조회함.

```python
q1 = df.loc[df['medals'].idxmax()]["name"]
q1
```

> ⭐ loc : 라벨(이름) 기준

> ⭐ iloc : 위치(순서 번호) 기준 (integer location)

> ⭐ df.loc[3]    # 라벨이 3인 행 → Daniel Lee

> ⭐ df.iloc[3]   # 위치가 3번째(0부터 센) 행 → Daniel Lee

> ⭐ idxmin()은 위치가 아니라 인덱스 라벨을 반환함

> ⭐ iloc은 위치(순서 번호) 기준입니다.

### `idxmin()`과 `loc`으로 최솟값에 해당하는 행 조회

`idxmin()`으로 나이가 최소인 행의 인덱스를 구한 뒤, 해당 선수의 이름을 선택함.

```python
q5 = df.loc[df['age'].idxmin()]['name']
q5
```


### `.values[0]`과 `print()`

종목 조건에 맞는 선수들의 나이에서 `.values[0]`으로 첫 번째 값을 꺼내고, `print()`로 출력하도록 작성함.

```python
q6 = df[(df['sport']=="Archery")]["age"].values[0]
print(q6)
```

### `mean()`과 `round()`

조건에 맞는 선수들의 평균을 `mean()`으로 계산하고, `round(2)`로 소수점 아래 둘째 자리까지 반올림함. 국가가 다른 선수를 선택할 때는 `!=`를 사용함.

```python
q10 = df[df['country'] != 'South Korea']['medals'].mean().round(2)
q10
```

### `nlargest()`와 `.index`를 이용한 단계적 조회

`nlargest(3)`으로 나이가 많은 상위 3명의 인덱스를 구함. 이 선수들의 메달 수에 다시 `idxmax()`를 적용해 이름을 조회함.

```python
q9 = df.loc[df.loc[df['age'].nlargest(3).index]["medals"].idxmax()]['name']
q9
```

> ⭐ top3 = df.nlargest(3, 'age')#age 기준 상위3명 행 리턴

> ⭐ top3.loc[top3['medals'].idxmax(), 'name']
