### 텐서 생성과 형태 변경

`MLP` 클래스가 `nn.Module`을 상속하도록 작성함. 생성자에서 먼저 `super().__init__()`을 호출함.

### `nn.Linear`와 `nn.Sigmoid`

`nn.Linear()`의 인자로 입력과 출력의 개수를 지정함. 두 선형 계층과 각각에 적용할 Sigmoid를 모델의 속성으로 생성함.

```python
    self.linear1 = nn.Linear(2, 2) # (2,2) 입력2개, 출력 2개
    self.sigmoid1 = nn.Sigmoid()

    # Layer2 (은닉 -> 출력)
```

### `forward()`의 순전파 계산

앞 계층의 계산 결과를 다음 계층에 전달하는 방식으로 순전파를 구현함. 선형 계층에서 가중합을 구하고 활성화 함수를 적용하는 과정을 두 번 수행함.

```python
    z1 = self.linear1(X) # 우리의 입력 데이터가 linear layer -> y = mx + b의 가중합 구하기
    a1 = self.sigmoid1(z1) # 활성화 함수에 가중합 넣기

    z2 = self.linear2(a1)
    a2 = self.sigmoid2(z2)
```

### `nn.BCELoss`

`nn.BCELoss()`의 인스턴스를 생성해 손실 함수로 사용함. 학습 과정에서는 예측값과 정답 텐서를 전달해 손실을 계산함.

```python
criterion = nn.BCELoss() # binary cross entropy
```

### `torch.no_grad()`와 매개변수 갱신

`torch.no_grad()` 안에서 가중치 갱신 연산이 계산 그래프에 기록되지 않도록 함. `model.parameters()`를 순회하면서 각 매개변수에서 학습률과 기울기의 곱을 빼도록 구현함.

```python
def gradient_descent(model, lr):
    with torch.no_grad():
        for p in model.parameters():
            p -= lr * p.grad
```

### 반복 학습과 `model.train()`

`range(epochs)`로 학습을 반복함. 각 반복에서 모델을 학습 모드로 설정하고 입력 텐서를 전달해 예측값을 구함.

```python
for epoch in range(epochs):
    model.train() # 학습 모드
    #1. 순전파
    y_pred = model(x_tensor)           # 학습데이터
```

### 역전파와 기울기 초기화

`loss.backward()`로 역전파를 수행한 뒤 직접 작성한 함수로 가중치를 갱신함. 갱신 후에는 `model.zero_grad()`로 기울기를 초기화함.

```python
    loss.backward()
    #4. gradient descent
    gradient_descent(model, lr) # 가중치 업데이트

    # gradient 초기화
    model.zero_grad()
```

### 평가 모드와 `np.where()`

`model.eval()`로 평가 모드를 설정하고, `torch.no_grad()` 안에서 예측을 수행함. `np.where()`로 예측값이 0.5 이상이면 1, 그렇지 않으면 0으로 변환해 출력함.

```python
model.eval() # train()모드에서 개입되는 parameter 조정을 eval() 모드에서는 건드리지 않는다.

  y_pred = model(x_tensor)
  print(y_pred)
  print(np.where( y_pred >= 0.5, 1, 0))
```
