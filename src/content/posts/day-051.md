## 핵심 개념

### 입력 데이터와 정답, 모델의 절편 구분

첫 실습에서는 입력을 `[10, 4]`, 정답을 `[1]`로 준비함. 코드 주석에서 문제에 적힌 `bias = [1]`은 모델의 절편이 아니라 정답 `Y` 역할이라고 구분함.

모델이 학습하는 절편은 클래스 내부의 `self.bias`이며, 가중치와 함께 0으로 초기화함.

### 단층 퍼셉트론의 예측과 학습

입력과 가중치를 원소별로 곱해 합산한 뒤 절편을 더하여 예측에 사용할 값을 계산함. 이 값이 임계값 50보다 작으면 0, 그렇지 않으면 1을 반환하도록 구현함.

학습에서는 정답에서 예측값을 뺀 오차를 구함. 가중치는 학습률·오차·입력값의 곱만큼, 절편은 학습률·오차의 곱만큼 갱신함. 매 epoch마다 가중치, 절편, 틀린 횟수를 출력하도록 구성함.

### 학습률을 달리한 실험

같은 입력 데이터에 대해 모델을 각각 새로 만들고, 학습률을 0.1, 0.01, 1로 설정하여 모두 5회씩 학습함. 각 모델의 가중치 두 개와 절편을 하나의 DataFrame으로 모아 확인하도록 구성함.

### 논리 게이트와 단층 퍼셉트론의 한계

AND·OR·XOR 실습에서는 두 입력이 각각 0 또는 1인 네 가지 조합을 사용함. 게이트마다 정답 배열을 다르게 준비하고, 학습률 1로 100회씩 학습한 뒤 각 입력의 예측을 출력하도록 구성함.

XOR 실습 코드에는 단층 퍼셉트론으로 XOR을 풀 수 없다는 한계를 주석으로 명시함. 실행 결과는 제공되지 않아 실제 예측값이나 학습 완료 여부를 별도로 단정하지 않음.

### 배열 연산과 `np.sum()`

가중치 배열과 입력 배열을 곱한 뒤 `np.sum()`으로 합산함. 계산한 값에 절편을 더하고, 같은 객체의 `step()` 메서드를 호출함.


### 중첩 반복문과 인덱싱

바깥 반복문은 epoch 횟수만큼, 안쪽 반복문은 입력 데이터 개수만큼 실행함. `len()`으로 데이터 개수를 구하고 `X[j]`로 학습할 입력을 하나씩 꺼냄.

```python
  def fit(self, X, Y, lr, epoch):
    for i in range(epoch):
      errors = 0
      for j in range(len(X)):
        x = X[j]
        y_pred = self.predict(x)
```

### 오차 계산과 누적 대입

정답과 예측값의 차이를 계산하고, `+=`로 가중치와 절편을 갱신함. 오차가 0이 아닌 경우에만 틀린 횟수를 증가시킴.

```python
        error = Y[j] - y_pred
        self.w += lr * error * x
        self.bias += lr * error
        if error != 0:
          errors += 1
```
