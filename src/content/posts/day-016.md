### CSV 불러오기와 데이터 확인

`pd.read_csv()`로 URL의 CSV를 읽어 `df`에 저장함. `head()`와 데이터프레임 자체를 평가하는 식으로 데이터를 확인함.

### 상위 데이터 선택과 위치 인덱싱

`nlargest()`로 기준 열의 상위 행을 선택하고, 이름 열에서 `iloc`으로 원하는 위치의 값을 가져옴. 다음 코드는 가격 상위 3개 중 세 번째 항목을 선택함.

```python
q6 = df.nlargest(3, 'price')['item'].iloc[2]
```

### 하위 데이터 선택과 동점 포함

`nsmallest()`로 기준 열의 하위 행을 선택함. `keep='all'`을 지정한 코드에서는 하위 3개를 고르는 경계값의 동점 항목도 포함해 주문 수의 평균을 계산함.

```python
q10 = df.nsmallest(3, 'price', keep='all')['orders_count'].mean().round(2)
```

### 조건 비교와 개수 계산

열의 값에 비교 연산을 적용하고 `sum()`으로 조건을 만족하는 행의 개수를 계산함. 도시·학년·카테고리의 일치 조건과 점수·열량의 이상 조건에 같은 방식을 사용함.

```python
q3 = (df['city']=='New York').sum()
```

### 조건 필터링과 열 선택

조건으로 행을 걸러낸 뒤 필요한 열을 선택함. 조회한 도시 열의 첫 번째 값을 `iloc[0]`으로 가져옴.

```python
q5 = df[df['name']=='Noah Davis']['city'].iloc[0]
```

### 평균과 반올림

`mean()`으로 평균을 구하고 `round(2)`로 소수점 이하 두 자리까지 반올림함. 조건으로 걸러낸 데이터에도 이어서 적용함.

```python
q9 = df[df['category'] == 'Soup']['calories'].mean().round(2)
```

### 최댓값 계산

`max()`로 선택한 열의 최댓값을 구함.

```python
q9 = df['english_score'].max()
```

### 결측값을 제외한 개수 계산

`count()`로 이름 열에서 결측값이 아닌 값의 개수를 계산함. 학생 수를 구하는 문제에 이 방식을 사용함.

```python
q10 = df['name'].count()
```

### 그룹별 평균과 최댓값의 인덱스

`groupby()`로 카테고리를 나누고 각 그룹의 평균 가격을 계산함. 이어서 `idxmax()`로 평균 가격이 가장 높은 카테고리를 선택함.

```python
q5 = df.groupby('category')['price'].mean().idxmax()
```

### 열 사이의 연산과 레이블 기반 조회

주문 수와 가격을 곱한 결과에서 `idxmax()`로 최댓값의 인덱스 레이블을 구함. `loc`으로 해당 행의 메뉴 이름을 조회함.

```python
df.loc[(df['orders_count']*df['price']).idxmax(), 'item']
```

### 리스트 컴프리헨션과 데이터프레임 생성

`range(1, 11)`과 리스트 컴프리헨션으로 1부터 10까지의 목록을 생성함. 이 목록으로 `question` 열을 가진 데이터프레임을 만듦.

```python

```

### Series 생성과 열 대입
