## 핵심 개념

### 선형 출력에서 분류 확률로 변환

공부 시간 `X`와 합격 여부 `y`를 사용해 분류 과정을 실습함. 먼저 `w * X + b`로 선형 출력을 구한 뒤, Sigmoid를 적용해 0과 1 사이의 확률로 변환함.

확률을 계산하는 단계와 최종 클래스를 결정하는 단계를 구분함. 실습에서는 확률이 임계값 `0.5` 이상이면 `1`, 미만이면 `0`으로 분류함.

### Cross Entropy로 예측 평가

정답과 예측 확률을 이용해 Cross Entropy 손실을 계산함. 정답이 `1`일 때 예측 확률이 `0.9`인 경우와 `0.1`인 경우를 각각 계산하도록 작성함.

손실 계산에 로그가 사용되므로, 예측 확률을 작은 양수와 1보다 조금 작은 값 사이로 제한한 뒤 계산함.

### 경사 하강법으로 학습

예측 확률과 실제 값의 차이를 이용해 가중치와 편향의 기울기를 구함. 각 기울기에 학습률을 곱한 값을 현재 가중치와 편향에서 빼는 방식으로 갱신함.

학습률을 `0.1`로 설정하고, 한 번만 갱신하는 코드에서 시작해 같은 과정을 1,000회 반복하는 코드로 확장함. 학습 후에는 기존 데이터와 새로운 공부 시간에 대한 확률 및 클래스를 계산함.

### `np.clip()`과 `np.log()`로 손실 계산

`np.clip()`으로 예측 확률의 범위를 제한한 뒤, `np.log()`를 사용해 각 데이터의 Cross Entropy 손실을 계산함.

```python
def cross_entropy(y, y_hat):
  eps = 1e-15
  y_hat = np.clip(y_hat, eps, 1-eps)
  return -(y * np.log(y_hat) + (1-y) * np.log(1-y_hat))
```

### `np.mean()`과 매개변수 갱신

`np.mean()`으로 가중치와 편향의 기울기를 계산함. 계산한 기울기에 학습률을 곱해 현재 값에서 빼는 방식으로 두 매개변수를 갱신함.
