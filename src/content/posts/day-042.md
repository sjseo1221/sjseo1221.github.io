## 오늘 배운 것

- 임의로 생성한 데이터로 선형 회귀 모델의 학습부터 평가까지 실습함.
- 학습용·테스트용 데이터를 7:3으로 나누고, 입력 배열의 형태를 바꿔 모델에 전달함.
- 네 가지 평가 지표를 계산하고, 데이터와 회귀선을 함께 시각화함.

## 핵심 개념

### 선형 회귀 실습의 구성

0 이상 30 미만의 정수 200개를 특성 데이터로 생성하고, 여기에 정규분포에서 추출한 값을 더해 목표 데이터를 구성함. 생성한 데이터의 관계는 산점도로 확인함.

### 학습 데이터와 테스트 데이터의 구분

전체 데이터의 70%는 학습에, 30%는 테스트에 사용함. 학습 데이터로 모델을 학습한 뒤, 테스트 데이터에 대한 예측값을 구해 평가하는 순서로 진행함.

### 학습 결과 확인

모델이 학습한 계수와 절편을 출력하고, MAE·MSE·RMSE·R2-score를 계산함. 마지막에는 학습 데이터와 테스트 데이터의 산점도 위에 예측값으로 그린 회귀선을 함께 표시함.

## 배운 문법

### 난수 시드 설정과 정수 데이터 생성

`np.random.seed()`로 난수 시드를 설정하고, `np.random.randint()`로 정수 배열을 생성함. 코드의 범위는 0 이상 30 미만이며, 생성 개수는 200개로 지정함.

```python
np.random.seed(42)
X = np.random.randint(0, 30, 200)
```

### 정규분포 난수 생성과 배열 연산

`X.size`로 원소 개수를 확인하고, 같은 개수의 정규분포 난수를 생성함. 이를 `X`에 더해 `y`를 구성함.

```python
y = X + np.random.normal(size=X.size)
```

### 산점도 그리기

`plt.scatter()`에 두 배열을 전달해 산점도를 그리고, `plt.show()`로 표시함.

```python
plt.scatter(X, y)
plt.show()
```

### 데이터 분할과 여러 변수에 대입하기

`train_test_split()`의 `test_size=0.3`으로 테스트 데이터 비율을 지정함. 반환되는 네 결과를 학습·테스트용 특성과 목표값 변수에 각각 대입함.

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
```

### 산점도 라벨과 범례 설정

각 산점도에 `label`을 지정해 학습 데이터와 테스트 데이터를 구분함. `plt.legend()`로 범례를 표시함.

```python
plt.scatter(X_train, y_train, label="train")
plt.scatter(X_test, y_test, label="test")
plt.legend()
plt.show()
```

### 모델 생성·학습과 배열 형태 변경

`LinearRegression()`으로 모델을 생성하고 `fit()`으로 학습함. `reshape(-1, 1)`을 사용해 1차원 특성 배열을 한 열을 가진 2차원 배열로 바꿔 전달함.

```python
model = LinearRegression()
model.fit(X_train.reshape(-1, 1), y_train)
```

### 모델 속성 확인과 f-string 출력

`coef_`와 `intercept_` 속성으로 학습한 계수와 절편을 확인함. f-string으로 설명 문구와 속성값을 함께 출력함.

```python
print(f"Coefficient : {model.coef_}")     # 모델의 coefficient
print(f"Intercept : {model.intercept_}")  # 모델의 intercept
```

### 테스트 데이터 예측

`predict()`에 테스트 특성을 전달하고 예측값을 `y_pred`에 저장함. 예측할 때도 특성 배열을 `reshape(-1,1)`로 변환함.

```python
y_pred = model.predict(X_test.reshape(-1,1))
```

### 회귀 평가 지표 계산

실제 목표값인 `y_test`와 예측값인 `y_pred`를 각 평가 함수에 전달함. MAE·MSE·RMSE·R2-score를 계산해 f-string으로 출력함.

```python
print(f"MAE : {mean_absolute_error(y_test, y_pred)}")
print(f"MSE : {mean_squared_error(y_test, y_pred)}")
print(f"RMSE : {root_mean_squared_error(y_test, y_pred)}")
print(f"R2-score : {r2_score(y_test, y_pred)}")
```

### 그래프 제목과 회귀선 표시

`plt.title()`로 제목을 설정하고, `plt.plot()`으로 테스트 특성과 예측값을 연결함. 회귀선에는 `c='red'`와 `linestyle='--'`를 지정해 빨간색 파선으로 표시함.

```python
plt.title("Linear Regression")
plt.scatter(X_train, y_train, label="train")
plt.scatter(X_test, y_test, label="test")
plt.plot(X_test, y_pred, label="Line of Best Fit", c='red', linestyle='--')
plt.legend()
plt.show()
```
