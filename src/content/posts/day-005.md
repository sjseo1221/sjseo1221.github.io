## 핵심 개념

### 튜플: 고정된 데이터 다루기

튜플은 순서가 있어 인덱싱과 슬라이싱이 가능하며, 요소의 중복을 허용함. 요소를 수정할 수 없으므로 고정된 데이터를 다루는 데 적합함.

### 딕셔너리: 키와 값 연결하기

딕셔너리는 키와 값의 쌍으로 데이터를 관리함. 키는 중복될 수 없지만 값은 중복될 수 있으며, 키를 통해 값을 찾거나 항목을 추가·삭제할 수 있음.

단어의 등장 횟수, 팀별 인원과 점수, 숫자별 좌표를 관리하는 실습에 활용함. 같은 키에 정보를 모아 두고 필요한 값을 조회하는 방식으로 문제를 해결함.

### 세트: 중복 제거와 집합 비교하기

세트는 리스트의 중복된 값을 제거하거나, 두 집합 사이의 관계를 비교하는 데 활용함. 합집합·교집합·차집합·대칭차집합을 실습함.

로또 실습에서는 세트로 번호를 모으고, 생성한 번호와 입력한 번호의 교집합을 구해 일치한 번호를 확인함. 일치 개수에 따른 등수는 딕셔너리로 연결함.

### 중첩 반복문: 경우의 수와 격자 다루기

두 주사위의 합이 입력값과 같은 경우를 세고, 숫자 사각형·X 모양·별·문자 패턴을 만드는 실습을 진행함. 행과 열을 반복하면서 조건에 따라 값을 배치하거나 출력하는 방식으로 구성함.

두 숫자열의 위치를 바꾸어 가며 곱의 합을 비교하는 문제와, 정수를 2로 나눈 나머지를 격자에 반영하는 문제에도 반복문을 활용함.

## 배운 문법

### 튜플 언패킹

`for x, y in coord`로 각 튜플의 두 값을 변수에 나누어 받는 방법을 사용함.

```python
coord = [(1, 2), (3, 4), (5, 6)]

for x, y in coord:
    print(x, y)
```

### 딕셔너리의 키 확인과 값 갱신

`in`으로 키의 존재 여부를 확인하고, 이미 있는 키의 값은 증가시키며 없는 키는 초기값을 지정함.

```python
for x in words:
    if x in count:
        count[x] += 1 # count에 x가 있다면 value를 1 더해줘
    else: 
        count[x] = 1 # count에 x라는게 없다면 value 초기값을 1로 해서 추가해줘
```

### `dict.get()`과 `dict.pop()`

양말의 짝을 찾는 코드에서 `get()`의 반환값이 `None`인지 확인해 항목을 추가함. 같은 값이 다시 나오면 `pop()`으로 해당 항목을 제거함.

```python
for i in socks:
  if d.get(i) == None:
    d[i] = 1
  else :
    d.pop(i)
```

### 세트 생성과 집합 연산자

중괄호로 세트를 만들고, `|`, `&`, `-`, `^`로 집합 연산을 수행함.

```python
a = {1, 2, 3}
b = {3, 4, 5, 6}
print(a|b) # 합집합
print(a&b) # 교집합
print(a-b) # 차집합
print(a^b) # 대칭차집합
```

### `while`, `len()`, `set.add()`로 번호 모으기

`randint(1, 45)`로 생성한 수를 `add()`로 세트에 추가함. 중복된 수는 새 요소로 늘어나지 않으므로, `len()`이 6이 될 때까지 반복함.

```python
lotto = set()

while len(lotto) < 6:
    num = randint(1, 45)
    lotto.add(num)
```

### `split()`과 `map()`으로 입력 변환하기

입력 문자열을 `split()`으로 나누고, `map(int, ...)`로 각 항목을 정수로 변환한 뒤 세트에 담음.

```python
user = set(map(int, input("숫자 6개 입력: ").split()))
```

### `enumerate()`와 좌표 저장

`enumerate(row)`로 열의 인덱스와 값을 함께 받음. 숫자를 키로 삼고 좌표 튜플을 리스트에 추가해, 같은 숫자가 나타난 위치를 모아 저장함.

```python
for y in range(h):
    row = list(map(int, input().split()))
    for x, num in enumerate(row):
        if num not in um:
            um[num] = []
        um[num].append((y, x))
```
