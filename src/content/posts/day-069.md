## 파트 1. OpenCV 증강 3종

| 증강 | 함수 | 기억할 점 |
|---|---|---|
| 좌우 반전 | `cv2.flip(img, 1)` | flipCode 1=좌우, 0=상하, -1=둘 다 |
| 회전 | `getRotationMatrix2D` → `warpAffine` | center와 dsize는 **(가로, 세로)** 순서, 양수 각도는 반시계 |
| 밝기 | `astype(float32)` → 더하기 → `np.clip` → `astype(uint8)` | uint8 그대로 더하면 넘침 ⭐ |

- `center = ((w-1)/2, (h-1)/2)`인 이유: 픽셀 번호가 0부터 시작해 마지막이 w-1이므로, 처음(0)과 마지막(w-1)의 중간이 가운데임
- `img.shape`만 (높이, 너비) 순서이고 OpenCV 함수 인자는 (가로, 세로) 순서라 헷갈리기 쉬움
- 넘침 예: uint8 `250 + 30` = 280 − 256 = **24**. 거의 흰색이 거의 검은색으로 바뀌는데 에러 없이 조용히 일어남

### 핵심 코드 2: 증강 함수 (random_flip)

```python
def random_flip(img):
    if random.random() < FLIP_PROB:   # 0~1 난수가 0.5보다 작으면 반전 (50%)
        return cv2.flip(img, 1)
    return img                        # 아니면 원본 그대로
# FLIP_PROB가 0.0이나 1.0이면 반전본/원본 중 하나만 나와 check_augment가 ❌
```

- **질문**: 증강은 왜 train/test 분리 후 train에만 적용하는가?

### Q&A

- **질문**: 평균 풀링(Global Average Pooling)은 무엇이며 MaxPool과 어떻게 다른가?
- **처음 내 이해**: 평균 풀링이 무엇인지 몰랐음
- **실제로는**: 채널 하나의 특징 맵 전체를 평균 숫자 하나로 줄임. MaxPool(2)은 2×2 최댓값으로 크기를 절반만 줄이고 Conv 블록 사이에 쓰며, 평균 풀링은 1×1로 줄이고 Linear 직전에 씀. 위치 정보를 버려 "특징이 어딘가에 있는가"만 전달하므로 외울 재료가 줄어듦 ⭐
- (보충) 기여도는 평균 풀링 > Conv 2개 > Dropout2d 순으로 추정하지만 절제 실험(ablation)으로 확인하지 않음. 확인하려면 평균 풀링 한 줄만 지우고 재학습

- **질문**: 값을 손으로 바꾸는 대신 하이퍼파라미터를 자동으로 실험하는 방법은?
- **처음 내 이해**: 이런 방법이 있었던 것 같은데 이름이 기억나지 않았음
- **실제로는**: (보충) Grid Search(모든 조합), Random Search(무작위 추출), Optuna(이전 결과를 보고 유망한 값 근처를 탐색). test 정확도로 값을 고르면 test에 맞춰지므로 원칙적으로는 검증(validation) 데이터를 따로 둠
