## 배운 문법

### Series 생성과 인덱스 지정

`pd.Series()`로 점수 목록을 만들고, `index`에 과목 이름을 지정함. 실제 작성한 코드에서는 수학 점수를 95로 사용함.

```python
scores = pd.Series([95, 80, 95, 90], index = ["국어","영어", "수학","과학"])
scores
```

> ⭐ scores = pd.Series([95, 80, 95, 90], index = ["국어","영어", "수학","과학"])

### DataFrame 생성

`pd.DataFrame()`에 딕셔너리 또는 중첩 리스트를 전달해 표를 생성함. 중첩 리스트를 사용할 때는 `columns`로 열 이름을 지정함.

```python
rows = [['민준', 88], ['서연', 92], ['도윤', 76]]
df2 = pd.DataFrame(rows, columns = ['이름','점수'])
df2
```

### 앞뒤 행 확인

`head()`와 `tail()`에 확인할 행 수를 전달함. 각각 처음 3행과 마지막 2행을 출력하도록 작성함.

```python
print(df.head(3))
print(df.tail(2))
```

### 수치형 데이터의 통계 요약

`describe()`를 호출해 국어·영어·수학 점수의 통계 요약을 확인함.

```python
df.describe()
```

### 크기와 열 이름 확인

`shape`로 행과 열의 개수를, `columns`로 열 이름을 확인함.

```python
print(df.shape)
print(df.columns)
```

### 한 열과 여러 열 선택

대괄호에 열 이름 하나를 넣어 한 열을 선택함. 여러 열을 선택할 때는 열 이름 목록을 전달함.

```python
df[['이름','수학']]
```

### 위치 기준 선택과 슬라이싱

`iloc`에 슬라이스를 전달해 정수 위치를 기준으로 행을 선택함. `0:3`으로 0·1·2번째 행을 선택함.

```python
df.iloc[0:3]
```

### 비교 조건과 불리언 인덱싱

비교식으로 만든 조건을 대괄호에 넣어 해당 행을 선택함. 두 조건을 모두 만족하도록 할 때는 각 조건을 괄호로 감싸고 `&`로 연결함.

```python
df[(df['반'] == 'A') & (df['영어'] >= 80)]
```

### 목록 포함 여부 확인

`isin()`으로 이름이 지정한 목록에 포함되는지 확인함. 그 결과를 행 선택 조건으로 사용함.

```python
df[df['이름'].isin(['민준','하은','예준'])]
```

### 단일·복수 기준 정렬

`sort_values()`로 정렬할 열을 지정하고, `ascending`으로 정렬 방향을 설정함. 여러 열을 기준으로 정렬할 때는 열마다 방향을 따로 지정함.

```python
df.sort_values(['반','국어'], ascending=[True,False])
```

> ⭐ df.sort_values(['반','국어'], ascending=[True,False])

### 그룹별 평균과 복수 통계 계산

`groupby()`로 반별 데이터를 묶고 `mean()`으로 과목별 평균을 계산함. `agg()`에는 통계 이름 목록을 전달해 수학 평균과 최댓값을 함께 계산함.

```python
df.groupby('반')['수학'].agg(['mean','max'])
```

### 값별 개수 집계

`value_counts()`로 반 값이 등장하는 횟수를 세어 반별 학생 수를 계산함.

```python
df['반'].value_counts()
```

### 결측치가 있는 데이터 생성

`np.nan`을 점수 목록에 넣어 결측치가 포함된 DataFrame을 생성함.

```python
data_missing = {
    '이름': ['민준', '서연', '도윤', '하은', '시우'],
    '수학': [88, np.nan, 76, 95, np.nan],
}
df_m = pd.DataFrame(data_missing)
```

### 결측치 확인과 개수 계산

`isna()`로 결측치 여부를 확인하고, `sum()`으로 열별 결측치 개수를 계산함.

```python
df_m.isna().sum()
```

### 평균으로 결측치 채우기

`mean()`으로 결측치를 제외한 수학 점수의 평균을 계산함. `fillna()`의 결과를 수학 열에 다시 대입함.

```python
mean_score = df_m['수학'].mean()
mean_score
df_m['수학'] = df_m['수학'].fillna(mean_score)
df_m
```

### 행과 열 삭제

`dropna()`로 결측치가 있는 행을 제거하고, `drop(columns=...)`로 지정한 열을 삭제함. 두 실습 모두 반환된 DataFrame을 변수에 대입함.

```python
df = df.drop(columns = ['총점'])

df
```

### 열 연산과 새 열 대입

과목별 열을 더해 총점 열을 생성함. 이어서 총점 열을 3으로 나눈 값을 평균 열에 대입함.

```python
df['총점'] = df['국어'] + df['영어'] + df['수학']
df
```

### 함수 정의와 `apply()`

`def`로 함수를 정의하고 `if`와 `return`으로 평균 90 이상 여부에 따른 등급을 반환함. `apply()`로 평균 열의 각 값에 함수를 적용해 등급 열을 생성함.

```python
def func(mean):
  if mean >= 90:
    return "우수"
  return "보통"

df['등급'] = df['평균'].apply(func)
```
