## 오늘 배운 것

- CLIP은 이미지와 문장을 같은 공간의 벡터로 바꾸고, 벡터 내적(유사도)이 큰 것을 고르는 모델임.
- 같은 원리로 문장 비교(01), 제로샷 분류(02), 텍스트-이미지 검색(03)을 모두 처리함.

## 핵심 개념

- CLIP 모델 안에는 **이미지 인코더**와 **텍스트 인코더**가 있고, 두 인코더의 출력이 같은 차원의 공간으로 투영됨 ⭐
- 길이를 1로 정규화한 벡터끼리 내적하면 **코사인 유사도**가 됨
- 모델이 하는 일은 벡터로 바꾸는 것까지이고, "가장 가까운 것 찾기"는 모델 밖의 단순 계산(softmax, topk)임

## 핵심 코드

### 1) 입력 만들기 → 점수 → 확률 (01)

```python
model = CLIPModel.from_pretrained(model_id)        # 이미지·텍스트 인코더를 가진 모델
processor = CLIPProcessor.from_pretrained(model_id) # 같은 model_id여야 전처리 방식이 맞음

inputs = processor(
    text=texts,
    images=image,            # RGB 배열(0~255). BGR인 image_bgr을 넣으면 색이 뒤바뀜
    return_tensors="pt",     # PyTorch 텐서로 받음. 안 쓰면 파이썬 리스트
    padding=True             # 문장 길이가 달라도 한 텐서로 묶으려면 필수
)

with torch.no_grad():        # 추론만 하므로 기울기 계산을 꺼서 메모리 절약
    outputs = model(**inputs)

# dim=1: 문장 방향으로 합이 1이 되게 함. dim=0이면 이미지 방향이라 의도와 달라짐
probs = outputs.logits_per_image.softmax(dim=1)[0]
```

### 3) 벡터 만들기 → 내적 → top-k 검색 (03)

```python
# 이미지 쪽: vision_model → visual_projection → normalize
vision_outputs = model.vision_model(pixel_values=image_inputs["pixel_values"])
image_features = model.visual_projection(vision_outputs.pooler_output)  # 텍스트와 같은 공간으로 투영
image_features = F.normalize(image_features, dim=-1)  # 길이 1 → 내적이 코사인 유사도

# 문장 쪽도 text_model → text_projection → normalize로 같은 3단계를 적용함

scores = (text_features @ image_features.T)[0]  # (1,512)@(512,N)=(1,N) → [0]으로 (N,)
# k가 이미지 수보다 크면 에러라서 min으로 제한
top_scores, top_indices = torch.topk(scores, k=min(4, len(images)))
```
