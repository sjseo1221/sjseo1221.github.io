## 핵심 개념

### 가까운 이웃의 범주로 분류하기

`KNNClassifier`의 `fit()`에서는 학습 데이터와 정답을 저장만 하도록 구현함. 예측할 때는 입력 샘플과 모든 학습 샘플 사이의 유클리드 거리를 계산하고, 가장 가까운 `k`개 이웃의 범주 중 빈도가 가장 높은 범주를 선택함.

여러 샘플을 예측할 때는 샘플마다 같은 과정을 반복함. 예측에 사용한 이웃의 인덱스도 별도로 기록하도록 구현함.

### 원본 데이터와 스케일링한 데이터로 실습하기

첫 번째 풀이에서는 원본 데이터를 그대로 사용함. 두 번째 풀이에서는 학습 데이터에 `StandardScaler`를 맞추고, 같은 변환을 테스트 데이터에도 적용한 뒤 동일한 분류기로 예측하도록 구성함.

## 배운 문법

### 클래스와 생성자로 상태 초기화하기

`KNNClassifier`의 생성자에서 이웃 수를 전달받고, 학습 데이터와 이웃 정보를 저장할 속성을 초기화함.

```python
  def __init__(self, k):
    self.k= k
    self.X = None
    self.y = None
    self.neighbors = []
```

### 메서드에서 학습 데이터 저장하기

`fit()`의 인자로 받은 특성과 정답을 인스턴스 속성에 저장함.

```python
  def fit(self, X, y):
    # 데이터 저장만
    self.X = X
    self.y = y
```

### NumPy 연산으로 유클리드 거리 계산하기

두 배열의 차이를 제곱한 뒤 `np.sum()`으로 합산하고, `np.sqrt()`로 제곱근을 계산함.

```python
  def euclidean_distance(self, x1, x2):
    # 유클리드 거리를 구하는 함수
    return np.sqrt(np.sum((x1 - x2) ** 2))
```

### 리스트 컴프리헨션으로 거리와 범주 모으기

리스트 컴프리헨션으로 입력 샘플에서 각 학습 샘플까지의 거리를 계산함. 선택한 이웃의 인덱스로 정답 범주를 모을 때도 같은 문법을 사용함.

```python
    dists = [self.euclidean_distance(x, t) for t in self.X]  # x부터 다른 모든 데이터까지의 거리 측정
```

### 정렬 인덱스와 슬라이싱으로 이웃 선택하기

`np.argsort()`로 거리가 작은 순서의 인덱스를 구하고, `[:self.k]`로 앞의 `k`개만 선택함. 선택한 인덱스는 `append()`로 이웃 정보에 추가함.

```python
    indexes = np.argsort(dists)[:self.k]      # 정렬한 후, 앞 K개만 slicing
    self.neighbors.append(indexes)            # 이웃들의 정보에 가장 가까운 K개의 데이터의 index를저장
```

### 범주별 빈도로 예측값 결정하기

`np.bincount()`로 이웃 범주의 빈도를 세고, `np.argmax()`로 빈도가 가장 높은 범주를 선택해 반환함.

```python
    categories = [self.y[i] for i in indexes] # 이 이웃들의 범주를 확인
    ret = np.argmax(np.bincount(categories))  # 이 중 가장 많이 발생한 빈도로 정답을 결정
    return ret
```

```python
    predictions = []    # 전체 예측 초기화
    self.neighbors = [] # 전체 이웃 정보 초기화
    for x in x_test:    # X_test의 각 샘플(x)에 대해 반복
```

### NumPy 배열로 데이터 구성하기

`np.array()`로 학습·테스트 데이터와 정답을 구성함. 구매 여부를 나타내는 정답도 배열로 저장함.

### StandardScaler로 데이터 변환하기

학습 데이터에는 `fit_transform()`을 사용해 변환 기준을 맞추면서 변환함. 테스트 데이터에는 `transform()`을 사용해 학습 데이터에서 정한 기준을 적용함.
