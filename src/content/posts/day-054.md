## 핵심 개념

### 데이터 준비와 배치 구성

이진 분류용 데이터를 생성한 뒤 학습용과 테스트용으로 분리함. 스케일링 기준은 학습 데이터에서 구하고, 테스트 데이터에는 그 기준을 적용함.

입력과 정답을 각각 텐서로 변환하고, 정답은 열 하나를 갖는 형태로 맞춤. 이후 두 텐서를 `TensorDataset`으로 묶어 `DataLoader`에 전달함.

### 학습 데이터를 투입하는 세 가지 방식

Batch GD는 학습 데이터 전체를 한 번에 모델에 전달함. Stochastic GD는 배치 크기를 1로, Mini-batch GD는 배치 크기를 32로 설정한 로더를 순회함.

세 방식 모두 `torch.optim.SGD`를 사용함. 이번 실습에서는 최적화기 이름이 아니라, 모델에 한 번에 전달하는 데이터 묶음의 크기로 학습 방식을 구분함.

### 손실과 정확도 비교

각 방식을 100 epoch 동안 학습하면서 손실을 기록함. 전체 데이터 학습은 epoch마다 계산한 손실을 저장하고, 배치 학습은 각 배치의 손실을 더한 뒤 배치 수로 나누어 저장함. 배치별 데이터 개수로 가중한 평균이 아니라, 배치 손실들의 단순 평균을 사용함.

테스트에서는 예측값을 0.5 기준으로 나누어 정확도를 계산함. 별도 비교 실습에서는 배치 크기를 1, 32, 256, 전체 데이터 크기로 바꾸어 손실 곡선을 그리도록 구성함. 실행 출력이 없어 어느 설정의 손실이나 정확도가 더 좋았는지는 판단하지 않음.

## 배운 문법

### 난수 시드 설정

`torch.manual_seed()`와 `np.random.seed()`로 난수 시드를 설정함. 배치 크기 비교 함수에서도 PyTorch 시드를 다시 설정함.

```python
torch.manual_seed(42)

```

### 분류 데이터 생성

`make_classification()`에 데이터 개수와 특징 수 등을 지정하여 입력과 정답을 생성함.

```python
X_np, y_np = make_classification(
    n_samples=1000,
    n_features=10,
...
    random_state=42
)
```

### 데이터 분리와 스케일링

`train_test_split()`으로 데이터를 나누고, `fit_transform()`과 `transform()`을 구분해 사용함. 학습 데이터에서 정한 스케일링 기준을 테스트 데이터에도 적용함.

```python
X_train, X_test, y_train, y_test = train_test_split(X_np, y_np, test_size=0.3, random_state=42)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)

```

### 텐서 변환과 형태 변경

`torch.tensor()`에서 자료형을 `torch.float32`로 지정함. 정답 텐서는 `reshape(-1,1)`로 열 하나를 갖도록 변경함.

```python
X_train_tensor = torch.tensor(X_train, dtype=torch.float32)
X_test_tensor = torch.tensor(X_test, dtype=torch.float32)
y_train_tensor = torch.tensor(y_train, dtype=torch.float32).reshape(-1,1)
y_test_tensor = torch.tensor(y_test, dtype=torch.float32).reshape(-1,1)
```

### TensorDataset과 DataLoader

`TensorDataset()`으로 입력과 정답을 묶고, `DataLoader()`의 `batch_size`와 `shuffle`로 배치 크기와 데이터 섞기 여부를 지정함.

```python

```

### 첫 배치 꺼내기와 크기 확인

`iter()`로 반복자를 얻고 `next()`로 첫 배치를 꺼내 두 변수에 나누어 저장함. 텐서의 `.shape`와 로더의 `len()`을 출력하도록 작성함.

```python
X_batch, y_batch = next(iter(loader))
print("배치 X shape:", X_batch.shape)   # (32, 10)
print("배치 y shape:", y_batch.shape)   # (32, 1)
print("총 배치 수  :", len(loader))
```

### 최적화기와 학습률 설정

`model.parameters()`를 `torch.optim.SGD()`에 전달하고, `lr`로 학습률을 지정함.

### 학습 모드와 순전파

`model.train()`을 호출한 뒤 입력을 모델에 전달하고, 예측값과 정답으로 손실을 계산함. 전체 데이터 학습에서는 로더 대신 학습 텐서를 직접 전달함.

```python

    model.train()
```

### 기울기 초기화와 파라미터 갱신

`zero_grad()`, `backward()`, `step()`을 차례로 호출함. 각 학습 반복에서 기울기를 초기화하고 역전파한 뒤 파라미터를 갱신함.

```python

    bgd.step()
```

### 중첩 반복과 배치 언패킹

바깥쪽 `range()` 반복으로 epoch를 진행하고, 안쪽 반복에서 로더의 입력과 정답을 각각 꺼냄.

```python

    model.train()
    epoch_loss = 0

        pred = model(X_b)

```

### 손실 누적과 리스트 저장

`loss.item()`으로 손실을 수치로 꺼내 누적하고, `append()`로 epoch별 평균 손실을 저장함. `cnt += 1`은 배치 반복 안에서 업데이트 횟수를 세는 데 사용함.

```python
        sgd.step()
```

### 조건부 출력과 f-string

### 기울기 계산 없이 예측하고 정확도 계산

`torch.no_grad()` 안에서 테스트 예측을 수행함. `np.where()`로 예측값을 0과 1로 변환한 뒤 `accuracy_score()`에 전달함.

```python

  y_pred = model(X_test_tensor)
```


### 함수 기본값과 조건 표현식

함수 매개변수에 epoch 수와 학습률의 기본값을 지정함. 배치 크기가 `None`이면 조건 표현식으로 전체 학습 데이터 수를 선택함.

```python
def train_with_batch(batch_size, epochs=50, lr=0.05):

    bs     = batch_size if batch_size is not None else len(X_train_tensor)
```
