## 오늘 배운 것

- YOLO11-seg가 박스와 마스크를 어떻게 돌려주는지 열어 보고, 마스크 IoU·Dice·mAP로 품질을 수치화함.
- 마스크 크기를 원본에 맞춘 뒤 `np.where`로 사람만 남기고 배경을 바꾸는 가상 배경 미니 프로젝트를 만듦.

## 이론 파트

### 1. Detection과 Segmentation

- Detection은 위치를 네모 박스로만 짚음. Segmentation은 픽셀 단위로 객체 모양까지 따냄
- YOLO 세그멘테이션 모델(`yolo11n-seg.pt`)은 박스와 마스크를 함께 출력함
- 가중치 이름 규칙: `yolo11` + 크기(n s m l x) + 작업(`-seg`) + `.pt`. 접미사가 없으면 detection 모델임

### 2. 추론 결과(Results) 구조

- `model.predict()`의 반환값은 `list[Results]`이고, 이미지 1장당 Results 1개가 들어 있음 → `[0]`으로 꺼내 씀
- `len(results)`는 이미지 장수, `len(result)`는 그 이미지에서 검출된 객체 수임
- `result.boxes.cls / .conf / .xyxy`는 각각 `(N,)`, `(N,)`, `(N, 4)`임. 객체 순서는 마스크와 같음
- Tensor는 `.cpu().numpy()` 순서로 NumPy로 바꿈. GPU에 있는 채로 `.numpy()`를 하면 에러가 남
- 객체가 하나도 없으면 `result.masks`는 `None`이라 `.data`를 쓰면 에러가 남

### 3. 마스크의 두 종류 ⭐

| 구분 | 픽셀 마스크 `.data` | 윤곽선 좌표 `.xy` |
|---|---|---|
| 표현 | 픽셀마다 0/1 | 테두리 점 (x, y) 목록 |
| 모양 | Tensor `(N, H', W')` | 길이 N 리스트, 각 `(K, 2)` |
| 기준 크기 | 모델 입력 크기 | 원본 이미지 |
| 용도 | 면적 계산, IoU/Dice | 윤곽선 그리기 |

- 비유: `.data`는 도장 자국 그대로의 사진, `.xy`는 그 자국의 테두리를 따라 그린 선

### 4. 평가지표 ⭐

- Mask IoU = 교집합 / 합집합, Dice = 2×교집합 / (정답 넓이 + 예측 넓이)
- 관계식 Dice = 2·IoU / (1 + IoU) → 항상 Dice ≥ IoU. 코드에서 `np.isclose`로 검증함
- 0으로 나누기를 막으려고 분모가 0이면 0.0으로 처리함
- `model.val()`은 데이터셋 전체로 평가하고, 평가용 conf 하한은 0.001임 (추론 기본 conf는 0.25)
- mAP50은 IoU 0.5 이상을 "맞음"으로 치는 기준, mAP50-95는 기준을 0.5~0.95로 바꿔 가며 평균한 더 엄격한 지표임
- 이번 coco8-seg 결과(4장, 객체 17개): 박스 mAP50 0.8869 / mAP50-95 0.6743, 마스크 mAP50 0.8519 / mAP50-95 0.5714
- 마스크 mAP50-95가 박스보다 낮음 → 픽셀 윤곽이 박스보다 높은 IoU를 맞추기 어려움

## 실습 파트

### 실습 흐름

1. 모델 불러오기 `YOLO("yolo11n-seg.pt")` → `model.task`, `model.names` 확인
2. 추론 `predict(...)[0]` → `plot()`으로 박스·마스크 그려 보기
3. boxes / masks 열어보기 → 정답(GT) 마스크 만들어 IoU·Dice 계산 → `val()`로 mAP
4. 미니 프로젝트: URL에서 이미지 로드 → 사람 마스크 → `np.where` 합성(+ 블러 배경)
5. `.py`로 옮겨 웹캠 프레임마다 같은 처리를 반복 (모델은 루프 밖에서 한 번만 로드)

### 핵심 코드 1. 사람 마스크 만들기

```python
person_mask = np.zeros((h, w), dtype=np.uint8)   # 처음엔 전부 0(배경). np.zeros는 (높이, 너비) 순서
for cls, mask in zip(classes, masks):            # classes[i]와 masks[i]가 같은 객체라 zip으로 짝지음
    if int(cls) == person_id:                    # cls가 float일 수 있어 int로 바꿔 비교. 사람이 아니면 건너뜀
        mask = cv2.resize(mask, (w, h))          # 마스크(384x640)를 원본(720x1280)으로. resize는 (너비, 높이) 순서
        person_mask[mask > 0.5] = 255            # 보간으로 생긴 중간 값을 0.5 기준으로 사람/배경으로 나눔
```

### 핵심 코드 2. 사람은 원본, 나머지는 새 배경

```python
condition = person_mask[:, :, None] > 0          # (H,W) → (H,W,1): 세 채널에 같은 조건을 쓰려고 차원 추가
output = np.where(condition, image, background)  # True면 image, False면 background. 두 이미지 크기가 같아야 함
```

- 두 인자를 바꾸면 사람 자리에 배경이 들어가고 나머지가 원본이 되어 사람이 사라진 것처럼 보임
- 배경만 흐리게 하려면 `background` 자리에 `cv2.GaussianBlur(image, (51, 51), 0)`을 넣음. ksize는 홀수여야 하고 클수록 더 흐려짐

### 핵심 코드 3. URL에서 이미지 불러오기

```python
req   = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})  # 기본 신분이면 서버가 막을 수 있어 브라우저인 척 함
data  = urllib.request.urlopen(req, timeout=20).read()   # 실제 접속은 urlopen. 20초 넘으면 포기(무한 대기 방지)
arr   = np.frombuffer(data, dtype=np.uint8)              # 이미지 바이트는 0~255라 uint8
image = cv2.imdecode(arr, cv2.IMREAD_COLOR)              # imread는 URL을 못 읽어서 디코딩으로 처리. 실패하면 None
```

### 🐛 에러 로그

- 메시지: `AttributeError: module 'urllib.request' has no attribute 'request'`
- 원인: `urlopen` 자리에 모듈 이름을 따라 `request`를 씀. `Request`(요청 객체 생성)와 `urlopen`(실제 접속)은 별개임
- 해결: `urllib.request.urlopen(req, timeout=20).read()`로 수정
