## 핵심 개념

### 집계 그래프와 개별 데이터의 차이

같은 월에 메뉴 데이터가 4행씩 있으므로, 메뉴를 구분하지 않은 Seaborn 선그래프는 네 메뉴의 평균을 나타냄. 선 주변의 띠는 95% 신뢰구간을 나타냄.

월과 메뉴의 조합마다 데이터가 한 행뿐인 막대그래프에서는 평균이 해당 값과 같아짐. 이 경우 신뢰구간 선이 생기지 않음을 확인함.

### long-form과 wide-form의 역할

원본 `df`는 월·메뉴·판매량이 각각 열로 구성된 long-form임. 메뉴별 판매량을 별도 열로 펼친 wide-form은 메뉴 간 관계를 살피거나 pandas Plot으로 여러 메뉴를 함께 그릴 때 사용함.

`wide_df`는 월을 인덱스로 유지한 데이터이고, `wide`는 인덱스를 초기화해 월을 일반 열로 둔 데이터로 구분함. 두 데이터의 구조가 다르므로 같은 이름처럼 혼용하지 않는 것이 중요함.

wide-form을 다시 long-form으로 변환한 뒤 Seaborn에 전달하는 실습 흐름은 다음과 같음.

## 배운 문법

import matplotlib.pyplot as plt

### CSV 읽기와 데이터 점검

`pd.read_csv()`로 데이터를 읽고, `head()`, `info()`, `describe()`로 앞부분·구조·기술통계를 점검함. 중간 데이터도 명시적으로 확인할 수 있도록 `print()`를 사용함.

```python
df = pd.read_csv("cafe.csv")  # 카페 메뉴 데이터
print(df.head())
print(df.info())
print(df.describe())
```

### 선그래프와 메뉴별 색·스타일 구분

`sns.lineplot()`의 `x`, `y`로 축을 지정하고, `hue`와 `style`로 메뉴를 구분함. `markers=True`로 마커를 추가하고 `plt.title()`, `plt.show()`로 제목 지정과 화면 표시를 수행함.

```python
sns.lineplot(data=df, x='월', y='판매량', hue='메뉴', style='메뉴', markers=True)
plt.title('메뉴별 월간 판매량')
plt.show()
```

### 막대그래프와 집계 기준 변경

`sns.barplot()`으로 판매량을 집계해 표시하며, 기본 평균 대신 중앙값을 사용하려면 `estimator='median'`을 지정함. 월별 막대를 메뉴별로 나누는 실습에서는 `hue='메뉴'`를 사용함.

```python
sns.barplot(data=df, x='메뉴', y='판매량', estimator='median')
plt.title('메뉴별 판매량 중앙값')
plt.show()
```

### 범주별 데이터 개수 세기

`sns.countplot()`으로 메뉴별 행의 개수를 막대그래프로 표시함. 판매량 값을 집계하는 `barplot()`과 구분해 사용함.

```python
sns.countplot(data=df, x='메뉴')
plt.title('메뉴별 결제 수')
plt.show()
```

### 산점도와 색상 구분

`sns.scatterplot()`으로 월과 판매량을 점으로 표시함. `hue='메뉴'`를 지정해 메뉴별 색상을 구분함.

```python
sns.scatterplot(data=df, x='월', y='판매량', hue='메뉴')
plt.title('메뉴별 월간 판매량')
plt.show()
```

### 피벗과 인덱스 초기화

`pivot()`으로 월을 기준으로 메뉴별 판매량을 펼치고, `reset_index()`로 월을 일반 열로 되돌림. 열 축의 이름인 `메뉴`는 유지해 범례 제목에 반영함.

```python
wide = df.pivot(index='월', columns='메뉴', values='판매량').reset_index()
print(wide)
```

### 여러 수치 열의 관계 확인

`sns.pairplot()`에 메뉴별 판매량 열이 있는 `wide_df`를 전달함. 숫자 열이 판매량 하나뿐인 원본 `df`를 전달하는 코드는 해당 실습의 답에서 제외함.

```python
sns.pairplot(wide_df)
plt.show()
```

### 히스토그램의 구간 수와 KDE 선

`sns.histplot()`으로 판매량 분포를 그리고, `kde=True`로 KDE 선을 추가함. 문제에서 요구한 구간 수는 `bins=10`으로 명시함.

```python
sns.histplot(data=df, x='판매량', kde=True, bins=10)
plt.title('전체 판매량 분포')
plt.show()
```

### 히스토그램의 누적·분리 배치

`hue`로 메뉴를 나눈 뒤 `multiple='stack'`으로 쌓거나 `multiple='dodge'`로 떨어뜨려 비교함. 두 방식 모두 구간 수를 10개로 지정함.

```python
sns.histplot(data=df, x='판매량', hue='메뉴', bins=10, multiple='stack')
...
sns.histplot(data=df, x='판매량', hue='메뉴', bins=10, multiple='dodge')
plt.title('메뉴별 판매량 분포')
plt.show()
```

### Seaborn 박스플롯

`sns.boxplot()`의 x축에 메뉴, y축에 판매량을 지정해 메뉴별 분포를 비교함. 실행 환경의 자동 표시에만 의존하지 않도록 `plt.show()`를 명시함.

```python
sns.boxplot(data=df, x='메뉴', y='판매량')
plt.title('메뉴별 판매량 분포')
plt.show()
```

### pandas 선그래프와 선 스타일

`DataFrame.plot()`에 `x='월'`을 지정하고, `style` 목록으로 메뉴별 선 모양을 설정함. 인덱스를 초기화한 데이터에서 x축을 생략하면 월 대신 행 인덱스가 사용되므로 주의함.

```python
wide.plot(x='월', style=[':', '--', '-', '-'])
plt.title("메뉴별 판매량 추이")
plt.show()
```

### pandas 막대그래프와 축 눈금 회전

`kind='bar'`로 막대그래프를 선택하고 월을 x축으로 지정함. `plt.xticks(rotation=0)`으로 x축 글자를 회전하지 않도록 설정함.

```python
wide.plot(kind='bar', x='월')
plt.title("메뉴별 월간 판매량")
plt.xticks(rotation=0)
plt.show()
```

### pandas 산점도의 두 축 지정

`kind='scatter'`와 함께 x축과 y축에 사용할 열을 지정함. 월과 라떼 판매량을 선택해 산점도로 표시함.

```python
wide.plot(kind='scatter', x='월', y='라떼')
plt.title("월별 라떼 판매량")
plt.show()
```

### melt로 long-form 복원

`melt()`에서 월을 식별 열로 유지하고, 메뉴 이름과 판매량이 들어갈 열 이름을 지정함. 변환 결과의 앞 8행을 확인한 뒤 `data=long_form`으로 산점도에 전달함.

```python
long_form = wide.melt(id_vars='월', var_name='메뉴', value_name='판매량')
print(long_form.head(8))

sns.scatterplot(data=long_form, x='월', y='판매량', hue='메뉴')
plt.title('메뉴별 월간 판매량')
plt.show()
```

### 여러 열 선택과 pandas 히스토그램

메뉴 열 네 개를 선택한 뒤 `kind='hist'`로 분포를 겹쳐 표시함. `alpha=0.5`로 투명도를, `bins=10`으로 구간 수를 지정함.

```python
wide[['아메리카노', '라떼', '에이드', '스무디']].plot(kind='hist', alpha=0.5, bins=10)
plt.title('메뉴별 판매량 분포')
plt.show()
```

### pandas 박스플롯과 y축 이름

`kind='box'`로 숫자 열의 박스플롯을 그리며, 문자 열인 월은 자동으로 제외됨. `plt.ylabel()`로 y축 이름을 지정함.

```python
wide.plot(kind='box')
plt.title('메뉴별 판매량 분포')
plt.ylabel('판매량')
plt.show()
```

## 어려웠던 점·느낀 점

그래프 모양은 대부분 맞았지만, 리뷰에서는 제목 누락 11곳과 pandas 선·막대그래프의 x축 지정 누락, 복사한 제목을 수정하지 않은 점이 주요 오류로 지적됨.

히스토그램에서는 `bins=10`을 빠뜨렸고, long-form 변환 실습에서는 변환한 데이터 대신 원본 `df`를 사용한 점을 수정함. 완성된 그림만 확인하는 데서 그치지 않고, 요구한 옵션과 데이터 처리 과정까지 함께 검토할 필요가 있음을 확인함.
