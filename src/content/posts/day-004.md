## 배운 문법

### 나머지 연산과 연속 조건 비교

`% 2`의 결과를 비교해 연속한 세 수의 홀짝이 같은지 검사함. 조건을 만족하면 결과를 바꾸고 `break`로 반복을 종료함.

```python
for i in range(n-2):
    if (number[i] % 2 == number[i+1] % 2) and (number[i+1] % 2 == number[i+2] % 2):
        result = 'true'
        break
print(result)
```

### 상태 변수와 `continue`

답안 코드에서는 `skip`으로 다음 원소를 건너뛸지 기록함. `continue`를 사용해 해당 반복의 나머지 처리를 생략함.

```python
  if skip:

```

### 슬라이싱과 리스트 연결

리스트의 두 구간을 슬라이싱한 뒤 `+`로 연결해 원소를 한 칸씩 앞으로 이동하도록 구성함. `print(*shift)`로 리스트의 원소를 풀어서 출력함.

```python
shift = arr[1:] + arr[:1]
print(*shift)
```

### `split()`과 `map()`으로 입력 분리·변환

`split('+')`로 덧셈 기호를 기준으로 문자열을 나눔. 나눈 값에 `map(int, ...)`를 적용하고 두 변수에 대입함.

```python
s1 = input()
a, b = map(int, s1.split('+'))
print(a+b)
```

### `lower()`, `sorted()`, `join()`으로 문자열 정리

문자열을 소문자로 바꾼 뒤 문자를 정렬함. 정렬된 문자들을 `join()`으로 이어 하나의 문자열로 구성함.

```python
s = input()
s = s.lower()
q=sorted(s)
result = ''.join(q)
print(result)
```

### `abs()`로 인접 원소의 차이 계산

인접한 원소를 인덱스로 선택하고, 두 값의 차이에 `abs()`를 적용함. 마지막 원소의 다음 위치를 참조하지 않도록 반복 범위를 `n - 1`까지로 설정함.

```python
for i in range(n - 1):
  brr = abs(arr[i] - arr[i + 1])
  print(brr, end=' ')
```

### `ord()`, `chr()`와 나머지 연산으로 문자 이동

시저 암호 답안에서는 문자를 `ord()`로 수치화한 뒤 이동량을 더함. `% 26`으로 알파벳 범위 안에서 순환하도록 계산하고 `chr()`로 다시 문자로 변환함.

```python
        shifted = (ord(char) - ord('a') + key) % 26 + ord('a')
        result.append(chr(shifted))
```

### 중첩 `for`문과 음수 간격의 `range()`

바깥 반복의 `i`에 따라 안쪽 반복의 시작값을 바꾸도록 작성함. 안쪽에서는 `range(..., 0, -n)`을 사용해 값을 `n`씩 줄이며 순회함.

```python
n = int(input())
for i in range(n):
    for j in range(n*n-i, 0, -n):
        a = j+64
```

**1. 문자열1**

**2. 문자열2**
- **내 풀이**: `list(a+b)`로 리스트를 만들고 `pop()`으로 뒤에서 꺼냅니다.

둘 다 정답이고, `print((a+b)[::-1])`로도 됩니다.

**3. 문자열분신술**
내 풀이의 `for s in str: print(s*2)`가 답안의 `range(len(s1))` + 인덱스 접근보다 더 파이썬답습니다. 다만 `str`을 변수명으로 쓰면 내장 함수 `str()`을 가려서, 나중에 `str(cur)` 같은 변환이 필요할 때 에러가 납니다. `s`, `text` 같은 이름이 안전합니다.

**13. 방탈출 퀴즈**
문제 설명이 없어서 코드로 추정했습니다. 연속된 숫자를 하나의 수로 보고, 4자리가 되면 끊어서 합산하는 문제로 보입니다.

- **내 풀이**: `ord()`로 숫자 여부를 판별하고, 다음 글자까지 미리 확인하며 `cnt`, `re`로 모읍니다.
- **답안**: `isdigit()`로 판별하고 `cur = cur*10 + int(i)`로 숫자를 직접 만듭니다.

답안이 훨씬 짧고 읽기 쉽습니다. 내 풀이의 약점은 다음과 같습니다.
- 마지막 글자는 다음 글자가 없어서 `a1`이 직전 값 그대로 남습니다. 그 결과 마지막 글자가 숫자면 "다음도 숫자"로 처리되어 더해지지 않을 수 있습니다. 길이 1짜리 숫자 입력이면 `a1`이 아예 없어서 에러도 납니다.
- `sum`을 변수명으로 써서 내장 함수를 가립니다.
- 앞자리가 0인 경우("0012" 등)는 내 풀이가 4글자 단위, 답안이 4자리 수 단위라서 다를 수 있습니다.

참고로 **답안도 문자열이 숫자로 끝나면 마지막 `cur`를 더하지 않습니다.** 입력이 항상 숫자가 아닌 문자로 끝난다는 조건이면 둘 다 통과합니다.
