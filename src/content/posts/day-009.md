## 배운 문법

### 클래스와 `__init__()`

`class`로 클래스를 정의하고, `__init__()`에서 객체 생성 시 전달받은 값을 저장함. `self`의 속성에 대입하여 객체마다 상품 정보를 보관함.

```python
class Product:
    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock
```

### 메서드 정의와 속성 접근

클래스 안에서 `def`로 메서드를 정의하고, `self.속성명`으로 해당 객체의 값을 참조함. `info()`에서는 객체에 저장된 정보를 출력함.

```python
    def info(self):
        print(f"상품명 : {self.name}")
        print(f"상품가격 : {self.price}")
        print(f"상품재고 : {self.stock}")
```

### 객체 생성과 메서드 호출

클래스 이름 뒤에 인수를 전달하여 객체를 생성함. 생성한 객체의 메서드는 점 표기법으로 호출함.

```python
item1 = Product("치킨", 20000, 15)
item1.info()
```

### `return`과 메서드 간 호출

`return`으로 계산값을 반환하고, 다른 메서드에서 그 값을 활용함. 덧셈으로 총점을 구하고, 총점을 3으로 나누어 평균을 계산함.

```python
    def total(self):
        return self.kor+self.eng+self.math
    
    def aver(self):
        return self.total() / 3
```

### `if`·`elif`를 이용한 등급 분기

평균을 지역 변수에 저장한 뒤 `>=`로 기준 점수와 비교함. 높은 점수 조건부터 확인하여 해당하는 등급을 반환함.

```python
    def grade(self):
        avg = self.aver()
        if avg >= 90:
            return "A"
        elif avg >= 80:
            return 'B'
```

### 비교 연산과 수량 검증

`<=`와 `>`로 판매 수량의 유효성과 재고 초과 여부를 검사함. `if`·`elif`·`else`로 잘못된 수량, 재고 부족, 판매 가능한 경우를 구분함.

```python
        if count <= 0:
            print("올바른 수량을 입력하세요.")
        elif count > self.stock:
            print("재고가 모자랍니다.")
        else:
            self.stock -= count
```

### 복합 대입으로 재고 갱신

판매 시에는 `-=`로 기존 재고에서 수량을 빼고, 입고 시에는 `+=`로 수량을 더함. 입고는 `count > 0`인 경우에만 처리함.

```python
    def restock(self, count):
        if count > 0:
            self.stock += count
```
