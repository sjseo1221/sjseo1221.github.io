## 핵심 개념

### NumPy 배열과 차원

NumPy의 배열은 데이터를 담는 자료구조로 이해함. 숫자 하나인 스칼라부터 벡터, 행렬, 3차원 이상의 배열까지 만들어 보며 차원에 따른 구조를 살펴봄.

행렬은 여러 벡터가 쌓인 2차원 배열이며, 행과 열로 이루어진 표 형태의 데이터를 표현할 때 사용함. 이번 수업에서는 3차원 이상의 배열을 텐서로 다룸.

### 원소별 연산과 브로드캐스팅

NumPy 배열의 덧셈과 곱셈은 파이썬 리스트 연산과 다르게 동작함. 같은 크기의 벡터끼리 연산할 때는 같은 위치의 원소끼리 계산함.

배열에 숫자 하나를 더하거나, 행렬의 한 행과 원소 수가 같은 벡터를 행렬에 더하는 연산도 실습함.

### 내적과 행렬곱

벡터의 내적은 같은 위치의 원소를 곱한 뒤 모두 더한 하나의 값으로 이해함.

행렬곱은 앞 행렬의 행과 뒤 행렬의 열을 내적해 모은 행렬로 이해함. 원소별 곱셈과 행렬곱은 서로 다른 연산임을 구분함.

## 배운 문법

### `np.array()`로 배열 만들기

`np.array()`에 숫자 하나를 전달해 스칼라를 만들고, 리스트를 전달해 벡터를 생성함.

```python
v = np.array([1,2,3,4])
print(v.ndim)
```

### `type()`과 배열 속성 확인

`type()`으로 객체의 타입을 확인함. 배열의 `shape`, `ndim`, `dtype`으로 형태·차원 수·원소의 자료형을 확인함.

```python
print(type(scalar))
print(scalar.shape)
print(scalar.ndim)
print(scalar.dtype)
```

### 벡터 인덱싱과 슬라이싱

인덱스로 특정 원소에 접근하고, 슬라이싱으로 범위나 간격을 지정해 원소를 선택함.

```python
v = np.array([10, 20, 30, 40])
print(v[0])
print(v[:3])
print(v[::2])
```

### 원소별 덧셈·곱셈과 스칼라 연산

배열 사이에 `+`, `*`를 사용해 원소별로 계산함. 배열에 숫자 하나를 더하는 연산도 함께 실습함.

```python
print(a+b)
print(a*b)
print(a+1)
#파이썬 리스트 연산과 다름
#원소별 연산이 가능해. 단 갯수가 같아야해
```

### `@`로 벡터 내적 계산하기

두 벡터 사이에 `@`를 사용해 내적을 계산함.

```python
a = np.array([1,2,3])
b = np.array([4,5,6])

print(a@b) #내적곱
```

### 중첩 리스트로 행렬 만들기

`np.array()`에 중첩 리스트를 전달해 2차원 배열을 생성함. 생성한 행렬의 차원 수와 형태를 확인함.

```python
m = np.array([[1,2,3], [4,5,6]])
print(m.ndim)
print(m.shape)
```

### 행렬 인덱싱과 슬라이싱

`m[행][열]` 또는 `m[행, 열]`로 특정 원소에 접근함. 행과 열 위치에 슬라이스를 지정해 행의 일부나 특정 열을 선택함.

```python
print(m[0][0])
print(m[1, 2]) #print(m[1][2]) 와 같음
print(m[0, :2])
print(m[:, 1])
```

### `*`와 `@`로 행렬 연산 구분하기

행렬에 `*`를 사용하면 원소별 곱셈을 수행하고, `@`를 사용하면 행렬곱을 수행함.

```python
print(a+b)#원소별 덧셈
print(a*b)#원소별 곱셈  행렬곱과는 다른것임
print(a@b)
```

### 벡터와 행렬의 덧셈

벡터의 원소 수가 행렬의 한 행에 있는 원소 수와 같을 때, 벡터를 행렬에 더하는 연산을 실습함.

```python
a = np.array([1,2,3])
b = np.array([[5,6,7],[8,9,10]])
#matrix와 vector와의 연산은 한 행의 요소의 개수만 맞으면 가능하다.
print(a+b)
```

### `np.arange()`와 `reshape()` 연결하기

`np.arange(24)`로 0부터 23까지의 값을 만들고, `reshape(2,3,4)`로 3행 4열 구조 두 개를 갖는 3차원 배열로 재구성함.

```python
t = np.arange(24).reshape(2,3,4)
print(t.ndim)
print(t.shape)
print(t.dtype)
print(type(t))
```

### 3차원 배열 인덱싱과 슬라이싱

세 축의 인덱스를 지정해 특정 원소에 접근함. `:`와 범위 슬라이스를 조합해 여러 묶음에서 필요한 행과 열의 일부를 선택함.

```python
print(t[0,1,2])

print(t[:,0,:2])

print(t[:, 2, 1:4])
```
